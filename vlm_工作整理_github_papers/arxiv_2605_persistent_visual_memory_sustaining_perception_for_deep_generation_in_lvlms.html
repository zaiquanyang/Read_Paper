Persistent Visual Memory: Sustaining Perception for Deep Generation in LVLMs

VLM视觉推理多模态arXiv 2605.00814
核心问题：

2.1 核心问题：视觉信号稀释（Visual Signal Dilution）

自回归 LVLM（如 Qwen3-VL、InternVL）在多模态任务上取得显著进步，但在深层生成（deep generation）场景——长对话、多步推理链——中面临一个根本性问题：视觉信号稀释。

在标准自回归框架中，视觉 token 作为固定的前驱 token 一次性注入序列开头，而文本 token 在生成过程中不断自我补充。随着文本历史累积，注意力的 Softmax 归一化机制将概率质量重新分配到越来越多的 token 上，导致视觉信号逐渐衰减。

2.2 理论分析：幂律衰减

本文对这一现象进行了严格的数学推导：

定义视觉注意力质量（Visual Attention Mass）： $$\Omega_{\mathcal{V}}(t) = \frac{Z_{\mathcal{V}}}{Z_{\mathcal{V}} + Z_{\mathcal{T}}}$$

其中 Z𝒱 是视觉 token 的未归一化注意力总和（有上界 β = M ⋅ exp (smax)），Z𝒯 是文本历史 token 的总和（随 t 增长）。

定理（Visual Signal Dilution）：在持续文本注意力条件下（Z𝒯/t ≥ μ > 0），视觉注意力质量服从幂律衰减： $$\Omega_{\mathcal{V}}(t) \le \frac{\beta}{\beta + \mu \cdot t} = \mathcal{O}(t^{-1})$$

两个阶段： 1. 幂律稀释阶段：Z𝒯 随 t 线性增长，与固定 Z𝒱 竞争概率质量 2. 高幅饱和陷阱：Z𝒯 最终饱和于 Z𝒯sat ≫ 𝔼[Z𝒱]，系统进入 Low-Attention Equilibrium——视觉信号被文本先验以数量级压制

2.3 实验验证：“盲画家”压力测试

使用 Qwen3-VL-8B-Instruct 在 COCO 2017 验证集上设计 “Blind Painter” 压力测试——要求模型以极端细节文本重构图像，迫使每个生成步骤都依赖视觉检索。

关键发现： - 对数尺度分析确认 Ω𝒱 紧密遵循 𝒪(t − 1) 衰减轨迹 - 衰减在中间层（Layer 8-27）最为显著——这些层恰恰是多模态推理的主要位置 - Text-to-Vision Ratio（TVR）从线性增长阶段过渡到饱和平台，文本质量超视觉质量近两个数量级

方法框架：3. 方法与框架（详细）

3.1 总体架构

PVM 框架总览：PVM 与冻结的 FFN 并行，通过瓶颈适配器（Projection → Cross-Attn → FFN → Restoration）检索原始视觉嵌入，经可学习门控注入主流

PVM 作为并行分支集成到 Transformer Decoder Block 中，与 FFN 子层并行：

  • 推理路径（原始 FFN）：冻结 FFN 处理隐藏状态，访问预训练静态知识和逻辑模式
  • 视觉检索路径（PVM）：同一隐藏状态作为 Query，检索原始视觉嵌入

3.2 PVM 计算过程

三阶段计算：

1. 投影（Projection）：将输入隐藏状态和视觉特征降维到低维潜在空间 d′ < d xlat = xWdowntxt,  Vlat = VimgWdownvis

2. 潜在检索（Latent Retrieval）：Cross-Attention，Query 为投影后的隐藏状态，Key/Value 为投影后的视觉特征 hattn = CrossAttn(Q = xlat, K = Vlat, V = Vlat) hlat = hattn + FFNlat(RMSNorm(hattn))

3. 恢复（Restoration）：投影回原始高维空间 hpvm = hlatWup

3.3 门控融合与选择性激活

y = x + hffn + (λ ⋅ hpvm) ⋅ ℳtxt

  • 可学习标量门控 λ：初始化为 0，确保预训练能力不被破坏
  • **Visual Silencing Mask $_{}**：二值指示器，仅对文本 token 激活，防止视觉 token 的冗余自引用

3.4 理论保证：结构化缓解视觉稀释

定理（Structural Mitigation of Visual Dilution）：在固定局部隐藏状态假设下，PVM 的检索表示与文本历史长度 t 在分区函数上解耦： $$\frac{\partial \|\mathbf{h}_{\mathrm{pvm}}\|}{\partial t} = 0$$

这是因为 PVM 的分区函数 Zpvm 仅在固定的视觉集合 𝒱 上求和，变量 t 既不出现在分数计算中也不出现在求和索引中。

3.5 关键设计选择

  • 注入层选择：8B 模型注入 Layer {8, 16, 24}，4B 模型注入 Layer {5, 11, 17}——采用 Strided 策略覆盖网络全深度
  • 瓶颈维度：d′ = 512（消融验证最优，增大反而因数据-容量不匹配退化）
  • 参数开销：仅增加 27.92M 参数（~0.32% 的 8B 模型大小）

实验与核心结论：4. 实验分析（详细）

4.1 实验设置

基座模型：Qwen3-VL-Instruct（4B 和 8B）

训练数据： - SFT 阶段：526K 样本（来自 OpenMMReasoner-SFT） - GRPO 阶段：3.6K 复杂推理 query（来自 MMK12、ThinkLite-VL-hard、ViRL39K、We-Math2.0-Pro）

训练流程： - Stage I（视觉记忆对齐，SFT）：冻结 backbone，仅优化 PVM 模块和门控标量 - Stage II（策略精炼，GRPO）：解冻 LLM backbone 和 PVM（Vision Encoder 保持冻结）

评估 Benchmark：MMMU、MMBench-CN/EN、MMStar、MMT、MathVerse、MathVision、AI2D（共 8 个）

基线方法： - 内部基线：Qwen3-VL 原始、SFT、LoRA-SFT、SFT+GRPO - Visual Injection：MemVR、ICoT、CoMemo - RL 推理模型：Euclid-8B、PEARL-8B、OneThinker-8B

核心发现：

  1. PVM-8B (SFT+GRPO) 达到 71.5% Overall，超越基线 +4.8pp，在所有方法中最佳
  2. 一致性跨规模提升：4B 模型上也取得 +4.4pp 提升（64.0→68.4）
  3. PVM 仅 SFT 就达到 70.6%，已超越所有 Visual Injection 方法和 RL 推理模型
  4. SFT 反而损害 MMT（-5.9pp），但 PVM-SFT 将退化抑制到仅 -1.6pp——PVM 有效缓解微调过程中的感知退化

PVM 的增益随序列长度单调递增——越深层的推理链，持续视觉检索越不可或缺。这直接验证了 PVM 对视觉信号稀释的结构化缓解。

4.4 LogitLens 机制分析

使用 LogitLens 技术测量中间层表示与最终输出分布之间的 KL 散度（prediction readiness）： - 基线表现出渐进的 KL 下降 - PVM 建立了显著更低的轨迹，在注入层（Layer 8）之后出现明显的“Improvement Gap” - 这证实 PVM 有效地短路了信息收集过程——通过将视觉检索卸载到并行分支，backbone 加速从感知到推理的转换
