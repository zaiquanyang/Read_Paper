Persistent Visual Memory: Sustaining Perception for Deep Generation in LVLMs

VLM视觉推理多模态arXiv 2605.00814
核心问题：

自回归 LVLM（如 Qwen3-VL、InternVL）在多模态任务上取得显著进步，但在深层生成（deep generation）场景——长对话、多步推理链——中面临一个根本性问题：视觉信号稀释。

在标准自回归框架中，视觉 token 作为固定的前驱 token 一次性注入序列开头，而文本 token 在生成过程中不断自我补充。随着文本历史累积，注意力的 Softmax 归一化机制将概率质量重新分配到越来越多的 token 上，导致视觉信号逐渐衰减。

本文对这一现象进行了严格的数学推导：

定义视觉注意力质量（Visual Attention Mass）： $$\Omega_{\mathcal{V}}(t) = \frac{Z_{\mathcal{V}}}{Z_{\mathcal{V}} + Z_{\mathcal{T}}}$$

方法框架：方法与框架（详细）

PVM 作为并行分支集成到 Transformer Decoder Block 中，与 FFN 子层并行：

三阶段计算：

1. 投影（Projection）：将输入隐藏状态和视觉特征降维到低维潜在空间 d′ < d xlat = xWdowntxt,  Vlat = VimgWdownvis

2. 潜在检索（Latent Retrieval）：Cross-Attention，Query 为投影后的隐藏状态，Key/Value 为投影后的视觉特征 hattn = CrossAttn(Q = xlat, K = Vlat, V = Vlat) hlat = hattn + FFNlat(RMSNorm(hattn))

3. 恢复（Restoration）：投影回原始高维空间 hpvm = hlatWup

实验与核心结论：实验分析（详细）

基座模型：Qwen3-VL-Instruct（4B 和 8B）

训练数据： - SFT 阶段：526K 样本（来自 OpenMMReasoner-SFT） - GRPO 阶段：3.6K 复杂推理 query（来自 MMK12、ThinkLite-VL-hard、ViRL39K、We-Math2.0-Pro）

训练流程： - Stage I（视觉记忆对齐，SFT）：冻结 backbone，仅优化 PVM 模块和门控标量 - Stage II（策略精炼，GRPO）：解冻 LLM backbone 和 PVM（Vision Encoder 保持冻结）

评估 Benchmark：MMMU、MMBench-CN/EN、MMStar、MMT、MathVerse、MathVision、AI2D（共 8 个）

基线方法： - 内部基线：Qwen3-VL 原始、SFT、LoRA-SFT、SFT+GRPO - Visual Injection：MemVR、ICoT、CoMemo - RL 推理模型：Euclid-8B、PEARL-8B、OneThinker-8B
