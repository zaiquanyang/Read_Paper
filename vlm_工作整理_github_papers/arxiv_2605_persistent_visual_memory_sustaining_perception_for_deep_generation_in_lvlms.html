Persistent Visual Memory: Sustaining Perception for Deep Generation in LVLMs

arXiv 2605.00814GitHub
VLM逐篇精读
核心思想：PVM 从注意力分区函数推导视觉信号随文本长度近似 O(t⁻¹) 稀释，随后在 FFN 旁增加并行视觉记忆通路，用独立视觉 cross-attention 和门控融合维持长推理中的视觉访问。

问题与研究动机

自回归 LVLM 只在序列开头注入视觉 token；随着文本历史增长，视觉 attention mass 被越来越多文本 token 分走，长对话和深推理会逐渐变成文本先验驱动。

方法框架

PVM 与冻结 FFN 并行：将当前 hidden state 和原始视觉 embedding 投影到低维空间，使用视觉域内的 cross-attention 检索，再恢复到主干维度。

\[\Omega_V(t)=\frac{Z_V}{Z_V+Z_T}\le\frac{\beta}{\beta+\mu t}=O(t^{-1})\]

可学习门控 λ 初始化为 0，只对文本 token 激活视觉记忆，避免破坏预训练推理路径。

实验与核心结论

Qwen3-VL-8B 上 PVM-SFT+GRPO 的 Overall Avg 为 71.5，比 base 66.7 高 4.8pp；4B 也提升 4.4pp。增益随输出长度增加，长序列组达到 +27.3%；推理 TPOT 只增加 1.18ms（约 4.6%），额外参数约 0.32%。

价值、局限与启发

主要价值

PVM 将“持续看图”从主干自回归竞争中隔离出来，理论、机制和长序列实验相互对应。

需要注意

只验证 Qwen3-VL 和静态图像；动态视频、全局自回归状态下的理论保证和其他视觉退化因素仍待扩展。
