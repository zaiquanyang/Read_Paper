Very Efficient Listwise Multimodal Reranking for Long Documents

arXiv 2605.11864GitHub
VLM逐篇精读
核心思想：ZipRerank 面向长文档多模态 reranking，同时压缩输入视觉 token 和输出 decoding：两阶段 listwise 训练迁移排序能力，query-aware pruning 后只解一个 token 得到候选排序分数。

问题与研究动机

多个页面以图像输入时，prefill 视觉 token 很快爆炸；传统 listwise reranker 又要自回归生成排序序列。只优化准确率而不优化推理路径，无法满足 MMDocIR/M-RAG 的部署时延。

方法框架

  1. Stage 1 在 text reranking 上学习 listwise formulation。
  2. Stage 2 用 document-image 数据和 teacher soft labels 做多模态微调。
  3. 推理前用 query-image early interaction 做视觉 token pruning，随后用 single-token logits 直接给出 listwise 分数。
代表性图示

实验与核心结论

MMDocIR 的 DSE first-stage 上，ZipRerank 的 R@1/R@3/R@5 macro 为 64.2/84.8/89.0，时间仅 0.36s；MM-R5 的对应时间为 3.82s。它牺牲少量 top-1，换来更强的 top-k recall 和约一个数量级的延迟下降；在 ColQwen first-stage 上趋势一致。

价值、局限与启发

主要价值

贡献是把训练目标和推理路径一起工程化：不是更强 reasoning，而是更高效的 multimodal reranking system design。

需要注意

teacher bias、激进剪枝和 top-1 verifier 能力仍是限制；评测主要集中在 document-image reranking。
