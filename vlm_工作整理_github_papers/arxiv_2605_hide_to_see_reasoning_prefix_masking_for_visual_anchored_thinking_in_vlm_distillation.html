Hide to See: Reasoning-prefix Masking for Visual-anchored Thinking in VLM Distillation

VLM逐篇精读arXiv 2605.11651
核心思想：Masking-KD 通过遮掉最容易形成文本 shortcut 的 reasoning prefix，恢复 think-answer 蒸馏难度，迫使 student 在生成后续 token 时重新利用图像，而不是只复制 teacher 的文字轨迹。

问题与研究动机

长 think-answer prefix 会让后续 token 变得容易预测，student 逐渐学会 textual shortcut 并发生 visual forgetting。直接蒸馏 teacher attention 并不能保证 student 自己持续看图。

方法框架

  1. 用 auxiliary student forward 估计 response prefix 对当前 token 的影响。
  2. 按 token 级 salient reasoning-prefix mask 遮挡高影响前缀，而保留视觉和问题输入。
  3. 用 self-paced budget 从 ρmin=0.3 调到 ρmax=0.5。
  4. 在被遮挡条件下做 response-level distillation，训练 student 形成 visual-anchored thinking。

实验与核心结论

8B teacher→4B student 时，Masking-KD 平均分达到 56.66，超过 Naive Response Distillation 的 48.89、CompoDistill 的 51.29；Geo3K/MathVista/We-Math 为 52.58/66.50/71.03。self-distillation 也有效。

价值、局限与启发

主要价值

核心是“破坏捷径”而不是“复制内部表征”，让 student 在每个阶段重新依赖视觉证据。

需要注意

需要 auxiliary forward 和 attention map，训练成本增加；验证主要集中在 reasoning-heavy benchmark。
