LearnPruner: 重新思考视觉语言模型中基于注意力的 Token 剪枝

VLM视觉推理多模态
核心问题：

VLM 推理时需要处理大量视觉 token（如 LLaVA-1.5 为 576 个，LLaVA-NeXT 可达 2880 个），带来严重的计算负担。Token 剪枝的核心在于判断 token 重要性，当前方法主要依赖注意力分数。但本文发现两个关键问题：

  1. 视觉编码器的 [CLS] 注意力不可靠：ViT 倾向于在背景区域产生高范数异常 token（artifacts），导致 [CLS] token 对前景区域的关注不足
  2. LLM 的注意力存在层间差异：虽然存在 attention shift 现象（视觉 token 索引越高获得的注意力越多），但文本到视觉的注意力对此偏移具有鲁棒性，且在中间层才能有效关注语义相关区域

核心问题：能否设计一个两阶段剪枝框架，在不同阶段使用最合适的重要性度量？

方法框架：方法概述

注意力机制分析（关键发现）

通过在 LLaVA-1.5-7B 上的系统实验，得出三个核心观察：

发现 1：视觉编码器 [CLS] 注意力的缺陷 - 将 token 选择限制在前景区域（[CLS]fg）始终优于全图选择（[CLS]all），尤其在激进剪枝比例下 - 甚至随机前景选择（Randomfg）都能达到与 [CLS]all 相当的性能 - 结论：[CLS] token 未能有效关注前景区域

发现 2：LLM 中文本注意力 vs 视觉注意力 - 视觉注意力受 attention shift 严重影响，不同样本间偏差大 - 文本注意力的偏移趋势更平缓，且不同样本和低索引 token 也能获得高关注度 - 结合视觉注意力会导致性能大幅下降

发现 3：LLM 中间层的注意力最可靠 - 浅层：不相关区域吸收了文本 token 的大部分注意力 - 中间层（8+ 层开始）：不同文本 token 能聚焦到语义相关区域，>95% 原始性能 - 深层：注意力可靠性显著下降

LearnPruner 框架

基于上述分析，提出两阶段剪枝框架：

阶段一：移除视觉冗余（视觉编码器后）

使用可学习剪枝模块（LPM）替代 [CLS] 注意力： - 轻量 MLP 对每个视觉 token 做二分类（保留/剪枝） - 使用 Straight-Through Estimator（STE）实现端到端训练 - Msoft = Softmax(MLP(Xv(0)))，推理时作为重要性分数

为防止 LPM 过度聚焦前景而丢失关键背景信息，引入多样性 token 选择： - LPM 选完后，对剩余 token 计算与已选 token 的最大余弦相似度 - 迭代添加相似度最小的 token，直到 token 预算用尽 - 默认保留 10% 的 token 预算用于多样性选择

阶段二：移除文本无关内容（LLM 中间层）

在 LLM 第 12 层利用文本注意力进行二次剪枝： - $\tilde{\mathbf{A}}^{(k)} = \frac{1}{N_q} \sum_{i=1}^{N_q} \mathbf{A}^{(k)}(\mathbf{X}_{q,i}^{(k)}, \mathbf{X}_v^{(k)})$ - 仅保留注意力分数最高的 top-k token

两个阶段的 token 保留比例 R1 : R2 = 3（消融实验验证最优）。

训练细节

  • 训练数据：LLaVA-665K 数据集的 10%（数据效率极高，5% 即可达到强性能）
  • 训练策略：冻结基础 VLM 权重，仅训练 LPM
  • 损失函数：ℒ = ℒntp + λ ⋅ ℒprune，其中 $\mathcal{L}_{\text{prune}} = (\frac{1}{N_v} \sum \mathbf{M}_{\text{hard}} - \tau)^2$，τ = 0 鼓励最小化 token 使用
  • 注意力掩码训练：通过修改 Softmax 模拟剪枝过程——被剪枝 token 不参与注意力计算
