LearnPruner: 重新思考视觉语言模型中基于注意力的 Token 剪枝

arXiv 2604.23950
VLM逐篇精读
核心思想：LearnPruner 发现视觉编码器 CLS 注意力和深层视觉注意力都不是可靠的 token 重要性指标，于是用轻量可学习剪枝加中间层文本注意力做两阶段压缩，在极少 token 下保持 VLM 能力。

问题与研究动机

LLaVA-NeXT 等模型会产生数千视觉 token。现有剪枝依赖 CLS 或视觉注意力，容易被背景 artifact 和 attention shift 误导；真正需要的是与文本问题相关、且跨样本稳定的视觉证据。

方法框架

  1. 阶段一：视觉编码器后接 0.53M 参数的 LPM，用 MLP+STE 预测保留/剪枝，并用多样性选择补回低相似度 token。
  2. 阶段二：在 LLM 第 12 层聚合文本到视觉的注意力，只保留与 query 相关的 top-k token。
  3. 两个阶段的保留比例为 R1:R2=3:1；冻结基础 VLM，仅用 LLaVA-665K 的 10% 训练 LPM。

实验与核心结论

在 LLaVA-v1.5-7B 仅保留 32 token 时，LearnPruner 保留原模型 94.8% 的综合性能，而 FastV 只有 58.6%；保留 64 token 时达到 96.9%。在高分辨率 LLaVA-NeXT（2880→640 token）和 Qwen2.5-VL 上仍保持接近完整输入的效果。

价值、局限与启发

主要价值

核心贡献是先验证“哪一种注意力值得信任”，再把不同层级的信号放到合适的位置。

需要注意

剪枝层和比例仍固定，复杂场景可能丢失背景证据；方法需要少量训练，尚未在更大模型上验证。
