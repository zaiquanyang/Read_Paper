Saliency-R1: Enforcing Interpretable and Faithful Vision-language Reasoning via Saliency-map Alignment Reward

arXiv 2604.04500GitHub
VLM逐篇精读
核心思想：Saliency-R1 用 token 级显著性图和 attention rollout 追踪“思考 token”依赖的视觉区域，再把显著性与人工框标注的对齐度作为 GRPO 奖励，直接优化可解释且忠实的视觉推理。

问题与研究动机

相同答案可能来自真正看图的推理，也可能来自语言先验或视觉幻觉。仅奖励 answer correctness 无法区分两者，因此需要一个能检查 reasoning 是否关注正确区域的过程信号。

方法框架

方法由三部分组成：logits 分解得到视觉 patch 的直接贡献；以 thinking tokens 为瓶颈做 attention rollout；将显著性落在 bbox 内的比例作为连续奖励。

\[R_{overall}=R_{accuracy}+R_{format}+R_{saliency},\quad R_{saliency}=\frac{\sum_{i\in bbox}s_i}{\sum_{i\in image}s_i}\]

每个问题采样 8 条 rollout，用 GRPO 同时约束答案正确、输出格式和视觉对齐。

实验与核心结论

在 COCO deletion test 中，方法的 deletion 分数为 70.96/59.45/50.34，优于 CAM、Grad-CAM、ATTN-LRP 和 TAM，说明显著性图更忠实。主实验在 MMMU-Pro、MMStar、IllusionVQA 和 SalBench 等任务上同时改善答案能力与幻觉抑制。

价值、局限与启发

主要价值

它把“解释看起来合理”转化成可测的空间对齐约束，并把解释监督接入 RL。

需要注意

依赖 bbox 标注与外部 judge；显著性仍是直接贡献近似，不覆盖所有隐式路径。
