Saliency-R1: Enforcing Interpretable and Faithful Vision-language Reasoning via Saliency-map Alignment Reward

VLM视觉推理多模态arXiv 2604.04500
核心问题：

2.1 任务定义与应用场景

VLM 在多模态推理中取得显著进展，但其可信度面临两个核心挑战： 1. 过度依赖文本线索：视觉信号在推理中扮演的角色相对较小 2. 幻觉问题：模型生成未被图像支持的内容

当前 VLM 推理使用 Chain-of-Thought (CoT) 或类似 DeepSeek-R1 的推理机制生成自然语言解释 (NLE)，但研究表明这些解释与最终答案之间可能存在不一致性——“思考”过程未必忠实反映解题过程。

2.2 核心洞察

不同思维过程关注图像的不同区域，即使得出相同答案： - 有的推理真正关注与问题相关的区域 - 有的关注不相关物体或背景 - 后者本质上是对视觉信息的误用或幻觉

本文的核心目标是：确保 VLM 的推理过程真正“看”到了正确的图像区域。

方法框架：3. 方法与框架（详细）

3.1 总体框架

Saliency-R1 包含三个核心组件：

  1. Token-level Saliency Map 生成：通过 logits 分解高效生成显著性图
  2. Attention Rollout 聚合：以 thinking tokens 为瓶颈，追踪视觉信息如何流向答案
  3. GRPO + Saliency Alignment Reward：用显著性图与人工标注 bounding box 的对齐度作为奖励信号

3.2 Token-level Saliency Map 生成（Logits 分解）

基于 Transformer 架构，将 token logits 分解为各 context token 的一阶贡献：

$$c_p = \sum_{l=1}^{L}\sum_{j=1}^{H}\alpha_{i,j,p}^l \mathbf{W}_{o,j}^l \mathbf{W}_{v,j}^l \mathbf{h}_p^{l-1} \mathbf{E}_u$$

其中 αi, j, pl 是 attention 权重，Wo 和 Wv 是输出和值投影矩阵。

关键实现细节： - 仅选取视觉 token 对应的 cp 值，按 patch 顺序重排 - 应用 ReLU 忽略负贡献 - 不需要额外的前向或反向传播——attention 权重和 KV cache 中的值向量已天然可用 - 虽然忽略间接贡献（残差连接、FFN 部分），但文献表明直接贡献占主导地位

计算效率：生成显著性图的额外开销几乎为零，使其能无缝集成到训练 pipeline 中。

3.3 Attention Rollout：Thinking Tokens 作为瓶颈

推理模型先生成思维链 (thinking tokens)，再生成答案。本文假设： - Thinking 过程从图像中提取信息 - 答案基于 thinking 过程的总结

为了可视化这一流程，使用 attention rollout 追踪视觉信息如何通过 thinking tokens 流向答案：

$$\tilde{\mathcal{A}}_{va}^{l,h} = \mathcal{A}_{vt}^{l,h} \cdot \mathcal{A}_{ta}^{l,h}$$

其中 𝒜vt 是视觉→thinking 的注意力矩阵，𝒜ta 是 thinking→answer 的注意力矩阵。

关键设计： - 不对列做归一化：某些 answer token（如介词）接收很少的 thinking 贡献，某些 thinking token 接收很少的视觉贡献，这些 token 自然在 holistic saliency map 中影响更小 - 直接求和 per-token map 得到最终的 holistic saliency map - 低置信度的 answer token（logits 小）贡献也更少

3.4 GRPO + Saliency Alignment Reward

Alignment Score 定义为 saliency map 在 bounding box 内的质量占比：

$$\text{Alignment\_Score} = \frac{\sum_{i \in \text{Bounding Box}} \text{Saliency\_Score}(i)}{\sum_{i \in \text{Image}} \text{Saliency\_Score}(i)}$$

实验与核心结论：4. 实验分析（详细）

4.1 实验设置

训练数据： - SFT 冷启动：Saliency-R1-cold（Vision-R1-cold 的子集），272,881 样本 - GRPO：Saliency-r1-8k（Visual-CoT 子集），8,080 样本，含 bounding box 标注

实现细节： - Base model: Qwen2.5-VL-3B/7B - SFT: llama-factory, 2 epochs, lr=5e-5, LoRA rank=128 - GRPO: TRL, 3 epochs, lr=1e-5, LoRA rank=8 (Q/V 投影层), batch=128, rollout=8 - LLM judge: GPT-4o-mini - 硬件：8× A6000 GPU
