Walk the Talk: Bridging the Reasoning-Action Gap for Thinking with Images via Multimodal Agentic Policy Optimization

arXiv 2604.06777
VLM逐篇精读
核心思想：MAPO 解决 multimodal agent 的 reasoning-action gap：模型先用 label 说清楚想观察什么，执行 crop/zoom 后再用 CLIP 检查 observation 是否与意图一致，并把该过程奖励加入策略优化。

问题与研究动机

只看最终答案会强化“嘴上说要看目标、实际裁错区域”的轨迹。错误动作在多轮视觉工具调用中不断累积，导致稀疏奖励、梯度方差和训练不稳定。

方法框架

  1. 模型在每次视觉动作前生成可验证的 descriptive label。
  2. 工具返回局部 observation，CLIP 计算 label 与 observation 的语义一致性。
  3. 将 step-level semantic score 与 outcome reward 融合进 MAPO advantage，约束“说到做到”。

实验与核心结论

同一 Ovis2.5-9B backbone 上，MAPO 的 V* Overall 为 89.5，HR-Bench Overall 为 79.8，优于 GRPO 的 88.6/77.8；HR-Bench 8K 达到 78.6。收益主要集中在高分辨率、细粒度视觉探索任务。

价值、局限与启发

主要价值

把隐式工具意图显式化，再对执行结果做局部验证，是一个可迁移的 multimodal agent reward 模式。

需要注意

CLIP 相似度不一定等价于任务一致性；label 质量和 task-specific reward 仍是瓶颈。
