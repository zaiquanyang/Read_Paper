HyperEyes: Dual-Grained Efficiency-Aware Reinforcement Learning for Parallel Multimodal Search Agents

VLM逐篇精读arXiv 2605.07177v1
核心思想：HyperEyes 面向多实体 multimodal search，把“能并行调用工具”变成“愿意以更低成本并行搜索”：用 UGS、并行数据构造、TRACE 成本奖励和失败轨迹 OPD 共同降低工具轮数。

问题与研究动机

串行 crop-search loop 会不断增加 interaction round 和上下文噪声。仅优化 accuracy 会鼓励 brute-force 搜索，模型不会主动把可分解子任务并行化。

方法框架

  1. UGS：统一 grounded action，让一轮动作可以定位多个实体并发起搜索。
  2. 数据管线：合成 multi-entity 样本，用 tool-necessity filtering 与 Progressive Rejection Sampling 保留真正需要搜索的轨迹。
  3. TRACE：提供 query-dependent 工具成本奖励；仅对 failed rollout 使用同家族 teacher 的 OPD 做细粒度修复。

实验与核心结论

HyperEyes-30B RL 的 Avg Acc/Turns 为 64.0/2.2，相对同规模开源 deep-search agent 准确率约 +9.9、工具轮数约 −9.4；相对 VDR 少约 5.3× 工具轮。BCVL/IMEB 的 CAS 达到 2.232/0.910，约为次优开源方法的 4.3×/7.6×。

价值、局限与启发

主要价值

它把并行搜索的动作空间、数据和奖励闭环起来；OPD 在这里是失败轨迹修复器而非主目标。

需要注意

更适合可分解的静态图像查询；对强 sequential multi-hop、视频和音频场景，以及无需同家族 teacher 的扩展仍未知。
