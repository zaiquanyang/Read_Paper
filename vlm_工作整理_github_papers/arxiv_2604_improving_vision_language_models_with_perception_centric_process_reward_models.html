Perceval: 以感知为中心的过程奖励模型改进视觉语言模型

VLM视觉推理多模态
核心问题：

RLVR（Reinforcement Learning with Verifiable Rewards）已成为提升 VLM 推理能力的关键技术，但其结果级（outcome-level）奖励信号过于粗糙，无法定位推理链中具体哪一步出了错。VLM 在多步推理中频繁出现感知幻觉（插入不存在的物体、错误的空间关系），但只有最终奖励才给出反馈，导致严重的信用分配问题。

本文提出核心问题：能否构建一个以感知为中心的过程奖励模型（PRM），在 token 级别定位并惩罚幻觉，从而提供更细粒度的训练监督和推理纠错？

方法框架：方法概述

Perceval 是一个生成式过程奖励模型，给定图像 v、问题 q、模型回答 o，输出结构化的验证结果：

  1. …：逐条分析回答中每个感知 claim 是否与图像视觉证据一致
  2. …：若无错误输出 "The response is correct."；否则输出一个 Python 列表，包含被识别为幻觉的原文子串

这种设计直接定位错误 span，而非给出单一标量分数。

  1. 查询选择：主要来自视觉搜索数据集（如 V*、DeepEyes），辅以少量数学推理和通用理解数据
  2. Rollout 生成：用 Qwen2.5-VL-7B 生成回答（其不完美的感知对齐天然产生丰富的幻觉样本）
  3. 自动标注与验证：使用强模型（如 Gemini-2.5-Pro）进行幻觉检测的逐步验证，生成结构化标注
  4. 监督微调：在聚合数据上 SFT 训练 Perceval 模型
