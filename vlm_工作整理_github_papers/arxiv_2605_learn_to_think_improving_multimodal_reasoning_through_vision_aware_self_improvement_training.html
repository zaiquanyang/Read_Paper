Learn to Think: Improving Multimodal Reasoning through Vision-Aware Self-Improvement Training

VLM逐篇精读arXiv 2605.11931
核心思想：VISTA 将 MLLM self-improvement 从“只收集答对样本”推进到两步数据治理：prefix resampling 为困难 query 回收更多正确轨迹，VAS 过滤答对但缺少视觉 grounding 的伪正确推理。

问题与研究动机

self-generated reasoning 同时存在 data imbalance 与 language prior bias：简单题容易采到大量正确解，Geometry3K 上超过 40% query 甚至采不到正确解；而一些最终答对的 trace 中间并没有真正看图。

方法框架

  1. Prefix resampling：在 negative trace 中寻找第一个不在前一步 Top-5 的 critical token，用新 Top-1 替换并截断后续，再从正确前缀继续采样。
  2. VAS：在中间层统计 reasoning token 对 visual/system/instruction token 的 attention 比例，标准化为 VAS=(S−mean)/std，过滤 VAS<−0.5 的伪正确解。
  3. 剩余数据可用于 SFT、DPO 或 GRPO；冻结 vision encoder 和 projector，只更新 LLM backbone。
\[S=\frac{\lambda_{vis}}{\lambda_{sys}+\lambda_{vis}+\lambda_{ins}}\]

实验与核心结论

Geometry3K 上 prefix resampling 将每个 query 的平均正确解数量从 2.4 提升到 4.4；hallucinated solution 的平均 VAS 约 −0.2，non-hallucinated 约 0.31。Qwen2.5-VL-3B 的 VISTA-SFT 在 ScienceQA/ChartQA 达到 82.29/62.09，跨 Qwen3-VL 与 InternVL 的总体平均达到 65.30；相对 3B SFT-Seed 平均提升 +13.66。

价值、局限与启发

主要价值

VISTA 把“难样本覆盖率”和“视觉可靠性”分开建模，且不依赖额外 reward model。

需要注意

prefix recycling 可能降低轨迹多样性；VAS 仍是 attention proxy，大模型和不同视觉拼接格式上的稳定性待验证。
