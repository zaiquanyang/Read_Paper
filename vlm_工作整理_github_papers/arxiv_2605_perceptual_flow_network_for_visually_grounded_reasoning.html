Perceptual Flow Network for Visually Grounded Reasoning

VLM视觉推理多模态arXiv 2605.02730
核心问题：

在 V* Bench 上使用 Qwen2.5-VL 家族进行探测，将原始标注各向同性扩展后送入模型（而非完整图像），测量不同几何先验的推理效用。结果发现： - 最精确的几何先验（专家标注）反而不是最有帮助的 - 适度扩展的区域（IoU 较低但包含更多上下文）效果更好 - 最优几何先验是高度实例特定的，无法通过简单启发式策略获得

原因在于：视觉专家最初为物体检测设计，追求严格的几何精度，但这会诱导 “隧道视野”（tunnel vision）效应——排斥了全面理解所需的上下文信息，反而降低推理性能。

方法框架：方法与框架（详细）

PFlowNet 将视觉推理分解为两个解耦的阶段：

p_θ(Y, Z | X) = p_θ(Z | X) · p_θ(Y | Z, ⟨X, I_RoI⟩)
  1. Flow Generation 阶段：从模型内在分布 pθ(Z|X) 采样 Perceptual Flow
  2. Flow-Guided Reasoning 阶段：基于生成的 Flow 及对应 RoI 裁剪图进行 self-conditioned 自回归生成

核心框架图见 Figure 4：

Perceptual Flow Z = (z0 → z1…zK) 是一个结构化的隐式轨迹，包含两种状态：

状态 定义 格式
Planning State (z0) 分解查询、识别视觉候选 <analyze>...</analyze> 包裹的语言序列
Perceptual States (z ≥ 1) 锚定观察链 <localize>...</localize> 包裹，每步 zk = ⟨rk, ck⟩（RoI + 描述 caption）

基于此，采用 Sub-Trajectory Balance (Sub-TB) 目标进行分层变分优化： minθ∑i, jD(ℱ(zi)𝒯F(zi : j)∥ℱ(zj)𝒯B(zj : i))

相比 PPO 等 RL 范式，Sub-TB 提供密集的中间监督，促进多样化的感知行为。

数据收集原则： - 多样化任务：覆盖细粒度理解和通用场景 - 多样化 RoI：跨专家交叉标注，保留空间覆盖足够广泛的样本
