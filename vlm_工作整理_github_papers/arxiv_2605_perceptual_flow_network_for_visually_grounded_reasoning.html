Perceptual Flow Network for Visually Grounded Reasoning

arXiv 2605.02730
VLM逐篇精读
核心思想：PFlowNet 发现几何上最精确的专家框并不一定最利于推理，提出由 planning state 和 perceptual state 组成的 Perceptual Flow，并用质量/效用双奖励学习自参数化视觉轨迹。

问题与研究动机

直接对齐检测器的精确 RoI 会产生 tunnel vision：上下文被裁得过窄，反而损害视觉推理。理想感知区域具有实例相关的上下文范围，不能用固定几何启发式得到。

方法框架

模型先生成查询分解的 <analyze> planning state，再生成包含 RoI 与 caption 的 <localize> perceptual states，形成 Z=(z0→…→zK)。训练分两步：用 teacher 合成多样 Flow 做 cold start，再用 Sub-Trajectory Balance 的 RFT 优化；奖励同时衡量 Flow 质量和推理效用。

实验与核心结论

Qwen3-VL-8B 上，PFlowNet 在 TreeBench/MME-RealWorld 达到 55.3/67.0，相对 base +10.4/+18.4；V* 达到 90.6，超过 Qwen3-VL-32B 的 87.4。去掉 Flow 后 V* 从 90.6 降至 83.8，说明 Flow 是语义锚点而非单纯定位工具。

价值、局限与启发

主要价值

关键洞察是“几何精度不等于推理效用”，并用显式可读的视觉轨迹把两者解耦。

需要注意

两阶段训练和固定推理格式增加复杂度；理论假设理想化，ε/λ 等超参数需要按模型调节。
