Personal Visual Context Learning in Large Multimodal Models

VLM逐篇精读
核心思想：Personal Visual Context Learning 先用 Personal-VCL-Bench 诊断模型不会稳定利用长期视觉历史，再提出 Agentic Context Bank：把离散视觉上下文整理成带证据的记忆条目，并在查询时按需回取视觉证据。

问题与研究动机

把所有个人视觉历史直接拼进 prompt 会造成 scaling paradox（上下文越多越不稳）和 modality paradox（模型看到了图却不会用）。关键不只是 retrieval，而是如何组织和路由证据。

方法框架

  1. Stage I：将每条记忆表示为 (τ,d,e)，分别是类型、文本描述和原始视觉证据；通过 ADD/CONFIRM/REVISE/RETRACT 持续合并和纠错。
  2. Stage II：先只给文本 bank 做 triage，让模型请求需要核验的 entry ID，再把少量对应视觉证据回填，完成最终回答。

实验与核心结论

Gemma-4-31B 上，Agentic Context Bank 在 PerID/ObjID/BehErr/EgoID 等任务达到 83.25/82.52/66.22/61.60，全面超过只给语言或全视觉上下文的 baseline。EgoWearer 上，Gemini-3-Flash 的 adaptive evidence 为 72.82，比最强标准 baseline 高 17.08。

价值、局限与启发

主要价值

贡献在于把长期视觉上下文拆成“结构化记忆”和“查询时证据路由”两个问题。

需要注意

尚未解决长时流的 context retrieval、隐私风险和 Stage-II 证据误选；方法仍是强推理时 baseline。
