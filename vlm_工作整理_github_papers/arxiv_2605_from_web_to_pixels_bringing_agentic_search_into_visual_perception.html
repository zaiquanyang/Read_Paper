From Web to Pixels: Bringing Agentic Search into Visual Perception

VLM逐篇精读arXiv 2605.12497
核心思想：From Web to Pixels 提出 Perception Deep Research：先通过网页搜索解析图中目标的真实身份，再把结构化 target hypothesis 绑定到具体像素，形成 search-grounding、search-segmentation 和 search-VQA 的统一任务。

问题与研究动机

真实图像中的目标身份常藏在图外知识里。直接做 language-to-region 会因实体歧义而找错对象；搜索增强回答又通常停在文本答案，没有把证据落回像素。

方法框架

Pixel-Searcher 是两阶段 agentic workflow：

  1. Search & Target Resolution：在 Search-Reason-Resolve 循环中得到 h={e,c,K}，分别表示实体、粗类别和可由图像核验的线索。
  2. Grounding & Tool Use：用 h 调用 grounding 工具生成候选区域，再做证据一致性验证，输出 box、mask 或答案。

实验与核心结论

WebEyes 上，Pixel-Searcher 的 SearchGround Overall IoU/R@0.5 为 34.17/41.30，超过 Qwen3-VL-8B 的 26.81/32.61；SearchSeg gIoU/cIoU 为 39.17/32.41；SearchVQA 达到 42.24。收益在 Anime、ICON、Product 等需要实体解析的类别最明显。

价值、局限与启发

主要价值

贡献首先是任务定义：把 search 变成 perception 的前端身份解析，而不是回答的后端知识补充。

需要注意

WebEyes 规模较小，流程依赖搜索可靠性和外部工具，闭源模型仍明显更强。
