AlphaGRPO: Unlocking Self-Reflective Multimodal Generation in Unified Multimodal Models via Decompositional Verifiable Reward

VLM逐篇精读arXiv 2605.12495
核心思想：AlphaGRPO 在统一多模态模型中把 reasoning text 与 diffusion image trajectory 放进同一条 RL 轨迹，用 DVReward 将复杂生成要求拆成可验证问题，并通过 FPR 抑制无效自我修图。

问题与研究动机

UMM 的视觉理解、规划和自我反思能力可能已存在，但额外 cold-start SFT 会混淆 RL 的真实贡献；单一 holistic score 也无法说明图像到底违反了哪一条约束。

方法框架

  1. 统一轨迹 τ=(y,z1→z0)：先生成 reasoning，再生成图像 diffusion trajectory。
  2. DVReward 把 request 分解为 atomic questions，对每个问题做 confidence scoring，再组合 reward。
  3. 同一 group-normalized advantage 同时更新 AR reasoning policy 和 flow generation policy。
  4. FPR 将没有超过初始图像的 refinement 压到 group 最低 reward，避免 false-positive optimization。

实验与核心结论

512 分辨率上，AlphaGRPO-SRR 在 TIIF Overall-S/L 达到 79.1/79.5，推理时再做 self-reflective refinement 后升至 83.9/83.2；1024 分辨率仍达到 82.2/81.4，并在 GenEval 达到 89.5。

价值、局限与启发

主要价值

最值得复用的是“先拆解约束，再逐项验证”的 reward 设计，以及跨文本/图像轨迹的 credit assignment。

需要注意

依赖大型 verifier，训练成本高；当前主要是 outcome reward，base model 的生成稳定性也限制上限。
