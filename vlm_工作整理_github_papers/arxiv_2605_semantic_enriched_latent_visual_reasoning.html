Semantic-Enriched Latent Visual Reasoning

VLM逐篇精读arXiv 2605.19342
核心思想：SLVR 在 latent visual reasoning 中增加 attribute-level semantic latent，并用 M-GRPO 在同一区域的多问题之间约束 latent 一致性，使隐式视觉表示从 appearance cue 变成可复用的语义载体。

问题与研究动机

纯 visual latent 往往只保留局部外观，换一个问法就不稳定；显式 crop/zoom 虽有证据但推理链长。论文要学习一种同时保留视觉细节、对象属性、动作和空间关系的 region-centric latent。

方法框架

  1. Stage 1 将 ROI visual latent 与原始视觉特征对齐，同时用 4096 维 attribute embedding 监督 semantic latent。
  2. Stage 2 的 M-GRPO 对同一区域的多 query 采样，联合优化 answer correctness、visual/semantic latent consistency。
  3. SV-QA 专门构造“同一区域、两个语义问题”的评测，直接测 latent 能否跨 query 复用。

实验与核心结论

SLVR-7B 在 OKVQA/VizWiz/ChartQA/TextVQA 达到 61.8/57.8/77.2/79.3，相对 LVR 分别 +11.2/+24.7/+12.8/+4.2；VisualPuzzles Overall 为 34.2，比 LVR +4.8。GQA、AI2D 略低于 LVR，说明语义增强对区域属性和多视角问题更有针对性。

价值、局限与启发

主要价值

贡献在于改变 latent 的监督目标：从“能不能答题”转向“能否稳定承载可复用语义”。

需要注意

依赖外部强模型生成 semantic profile 和 judge；dense semantic embedding 可能过度压缩复杂关系，标准 benchmark 也并非全面提升。
