Why Does Self-Distillation (Sometimes) Degrade Reasoning?

arXiv 2603.24472GitHub
Analysis PDF Code MSR / KAIST / SNU · arXiv 2603.24472
核心思想：诊断性研究发现 rich privileged context 的教师会抑制学生的 epistemic verbalization（不确定性表达），导致学生"假装确定"，在 OOD 任务上出现最高 40% 的性能退化。

核心发现

  • Epistemic Verbalization Collapse：rich privileged context 抑制学生不确定性表达
  • Rich context 带来更大 in-domain 增益，但造成更严重 OOD 退化
  • Thin privileged context 提供更平衡的 in-domain/OOD 表现

优点与局限

优点

  • 揭示了 OPSD 的关键失败模式
  • Epistemic verbalization collapse 概念化具有理论深度
  • 对方法设计有重要指导意义

局限

  • 纯分析论文，未提出解决方案
  • 如何平衡 in-domain 增益与 OOD 退化仍需后续探索

定位：诊断性分析工作，揭示了 OPSD 在 rich privileged context 下的 epistemic verbalization collapse 失败模式。
