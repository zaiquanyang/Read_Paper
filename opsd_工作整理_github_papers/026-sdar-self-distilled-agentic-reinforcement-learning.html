SDAR: Self-Distilled Agentic Reinforcement Learning

arXiv 2605.15155GitHub
SDAR PDF Code ZJU-REAL · arXiv 2605.15155
核心思想：把 OPSD 放到多轮 agent RL 场景中，用 token-level detached sigmoid gate 严格调制 teacher guidance，承认 skill-conditioned privileged teacher 只是局部可信，RL 保留为任务优化主干。

方法

  • GRPO 主干 + SDAR 辅助项解耦：RL 对齐任务回报，distillation 只补充 token-level shaping
  • Teacher-student gap $\Delta_t$ 经 detached sigmoid gate 过滤：$g_t=\sigma(\beta\Delta_t)$
  • Gate 只在 teacher 正向背书 student token 时放大 distillation，负向信号温和抑制
  • 使用 reverse KL，mode-seeking 更适合"只吸收 teacher 正向支持"

实验结果

GRPO+OPSD 在 7B ALFWorld 上不稳定，说明 naive OPSD 不是普适解。Random retrieval 仍优于无 OPSD。

优点与局限

优点

  • 问题定位准：多轮 agent OPSD 失败是多重因素叠加
  • 方法简单可插拔：只需两个上下文前向 + token-level gate
  • 对 retrieval 质量不敏感，Random retrieval 仍有收益

局限

  • 依赖 skill library，系统性偏差强时 gate 无法创造正确知识
  • 训练需额外 teacher-context forward pass
  • 仅在 ALFWorld/Search-QA/WebShop 验证

定位：首次把 OPSD 安全接入多轮 agent RL 的工作，核心创新是 token-level detached sigmoid gate。
