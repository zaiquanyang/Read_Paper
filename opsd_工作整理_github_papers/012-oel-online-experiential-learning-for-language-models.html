OEL: Online Experiential Learning for Language Models

arXiv 2603.16856GitHub
OEL PDF Code Microsoft Research · arXiv 2603.16856
核心思想：在真实部署后将文本交互经验提炼为可迁移知识，再用 OPCD 风格的 on-policy context distillation 将知识压进模型权重，实现 reward-free 的在线持续学习闭环。

方法

  • 两阶段闭环：先从交互轨迹中提取 experiential knowledge，再用 OPCD 做 on-policy RKL 蒸馏内化
  • 经验提取器将 trajectory 压缩成可迁移规则/策略（非原始轨迹），token efficiency 更高
  • 整个流程 reward-free，不需要 server 访问原始 user environment

优点与局限

优点

  • 问题设置现实：不要求 reward、不要求人标、不要求 server 访问用户环境
  • 经验提炼视角强：不是记忆原始轨迹而是抽象成可迁移知识
  • 闭环完整：部署→经验回流→知识提炼→参数内化→再部署

局限

  • 实验环境较简单（Frozen Lake、Sokoban）
  • 知识质量依赖 extractor，可能累积偏差
  • Online loop 可能引入自我强化偏差

定位：将 OPD/OPCD 作为核心 consolidation engine，支撑 reward-free 在线自我改进系统的框架性工作。
