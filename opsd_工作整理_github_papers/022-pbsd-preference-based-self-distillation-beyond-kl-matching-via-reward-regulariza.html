PBSD: Preference-Based Self-Distillation beyond KL Matching via Reward Regularization

arXiv 2605.05040
PBSD PDF arXiv 2605.05040
核心思想：把 self-distillation 从纯 KL matching 提升到 reward-regularized 目标——student 不应照抄 teacher，而应学习 teacher 分布按 latent reward 指数重加权后的 reward-tilted distribution，用 DPO 风格 pairwise preference objective 近似优化。

实验结果

OPSD 早早到峰值后退化，PBSD 更稳定持续提升。1.7B 收益最完整。

优点与局限

优点

  • 观点很强：teacher 不是 oracle，不该被完整复制
  • 理论与算法衔接自然：reward-regularized optimum → preference-margin → DPO-style
  • Tool-use 结果证明不只在 math 上 work

局限

  • 仍依赖 privileged context，若上下文很弱收益受限
  • latent reward 不可直接观测
  • 最大只验证到 8B

定位：对 OPSD 的直接升级，把 self-distillation 从 imitation-style 推向 reward-aware self-improvement。
