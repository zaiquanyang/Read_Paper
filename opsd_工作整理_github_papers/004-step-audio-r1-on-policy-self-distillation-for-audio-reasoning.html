Step-Audio-R1: On-Policy Self-Distillation for Audio Reasoning

arXiv 2511.15848GitHub
Step-Audio-R1 PDF Code StepFun · arXiv 2511.15848
核心思想：将 on-policy self-distillation 应用于音频推理任务，通过迭代 self-distillation + SFT + PPO/RLVR 混合管线提升多模态音频推理能力。仅使用模态相关问题做 self-distill 更有效。

优点与局限

优点

  • 将 OPSD 拓展到多模态（音频）推理场景
  • 模态特定数据筛选策略有效
  • 有开源代码和模型

局限

  • 音频模态的 privileged context 设计细节未充分展开
  • 与纯文本 OPSD 的差异分析不足

定位：多模态（音频）OPSD 的代表工作，展示了 self-distillation 范式在非文本模态上的可行性。
