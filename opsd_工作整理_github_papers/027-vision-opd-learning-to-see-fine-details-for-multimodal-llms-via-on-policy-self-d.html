Vision-OPD: Learning to See Fine Details for Multimodal LLMs via On-Policy Self-Distillation

Vision-OPD arXiv abs PDF arXiv 2605.18740
核心思想：把同一个 MLLM 的"区域裁剪视角"当特权教师、"全图视角"当学生，在 on-policy 轨迹上做 token-level 分布对齐，将"测试时缩放看细节"的收益内化进单次前向推理。

方法

  • 构建三元组数据（全图+红框/裁剪放大图/细粒度问题），约 6.2K 条训练数据
  • 教师：裁剪图条件；学生：全图条件，同一 MLLM
  • EMA teacher 正则（α=0.05）、JSD 散度（β=0.5）、Top-K logits distillation（K=100）
  • 推理时只需单次前向，无需多步工具调用

优点与局限

优点

  • 创新地把"视觉条件差异"作为特权教师构造方式
  • 不增加推理时代理复杂度
  • 训练数据量小（6.2K），性价比高

局限

  • 区域提议偏差会污染监督
  • 验证集中在细粒度视觉问答
  • 未报告详细 benchmark 对比分数

定位：首次将 OPSD 范式引入多模态 LLM 细粒度视觉理解，用"输入条件更清晰的同模态视角"当 teacher。
