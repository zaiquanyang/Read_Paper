OPSD: Self-Distilled Reasoner — On-Policy Self-Distillation for Large Language Models

OPSD arXiv abs PDF Code arXiv 2601.18734
核心思想：让同一个 LLM 同时充当 student（只看问题）和 teacher（额外看 ground-truth reasoning trace），在 student 自己采样的 rollout 上做逐 token 分布对齐。核心假设：rationalization is easier than generation。

方法

  • Student 只看问题 $x$，teacher 额外看到 ground-truth solution $y^*$，参数共享但上下文不同
  • 主目标：full-vocabulary forward KL 蒸馏在 student rollout 上
  • Pointwise KL clipping：限制极端 divergence 项的影响，防止 style token 吞没数学 token 监督
  • 最优配置：student thinking mode off + teacher thinking mode on

实验结果

小模型收益最大（1.7B 提升 ~6pp）。Token efficiency：OPSD 每题 1 rollout×1024 tokens×100 steps vs GRPO 8 条×16k×500 steps。

消融要点

  • Divergence 目标：Forward KL >> Reverse KL, JSD
  • Full-vocabulary vs sampled-token：全词表蒸馏显著更优（AIME25 84.1 vs 82.1）
  • Generation length：1024 vs 4096 差异不大，前期 token 监督价值更高

优点与局限

优点

  • 设定干净：只利用 ground-truth solution 作为 privileged information
  • Token efficiency 显著高于 GRPO
  • 对小模型尤其有效：1.7B 上提升 ~6pp

局限

  • 只验证到 8B 规模，更大模型上未验证
  • 依赖 ground-truth solution，无高质量 reference 时不适用
  • 尚未引入显式 correctness verification

定位：OPSD 方向的核心代表作，在 SFT 和 RL 之间找到平衡——兼具 on-policy 真实性与 dense supervision，且不依赖外部大 teacher。
