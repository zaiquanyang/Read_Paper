Skill-SD: Skill-Conditioned Self-Distillation for Multi-Turn LLM Agents

Skill-SD arXiv abs PDF arXiv 2604.10674
核心思想：把智能体轨迹中总结出的自然语言 skills 只给教师看、不给学生看，通过重要性加权逆 KL 的 on-policy 自蒸馏将 skill 内化到学生，将 OPD 从"固定答案蒸馏"推进到"动态 skill 蒸馏"。

方法

  • 从历史轨迹中用外部 LLM 总结出 skills（success_analysis + mistake_analysis + golden_workflow）
  • 推导了 importance-weighted reverse-KL 估计器，修正跨 prompt 自蒸馏的梯度偏差
  • 训练目标 = GRPO（任务级 credit）+ λ·SDL（token 级塑形）
  • 学生始终在 plain prompt 下 on-policy rollout，推理时无需依赖 skill 检索

实验结果

BenchmarkVanilla GRPOSkill-Augmented GRPOSkill-SD
AppWorld50.9%42.1%64.9% (+14.0%)
Sokoban51.6%20.3%62.5% (+10.9%)

Skill-Augmented GRPO 反而变差——证明 skill 不应直接给 student。教师拥有的 rollout 在 Sokoban 上几乎完全崩溃（10.9%），证明 on-policy rollout 不可放松。

优点与局限

优点

  • 将 OPD 从"固定答案蒸馏"扩展到"动态 skill 蒸馏"
  • 重要性加权逆 KL 推导是跨 prompt 自蒸馏的核心贡献
  • 清晰证明 skills 应作为 training-only 特权信息

局限

  • 仅 AppWorld 和 Sokoban 两个基准
  • Skill 总结依赖外部 LLM API
  • 仅在单一模型尺度（4B）验证

定位：将 OPD 从单步/单答案问题扩展到多轮多路径智能体任务的关键工作。
