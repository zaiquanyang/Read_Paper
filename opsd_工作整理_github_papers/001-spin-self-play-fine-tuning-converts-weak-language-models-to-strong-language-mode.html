SPIN: Self-Play Fine-Tuning Converts Weak Language Models to Strong Language Models

arXiv 2401.01335GitHub
SPIN PDF Code UCLA · arXiv 2401.01335
核心思想：使用 self-play 范式让弱模型与自己的前一版本竞争，通过 DPO 偏好优化迭代提升模型能力——"与昨天的自己竞争"。

方法要点

  • 当前模型生成回答，前一 frozen checkpoint 生成回答作为"弱"对手
  • 使用 DPO 让学生偏好自己的当前输出而非前一 checkpoint 的输出
  • 迭代进行：每次更新后前一 checkpoint 滚动更新

优点与局限

优点

  • 无需外部 teacher，迭代 self-play 可持续提升
  • 与 DPO 天然兼容，实现简单

局限

  • 更准确说是"iterative on-policy DPO"，非严格 per-token logit 蒸馏
  • supervision 是 sequence-level DPO preference

定位：Self-play + DPO 范式的代表作，属于 OPSD 谱系中的"迭代自竞争"分支。
