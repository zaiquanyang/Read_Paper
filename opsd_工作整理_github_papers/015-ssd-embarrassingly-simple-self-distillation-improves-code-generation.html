SSD: Embarrassingly Simple Self-Distillation Improves Code Generation

SSD arXiv abs PDF Code Apple MLR · arXiv 2604.01193
核心思想：通过训练时温度与截断配置系统性改写目标分布，使普通交叉熵训练也能诱导非平凡自我提升——压缩无用 tail、保留有价值的 head 探索。方法极简：无验证器、无 RL、无教师、无正确性过滤。

方法

  • 用训练时解码配置 $(T_{\text{train}}, \rho_{\text{train}})$ 从冻结基础模型采样，不做执行验证
  • 理论分解：support compression（压低外部尾部概率）+ within-support reshaping（保留头内有效探索）
  • 有效温度 $T_{\text{eff}} = T_{\text{train}} \cdot T_{\text{eval}}$，最佳工作带约在 1.2 附近

实验结果

ModelBaseSSDChange
Qwen3-30B-Instruct LCBv642.4%55.3%+12.9pp
Qwen3-4B-Instruct—+7.5pp—

提升主要集中在中等/困难问题。即使 62% 输出无法提取代码的高温数据仍能带来提升。单纯调温度的解码扫描 vs SSD 差 11.8pp。

优点与局限

优点

  • 方法极简但收益硬（+12.9pp on 30B）
  • 提供完整机制叙事：lock/fork、支持压缩、有效温度
  • 是 OPD/self-distillation 的重要低复杂度对照基线

局限

  • 适用性高度依赖代码任务的 lock/fork 结构
  • 需要仔细调节训练/推理解码超参数
  • 与 OPD 联系是"邻近机制"而非同一算法族

定位：无 reward 自提升的机制型论文，适合作为复杂 RL 方法的低复杂度对照基线。
