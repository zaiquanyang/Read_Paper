CRISP: On-Policy Self-Distillation for Reasoning Compression

arXiv 2603.05433GitHub
CRISP PDF Code LinkedIn · arXiv 2603.05433
核心思想：给教师添加 "be concise" 指令作为 privileged context，再用 on-policy RKL 蒸馏让学生学会在无显式指令时也产生简洁推理链，压缩推理长度而不导致 entropy collapse。

优点与局限

优点

  • "通过指令蒸馏压缩推理"可推广到控制输出长度场景
  • 有效区分了 self-distillation 与 RL 长度惩罚在 entropy collapse 上的差异
  • 方法简洁实用，有公开代码

局限

  • 缺少具体压缩率数值和 benchmark 结果
  • 压缩效果的跨任务泛化性待验证

定位：推理链压缩场景下的 on-policy self-distillation，避免了 RL 长度惩罚的 entropy collapse 问题。
