SD-Zero: Self-Revision Turns Binary Rewards into Dense Supervision

arXiv 2604.12002
SD-Zero PDF Princeton / Toronto / CMU · arXiv 2604.12002
核心思想：使用单一模型扮演 Generator 和 Reviser 双角色，Reviser 接收 Generator 的回答 + 二值奖励作为条件，通过自我修正将稀疏二值奖励转化为密集 token 级监督。

方法

  • Generator 生成初始回答，Reviser 接收回答 + 二值奖励作为条件生成修正版
  • 通过逐 token KL 蒸馏从 Reviser 到 Generator
  • 特权上下文是非文本的：Generator 完整回答 + 标量二值奖励

优点与局限

优点

  • "二值奖励 → 密集监督"的优雅转化
  • 在 Qwen3-4B / OLMo-3-7B 上比基础模型提升 ≥10%
  • 优于 RFT、GRPO、SDFT（匹配样本预算下）

局限

  • 仍需要可验证的二值奖励信号
  • Generator-Reviser 共同进化的稳定性待深入分析

定位：将自我修正作为桥接稀疏奖励与密集监督的机制，是 OPSD 中"非文本特权上下文"的代表。
