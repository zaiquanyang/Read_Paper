TRACE: Distilling Where It Matters via Token-Routed Self On-Policy Alignment

TRACE arXiv abs PDF arXiv 2605.10194
核心思想：只在真正关键的 reasoning span（≤25% token）上蒸馏，对不同类型 span 用不同 KL 方向（FKL/RKL/无），且 privileged KL 通道在短暂 warm-up 后衰减为 0，避免全 token 蒸馏的伤害。

方法

  • Span Annotator 标出关键 span（key spans / error spans），覆盖率 ≤25%
  • Key spans 用 FKL，error spans 用 RKL；KL 权重快速 decay 到 0
  • 剩余 token 走 GRPO，span token 在 KL 衰减后也交还给 GRPO

优点与局限

优点

  • 把 self-OPD 问题从"teacher 好不好"转成"蒸馏粒度对不对"
  • FKL/RKL 路由有机制解释：under-allocation 用 FKL，confident-wrong 用 RKL
  • Privileged leakage 控制成显式设计目标

局限

  • 依赖 annotator 的 span 定位质量
  • 目前主要验证在 math RLVR
  • Coarse type taxonomy 仍是人工设计

定位：把 self-distillation 失败重新解释为 supervision granularity / divergence direction / privileged exposure 三重 mismatch。
