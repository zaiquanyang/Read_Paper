SCOPE: Signal-Calibrated On-Policy Distillation Enhancement with Dual-Path Adaptive Weighting

SCOPE arXiv abs PDF Code arXiv 2604.10688
核心思想：OPD 最大的问题是把所有 rollout 的监督信号当成同等可信。SCOPE 按 trajectory correctness 分流——错误轨迹用 teacher PPL 加权（teacher 越自信越值得学），正确轨迹用 student PPL 加权（student 越不确定的正确路径越值得强化），实现 trajectory-level signal calibration。

问题与动机

  • Pass@k paradox：现有 OPD/RL 方法提升 Pass@1 却降低 Pass@k——概率质量被压缩到少数路径，牺牲多样性。
  • Flawed prefix trap：teacher 在 student 的错误 prefix 上也会被拖偏，高 teacher PPL 的错误前缀 recovery rate 显著更低。
  • 核心问题："哪些 trajectory 值得教、值得教多少"。

方法：Dual-Path Adaptive Weighting (DPAW)

  • Correctness 分流：rollout 按 verifier 分成正确组 $\Omega_c$ 和错误组 $\Omega_w$。
  • 错误轨迹 (teacher-guided)：走标准 OPD surrogate，用 teacher PPL inverse 加权——teacher 越自信，纠错信号越可信。
  • 正确轨迹 (student-guided)：改用 MLE self-reinforcement，用 student PPL 加权——student 越不确定的正确路径越值得强化。

消融要点

  • 去掉 DPAW：Avg@32 42.7 → 39.9，uniform weighting 问题复现。
  • 去掉 student-guided weight：Pass@32 77.9 → 74.1——正确路径保 diversity 有价值。

优点与局限

优点

  • 精准拆穿 "uniform supervision" 假设，问题定义强
  • 正误路径用相反 PPL 逻辑，直觉自然且有实验支撑
  • 同时提升 Avg@32 和 Pass@32

局限

  • 依赖 verifier 分流，更适用于数学/代码等 objective task
  • 多 rollout + teacher scoring 开销大（641.9s vs OPD 227.5s）
  • 未直接处理 token-level teacher uncertainty

定位：trajectory-level signal routing for OPD。与 EOPD（token-level KL routing）、LSM（token-level supervision granularity）互补。

EOPD: Entropy-Aware On-Policy Distillation of Language Models

EOPD arXiv abs PDF Code KAIST / IBM / Toronto / Vector · arXiv 2603.07079
核心思想：标准 OPD 用统一的 reverse KL 处理所有 token，但在 teacher 高熵 token 上 RKL 会 mode-seeking 过头，压塌多样性和学习稳定性。EOPD 在低熵 token 继续用 RKL，在高熵 token 额外加 forward KL，实现 entropy-aware 的 KL routing。

问题与动机

  • Diversity degradation：teacher 高熵 token 占 18.5%，student 经 OPD 后只剩 6.8%。
  • Reward instability：高熵 teacher 区域 RKL reward 不稳定，student top-1 频繁变化。

方法：Entropy-Aware RKL/FKL Routing

  • Token-level 目标：$\mathcal{L}_t^{\text{EOPD}} = \mathcal{L}_t^{\text{OPD}} + \alpha \cdot \mathbb{I}[H_t^{\text{te}} > \tau]\, \mathcal{L}^{\text{FKL}}_t$
  • 低熵 token：teacher 很确定 → 只用 RKL，精确模仿主模态
  • 高熵 token：teacher 保留多 plausible continuation → 额外加 FKL，传递"有结构的不确定性"
  • FKL 只在 teacher top-k (k=16) token 上近似，额外开销仅 ~4.5%

消融要点

  • Random FKL：随机选 20% token 加 FKL 明显不如 EOPD——"加在哪些 token 上"很关键。
  • Full FKL：低熵 token 加 FKL 反而干扰 RKL，不如 selective。
  • Entropy Bonus ≠ EOPD：只鼓励高熵不等于更像 teacher，FKL 传递的是结构化不确定性。

优点与局限

优点

  • 改动极小（OPD + selective FKL），逻辑干净
  • 额外开销仅 ~4.5%，selective FKL 显存省 7.4x
  • Pass@k 提升明显，尤其对更强 student 更有效

局限

  • 基于阈值 $\tau$ 的 hard routing，非完全自适应
  • 主实验在 math reasoning，泛化待验证
  • 只解决 token-level uncertainty，不涉及 trajectory-level credit

定位：token-level entropy-aware KL routing for OPD。与 SCOPE（trajectory-level signal calibration）、LSM（token-level supervision granularity）互补。

Revisiting On-Policy Distillation: Empirical Failure Modes and Simple Fixes

LSM arXiv abs PDF arXiv 2603.25562
核心思想：系统诊断 sampled-token OPD 的三个 failure mode（信号不均衡、teacher prefix drift 后不可靠、tokenizer mismatch），提出 teacher top-K local support matching：在 teacher top-K candidate set 上做 truncated reverse-KL + renormalization，配合 top-p rollout。Multi-task 下 reasoning average 相对 sampled-token OPD +19.8%。

三个 Failure Mode

  • FM1 — 信号不均衡：sampled token 大多落在 teacher prob < student prob 区域，训练信号大量为负。
  • FM2 — Teacher prefix drift：student 生成退化 prefix 时，teacher 局部概率仍可能对齐，甚至奖励重复 token。
  • FM3 — Tokenizer mismatch：不同 tokenizer 切分不同，exact token comparison 产生假负样本。

方法：Teacher Top-K Local Support Matching

  • 在 teacher top-K（K=32）token set 上做 truncated reverse-KL，替代 sampled-token 单点 log-ratio。
  • Support renormalization：截断后 teacher/student 概率质量不匹配，必须分别归一化。
  • Top-p rollout (p=0.9)：限制 rollout 在 typical 区域，减轻 prefix drift。
  • LSM 本身对 tokenizer mismatch 更鲁棒（w/ mask 与 w/o mask 差别很小）。

实验结果

Single-task math 上 LSM 也将 average 从 36.4 提到 41.7（+14.6%），且 w/ mask 与 w/o mask 差别很小，说明 LSM 对 tokenizer mismatch 更鲁棒。

消融要点

  • Renormalization 必须做：不做会快速 collapse。
  • Top-p 必须配合 top-K：teacher top-K 单独用并不好，先 top-p 保持 typical prefix，LSM 才更稳。

优点与局限

优点

  • Failure mode 诊断系统，对理解 OPD 很有价值
  • LSM 在 full-vocab KL 与 sampled-token 之间找到实用折中
  • Multi-task（agentic + reasoning）是真实的困难场景

局限

  • Truncated objective 仍有偏，top-K 外 token 无梯度
  • Teacher matching ≠ task success，off-distribution prefix 仍可能偏
  • 与 teacher 性能差距仍大（56.0 vs 41.7）

定位：改 token-level supervision 的 granularity：从 point-wise sampled token 升级到 top-K support 上的 truncated distribution matching。与 EOPD（改 KL 方向）、SCOPE（改 trajectory weighting）互补。

HDPO: Hybrid Distillation Policy Optimization via Privileged Self-Distillation

HDPO arXiv abs PDF arXiv 2603.23871
核心思想：RL 训练中的 cliff prompts（所有 rollout 都失败、梯度为零）形成学习死区。HDPO 不回避 cliff，而是让同一个模型在 privileged context（附加 ground truth）下生成 teacher 轨迹，筛选正确样本后用 JSD 蒸馏给 student——直接给 RL 无梯度区域补学习信号，同时揭示 coverage 与 greedy accuracy 之间可调的权衡。

问题与动机

  • Cliff prompts 问题：某个 prompt 上所有 rollout 都失败 → reward 全为 0 → advantage 无方差 → 梯度消失。最难、最需要学习的样本反而拿不到训练信号。
  • 已有解法（curriculum / hint / replay / PRM / RL+SFT 交替）普遍需要额外模块或调度器，工程复杂度高。
  • 核心问题："RL 在 cliff prompts 上零梯度时，能否不依赖外部教师模型，仍给模型可靠的学习信号？"

从 OPD 角度看，HDPO 是一种 on-policy distillation for failure regions——distill 对象是 cliff prompts，teacher 是 privileged version of self，蒸馏目标是给 RL 无梯度区域补信号，损失函数用 JSD 做更偏 mode covering。

方法：Privileged Self-Distillation

  • Step 1 — 标准 GRPO rollout：student 看原始题目 $x$，正常采样并更新 $\mathcal{L}_{\mathrm{GRPO}}$。
  • Step 2 — 定位 cliff prompts：所有 rollout 都失败的 prompt 集合 $\mathcal{C}$。
  • Step 3 — Privileged teacher 采样：对每个 $x \in \mathcal{C}$，将 ground truth $y^*$ 拼入输入，让同一模型生成 teacher rollout，只保留正确轨迹 $\mathcal{T}$。
  • Step 4 — JSD 蒸馏：在 teacher 正确轨迹上计算 token-level JSD，作为辅助损失。

联合目标：

\[ \mathcal{L}_{\mathrm{HDPO}}(\theta) = \mathcal{L}_{\mathrm{GRPO}}(\theta) + \lambda \cdot \mathcal{L}_{\mathrm{JSD}}(\theta) \]

选 JSD 而非 KL 的动机是 mode covering——扩大对多种正确策略的覆盖，提升 pass@$k$。teacher 和 student 共享参数，差别仅在输入是否含 privileged information，realizability gap 更小。

实验结果

基座 Qwen2.5-Math-1.5B-Instruct，数据集 OpenMathInstruct-2，GRPO $G=16$，2000 步。

Methodpass@1pass@4pass@8

  • 低 $\lambda$：coverage 提升但 greedy accuracy 基本不掉（drifting $\lambda\!=\!0.01$：pass@4 +1.1%，pass@1 持平）。
  • 高 $\lambda$：pass@8 显著提升但 pass@1 下降约 2–3%——exploration-exploitation 权衡。
  • Drifting teacher 在低 $\lambda$ 下更好（realizability gap 更小），frozen teacher 在高 $\lambda$ 下提供更多 signal diversity。

优点与局限

优点

  • 精准命中 RL 的零梯度死区，问题定义准确
  • 无需额外 teacher model / replay buffer / PRM / 多阶段切换
  • same-model privileged distillation 设定干净，理论可解释
  • 明确展示 coverage vs. greedy accuracy 的可控权衡

局限

  • 依赖 ground truth 作为 privileged information，仅适用可判定答案任务
  • 实验规模窄：1.5B 模型、1 个数据集、1 类任务
  • 覆盖提升幅度不算大，对 run-to-run variance 敏感
  • 额外计算开销真实存在（privileged generation + JSD 计算）

定位：针对 RL failure region 的 privileged self-distillation。与 SCOPE（trajectory-level signal routing）、EOPD（token-level KL routing）、LSM（token-level supervision granularity）互补。启发：teacher 不必更强只需信息更全；JSD 适合 coverage-oriented distillation；"expand then sharpen"两阶段训练值得跟进。

TSD-KD: Explain in Your Own Words — Token-Selective Dual Knowledge Distillation

TSD-KD ICLR 2026 arXiv abs PDF Code arXiv 2603.13260
核心思想：更细粒度、更 student-centric 的 OPD 变体。不要求 student 在每个 token 上模仿 teacher，而是只在关键 token 上施加监督，拆成 间接偏好蒸馏（teacher 只做 ranking）+ 直接 selective KD（entropy gap gating）+ selective entropy regularization 三部分。Reasoning 任务上多次实现 student 超越 teacher。

问题与动机

  • 全 token 监督过重：标准 OPD/GKD 在 student 生成的每个 token 上都做 KL/JSD 对齐，小模型 capacity 不够，被 teacher 完整分布压住，学不会"用自己的方式"推理。
  • 不是所有 token 同等重要：reasoning 里关键分叉点集中在较早的 token，对 student 最有帮助的不是处处模仿 teacher，而是在困难 token 上获得恰到好处的引导。
  • 核心判断："对 reasoning student 来说，最好的 teacher 不是时时刻刻都在讲话的 teacher，而是在关键分叉点给一点点高价值提示的 teacher。"

从 OPD 角度看，它是 OPD + selective KD + preference-style weak supervision，而非 RL-style OPD。仍用 on-policy 数据和蒸馏损失，但 token 选择基于 entropy gap，间接监督借 preference modeling 形式。

方法：Token-Selective Dual KD

  • 1. 间接蒸馏（Indirect）：student 提出 top-$k$ 候选 token，teacher 只做 preference ranking（Plackett-Luce），不暴露自身完整分布。保留 student 自主表达空间。
  • 2. Opener 机制：高熵 token 集中在 reasoning trace 前部。从序列开头累计 entropy，当前缀累计熵达总熵的 $c\%$（默认 10%）时停下，间接蒸馏只作用于这段 opener。
  • 3. 直接蒸馏（Direct）：entropy gap soft gating——student 高熵 + teacher 低熵时加大蒸馏权重，student 自信时弱化蒸馏。
  • 4. Selective entropy minimization：只在 top-10% 高熵 token 上做 entropy regularization，防止关键 reasoning step 犹豫，又避免过度自信。

  • MATH 上 student 超 teacher：teacher 21.7，TSD-KD student 做到 26.1（+20.3%）。
  • SciQ：student 甚至超过 teacher（86.4 → 93.0）。

消融要点

  • 三个组件都有效：从 GKD baseline 逐步加 selective gating → indirect distillation → entropy minimization，MATH 从 18.1 提到 26.1。
  • Opener 比例 $c=10\%$ 最优：$c=100\%$ 退化为全序列蒸馏，效果反而更差——直接证据表明全 token OPD 不是最优。
  • Top-$k=10$ 最优：候选太多把 teacher 弱监督变噪声。
  • Selective entropy min 也必须 selective：对所有 token 都做会过度自信。

优点与局限

优点

  • 清楚指出 OPD 里"不是所有 token 都值得 teacher 介入"
  • 间接蒸馏设计聪明——teacher 只做 ranking，不强灌 full distribution
  • reasoning 任务极强，多次 student 超 teacher
  • 跨模型家族有效，PEFT 下也成立

局限

  • indirect distillation 需 teacher 逐 token rerank top-$k$ 候选，推理成本不低
  • 仅验证 reasoning/instruction/code 场景，开放式生成是否有效未知
  • student 超 teacher 有 benchmark contamination 潜在疑问，未深挖
  • 不是 RL-style OPD，不直接解决 rollout-level reward 问题

定位：token-selective + preference-style OPD。把 OPD 往更细粒度、更选择性、更偏 preference 的方向推进。与 SCOPE（trajectory-level routing）、EOPD（entropy-aware KL routing）、HDPO（privileged self-distillation for cliff prompts）互补。核心启发：(1) OPD 不一定要全 token 对齐；(2) 弱监督比强监督更适合小模型 reasoning；(3) 可拆成 sequence-level guidance（indirect）+ token-level correction（direct）。

TIP: Token Importance in On-Policy Distillation

TIP arXiv abs PDF arXiv 2604.14084
核心思想：OPD 里并非所有 rollout token 都值得蒸馏。只用 student entropy 选 token 会漏掉最危险的 Q3（自信但错误）token。TIP 将 uncertainty 和 teacher-student disagreement 融合为 Soft-OR 分数，只蒸馏高价值 token，50% 预算下性能全面超过 full-token OPD，显存下降约 47%。

问题与动机

  • Token 训练价值不均：传统 full-token OPD 对整条 student 轨迹每个 token 都做蒸馏，但大量 token 训练价值很低。
  • Entropy-only 的盲区：只按 student entropy 选 token 时，Q3（低熵但 teacher 强烈不同意）和 Q4（低熵且正确）无法区分——自信但错误的 token 被一起忽略。
  • 核心判断：token importance 必须同时考虑 uncertainty（student 知不知道自己不会）和 disagreement（teacher 觉不觉得 student 走偏了）。

方法：Soft-OR Token Selection

  • 四象限 taxonomy：按 student entropy $h_t$ 和 teacher-student KL divergence $\delta_t$ 将 token 分为 Q1（高熵+高分歧，最值得纠正）、Q2（高熵+低分歧）、Q3（低熵+高分歧，最危险）、Q4（低熵+低分歧，最不重要）。
  • Soft-OR scoring：$s_t = \hat{h}_t + \hat{\delta}_t - \hat{h}_t \hat{\delta}_t$，任一信号高即可把 token 选出，避免 Q3 被漏掉。
  • Top-$k$ selection：按 $s_t$ 取 top-$\lfloor\rho m\rfloor$ token 做蒸馏，$\rho$ 为保留比例。
  • 最终损失：只在选中 token 上做 KL distillation，$\hat{\delta}_t=0$ 时退化回 entropy-only。

Beyond Math — DeepPlanning (Agentic)

优点与局限

优点

  • Q1/Q2/Q3/Q4 分析框架清晰，uncertainty × disagreement 两个维度拆解 token importance
  • Soft-OR 公式简洁直觉强，entropy-only 退化保证兼容性
  • 50% 预算全面超过 full-token OPD，显存省 47%
  • Q3-only 在 agentic planning 上甚至超过 full OPD

局限

  • Soft-OR 需要实时计算 teacher-student KL，推理成本仍在
  • 主实验集中在 math reasoning，泛化到开放生成待验证
  • Q3 token 数量少、检测依赖 KL，低资源场景可能不稳定

定位：token-level importance scoring for OPD。与 EOPD（entropy-aware KL routing）、TSD-KD（token-selective dual KD）互补——TIP 关注"选哪些 token 蒸馏"，EOPD 关注"用什么 KL 蒸馏"，TSD-KD 关注"用什么形式监督"。Q3 correction 在 long-horizon/agentic 场景的启发值得后续跟进。
