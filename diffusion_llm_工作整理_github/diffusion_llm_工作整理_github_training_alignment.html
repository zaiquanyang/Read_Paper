GDSD: Reinforcement Learning as Guided Denoiser Self-Distillation for Diffusion Language Models

abs | pdf | GitHub | summary md

作者：Xiaohang Tang, Keyue Jiang, Che Liu, Qifang Zhao, Xiaoxiao Xu, Sangwoong Yoon, Ilija Bogunovic

机构：UCL, Alibaba Group, Imperial College London, UNIST, University of Basel

核心思想：GDSD 不再把 ELBO 当作可替代 likelihood 的 RL 中介，而是把 diffusion LLM 的 policy improvement 改写成 advantage-guided denoiser self-distillation。这样它绕开了 surrogate ratio 的系统偏差，也更贴近 diffusion 模型真正优化的去噪对象。

问题与动机

此前 dLLM 做 RL 时，常用套路是拿 ELBO 或 Monte Carlo proxy 近似 sequence likelihood，再沿用 PPO / GRPO 风格的 ratio correction。问题在于，这会把 ELBO gap 与 training-inference mismatch 一起放大，最后让 importance ratio 又偏又噪。

GDSD 的判断很直接：既然 surrogate ratio 本身就站不稳，不如不再围绕它修补，而是把 RL 目标直接落到去噪 teacher-student 对齐上。

方法与框架

作者从 reverse-KL regularized RL 目标出发，把最优策略改写成由 old policy、reference policy 与 advantage 共同诱导的 guided teacher。关键变化不是换个 clipping，而是把 sequence-level policy improvement 转成 denoiser-level matching。

  • 一致 corruption 条件：当前模型、旧模型与 reference 模型在相同前向噪声下比较。
  • guided teacher：student 不再拟合 noisy ratio，而是蒸馏一个带 advantage 偏置的去噪 teacher。
  • normalization-free distillation：实现上用 squared-logit 形式，避免再次退回 softmax ratio 的高噪空间。

这也是它和很多 ELBO-based 方法最本质的区别：优化接口变了，所以它能同时绕开 TIM 与 surrogate bias。

实验与结论

论文在 LLaDA-8B 与 Dream-7B 上测试 planning、math、coding。整体结论很一致：GDSD 在两类 dLLM 上都优于此前 ELBO-based 方法，其中 planning 收益最大，摘要里最高到 +19.6%。

观察结论
跨模型LLaDA-8B 与 Dream-7B 都稳定受益
跨任务planning / math / coding 普遍提升，不是只在单一 benchmark 生效
最强收益planning 最突出，符合长程 credit 更受益的直觉
训练动态reward 曲线更稳，后期退化更轻

这张图尤其能看出 planning 优势最明显，也最契合“guided denoising 更利于长程决策”的方法直觉。

作者还观察到 guidance coefficient \psi 不能太弱，否则 guided self-distillation 会退化成温和模仿；而 TLC 这类 calibration 组件则能继续减轻训练后期抖动。

价值、局限与启发

  • 价值：把 dLLM RL 的核心矛盾重新表述成“不要再把 ELBO 当 likelihood”。
  • 局限：方法仍然依赖 reward / advantage 质量，本质上没有离开 RL；主要论证也集中在 masked diffusion setting。
  • 启发：后续 diffusion RL 也许更该寻找与 denoiser 对齐的优化接口，而不是继续沿用 AR LLM 的 sequence-level update。
  • 验证边界：当前主要围绕 LLaDA、Dream 等代表性 dLLM，其他变体仍需更多实验支持。

Stabilizing Reinforcement Learning for Diffusion Language Models

abs | pdf | 代码 | summary md

作者：Jianyuan Zhong, Kaibo Wang, Ding Ding, Zijin Feng, Haoli Bai, Yang Xiang, Jiacheng Sun, Qiang Xu

机构：Huawei Foundation Model Department, CUHK, HKUST

核心思想：StableDRL 不再把重点放在“估一个更准的 surrogate likelihood ratio”上，而是直接稳定 noisy proxy ratio 进入梯度聚合器的几何方式。做法很克制：先对 proxy ratio 做无条件裁剪，再做组内 self-normalization，把更新限制在样本梯度的稳定凸组合里。

问题与动机

AR LLM 可以精确计算 importance ratio，但 masked diffusion LM 的序列似然不可 tractable，只能依赖 ELBO/Monte Carlo proxy。这个 proxy 一旦被指数化，就会把局部估计噪声放大成长尾权重，进一步触发 gradient spike 和 policy drift。

\[ \hat{\rho}(x)=\exp\left(\hat{\mathcal{L}}_\theta(x)-\hat{\mathcal{L}}_{\theta_{\text{old}}}(x)\right) \]

因此作者的诊断不是泛泛地说“方差大”，而是更具体地指出：noisy proxy ratio、conditional clipping 和 group-level 随机步长会一起形成 self-reinforcing instability loop。

方法与框架

作者先指出 dLLM 版 GRPO 的问题：负优势样本上的 conditional clipping 仍可能让极端 ratio 穿透 trust region，所以仅仅“有 clipping”还不够。

\[ \nabla_\theta\mathcal{J}_{\text{GRPO}} = \mathbb{E}\left[ \frac{1}{G}\sum_{j=1}^{G} \min\Big( \rho_{j} A_{j}, \text{clip}_\epsilon(\rho_{j}) A_{j} \Big) g_j \right] \]
  • Unconditional clipping：先把每个样本权重裁剪到对称区间，避免负优势分支绕过裁剪。
  • Self-normalization：再做组内归一化，去掉 \(\sum_j w_j\) 带来的随机 step-size scaling。
\[ w^j=\operatorname{clip}(\hat{\rho}^j,1-\epsilon,1+\epsilon),\qquad \alpha^j=\frac{w^j}{\sum_{k=1}^{G}w^k} \]

这张图最值得看的地方，不是“结果更高”，而是它清楚地解释了为什么 dLLM RL 会炸、为什么只是换 reward 不够、以及 StableDRL 为什么用两个小改动就能把训练几何拉回稳定区间。

实验与结论

在 LLaDA-8B-Instruct 上，StableDRL 在四类任务平均分都最好：GSM8K 84.2、MATH500 41.8、Countdown 83.5、Sudoku 91.5。它的优势不只是单点峰值更高，而是在不同 decoding budget 下都更稳。

方法GSM8KMATH500CountdownSudoku
ESPO82.039.581.086.0
SPG w/ Mixture83.038.469.990.0
StableDRL84.241.883.591.5

作者还把方法扩展到 SDAR-8B-Chat。在 static setting 下，StableDRL 在 MATH500/GSM8K/AIME24 上达到 79.2/92.4/16.7，说明它不只适用于 full-attention LLaDA。不过目前主要验证仍集中在 LLaDA-8B-Instruct 与 SDAR-8B，对更多 dLLM 变体还需要进一步验证。

如果只留一张实验图，这张最关键。它直接把理论里的 noisy proxy ratio 假设变成了可观测现象，也解释了为什么 StableDRL 的提升不只是 benchmark 调参好运。

价值、局限与启发

  • 价值：把 dLLM RL instability 解释成 noisy proxy ratio 与 policy drift 的闭环，并用很简单的权重几何改造解决。
  • 局限：理论更偏解释性，不是严格收敛保证；收益来自稳定聚合几何，不会自动修正 proxy estimator 的系统偏差。
  • 验证边界：full-attention 主要围绕 LLaDA-8B-Instruct，block diffusion 主要围绕 SDAR-8B；其他 dLLM 架构、尺寸和采样器仍需要更多验证。
  • 启发：做 dLLM RL 时，先保证 noisy ratio 进入 optimizer 的方式稳定，往往比继续堆更复杂的 reward shaping 更重要。

Improving Sampling for Masked Diffusion Models via Information Gain

abs | pdf | 代码 | summary md

作者：Kaisen Yang, Jayden Teoh, Kaicheng Yang, Yitong Zhang, Alex Lamb

机构：Tsinghua University, Singapore Management University, Shanghai Jiao Tong University, Beihang University

核心思想：Info-Gain Sampler 认为 masked diffusion 的采样器不该只看“当前哪个位置最确定”，而应该看这一步解码会让后续整体不确定性下降多少。于是它把局部 greedy decoding 改成了面向未来的 information-gain 选择。

问题与动机

很多 masked diffusion sampler 都是两步贪心：先给每个 mask 位置采样候选 token，再按局部 confidence、entropy 或 margin 选出最确定的位置优先解码。这样的策略短视，容易优先处理“看起来简单”的 token，却忽略哪些决策更能减少后续整体搜索难度。

作者用单向乘法等 toy case 说明：有些 token 局部不确定性很低，但过早固定会把系统推进错误分支；真正更优的动作，应该优先解开对后续最有信息价值的位置。

方法与框架

Info-Gain Sampler 的核心不是改模型，而是改“选哪个位置先解码”。它先用模型分布为每个待解码位置生成候选，再估计如果当前释放该位置，接下来整个采样过程的累计不确定性会下降多少，把这个值当作信息增益分数。

  • 从局部置信度到全局收益：评分目标由“当前 token 最稳”换成“当前 token 是否最能帮后续去不确定”。
  • 兼容现有 masked diffusion 模型：不要求重训，只是在推理时多做一步 look-ahead 估计。
  • 更像 planning：它本质是在采样阶段引入短期前瞻，而不是把解码完全交给一步贪心启发式。

这篇论文最值得保留的不是复杂细节，而是这个视角转换：在 masked diffusion 里，位置选择本身就是 sequential decision problem。

实验与结论

论文在代码、推理与一般语言生成场景上比较了多种采样器。主结论不是“所有任务都大幅领先”，而是：当任务存在明显的长程依赖和先后解码耦合时，Info-Gain 的优势最稳定，因为它更擅长避免早期局部贪心带来的后续锁死。

  • 在 case study 中，Info-Gain 能明显避开“先解看似容易但信息价值低的 token”这一错误路径。
  • 在真实 benchmark 上，它相对纯 confidence / entropy 型采样器表现更稳，尤其适合结构约束强的生成任务。
  • 它的收益主要来自采样顺序优化，而不是模型参数变化，因此迁移成本较低。

如果后面还要继续整理这篇卡片，最值得补的一张图会是累积熵轨迹；但在当前页面里，这张 toy case 更容易让读者立刻理解方法直觉。

价值、局限与启发

  • 价值：把 masked diffusion sampling 从“局部置信度排序”提升到了“面向未来的信息价值排序”。
  • 局限：前瞻式评分会带来额外推理成本，收益大小也依赖任务是否真的存在强顺序耦合。
  • 启发：后续 diffusion 解码器可以继续引入 planning / value estimation 视角，而不是只在 confidence heuristic 上做微调。

Improving Variable-Length Generation in Diffusion Language Models via Length Regularization

abs | pdf | summary md

作者：Zicong Cheng, Ruixuan Jia, Jia Li, Guo-Wei Yang, Meng-Hao Guo, Shi-Min Hu

机构：Tsinghua University, Proxseer Inc.

核心思想：这篇工作解决的是 diffusion LLM 最常见却也最尴尬的问题之一: 生成长度事先并不知道。作者提出 LR-DLLM，用一个带 \(\log L\) 校准项的长度置信度信号，在不重训模型的前提下做 variable-length generation。

问题与动机

固定长度 canvas 是 dLLM 很自然的生成形式，但它默认目标 span 长度已知。到了 infilling、continuation 或通用补全场景，这个前提经常不成立：mask 太短会欠生成，mask 太长又会让模型为了填满画布而重复、拖沓或产生无关后续。

作者指出更深一层的问题是：不同 mask length 下的 raw confidence 不能直接比较，因为长度本身就会系统性改变平均置信度。

方法与框架

LR-DLLM 的做法很克制：仍然使用原来的 diffusion LM，只是在推理时先评估多个候选长度，再根据“校准后的长度置信度”选出更合理的 span 长度。

\[ \mathrm{CL}(L)=\mathrm{AVG}_{\mathrm{conf}}(L)-k\log L \]
  • 长度偏置校准：作者观察到平均置信度随 mask length 变化更接近 \(\log L\) 而非线性关系，因此用 \(k\log L\) 去掉长度诱导偏置。
  • instance-specific probing：k 不是全局常数，而是按样本轻量估计，所以比固定 heuristic 更稳。
  • training-free：不改预训练、不加特殊终止 token，更适合直接叠到现有 dLLM 推理流程上。

这也是这篇论文比一般“长度搜索技巧”更值得记住的地方：它先解释了为什么 naive confidence 失真，再给出一个可落地的校准项。

实验与结论

实验主要覆盖 code infilling、code generation 与 math reasoning。总体趋势很清楚：当任务对生成长度敏感时，LR-DLLM 几乎总比 fixed-length baseline 更稳，且多数情况下比 DreamOn / FlexMDM 这类替代方案更强。

模型设置代表性结果
LLaDA-8BHumanEval-InfillingMean 从 23.4 提升到 36.7
Dream-7BHumanEval-InfillingMean 从 22.5 提升到 44.8
DreamCoder-7BHumanEval-InfillingMean 从 39.1 提升到 51.3

值得注意的是，它的收益并不是来自更复杂的模型结构，而是更合理地选择生成长度，因此尤其适合“我不想重训，只想让现有 dLLM 推理更聪明”的使用场景。

在页面里保留这一张消融图就够了，因为它正好对应方法中最关键、也最容易被忽视的那一步。

价值、局限与启发

  • 价值：给 dLLM 的 variable-length generation 提供了一条真正 training-free 的路径，特别适合 infilling / continuation 这种不知道该补多长的任务。
  • 局限：它通过 probing 与搜索换来更好的长度判断，因此 forward call 会增加，真实 wall-clock 成本不能忽略。
  • 启发：长度选择本身就是解码策略的一部分，未来可以与 cache reuse、稀疏解码、planner-style sampler 联动设计。

Consolidating Reinforcement Learning for Multimodal Discrete Diffusion Models

abs | pdf | 代码 | summary md

作者：Tianren Ma, Mu Zhang, Yibing Wang, Qixiang Ye

核心思想：MaskGRPO 想回答一个很实际的问题: AR LLM 已经能用 GRPO 做在线 RL，那么离散 diffusion model 能不能也有一套可计算、跨文本和视觉都能工作的 RL 接口？论文给出的答案是，把不可 tractable 的 DDM likelihood ratio 近似成 masked prediction loss 差值，再配合 modality-aware rollout 与 reversing 策略。

问题与动机

难点在于 DDM 不是按 token 自回归展开，而是在多个位置并行去 mask，所以传统 GRPO 里那套 token-level likelihood ratio 无法直接套用。与此同时，RL 又要求同一个 prompt 下采样多个 rollout 做 group-relative advantage，这对离散扩散模型的采样多样性与稳定性都提出了更高要求。

论文因此瞄准两件事：先把 importance estimation 做到“能算”，再把文本与视觉的 rollout 设计成真正适合各自模态结构的形式。

方法与框架

作者把 response corruption 写成 \(o^t\sim q(o^t\mid o,t)\)，再用同一 corrupted completion 上的 masked prediction loss 差来近似 policy ratio 变化。核心思想是：虽然 DDM 的完整 completion likelihood 难算，但在相同噪声状态下比较两个模型的 denoising loss，依然能给出可用的相对更新信号。

\[ \hat{\rho}_i^t=\exp\left(\ell_{\pi_\theta}(o_i^t,o_i\mid\mathbf{c})-\ell_{\pi_{\theta_{\mathrm{old}}}}(o_i^t,o_i\mid\mathbf{c})\right) \]
\[ \hat{\mathbb{D}}_{\mathrm{KL}}^{i,t}=\exp\left(\ell_{\pi_{\theta_{\mathrm{ref}}}}-\ell_{\pi_\theta}\right)-\left(\ell_{\pi_{\theta_{\mathrm{ref}}}}-\ell_{\pi_\theta}\right)-1 \]
  • 统一估计接口：importance ratio 与 KL penalty 都落到 masked prediction loss 差值上。
  • 文本策略：利用 AR-like fading-out reversing，让文本 rollout 更接近顺序展开的 reasoning 结构。
  • 视觉策略：用 high-mask random reversing 与 Token Emerge sampler，为高熵视觉 token 提供更强探索。

这张图比单独记公式更重要，因为它解释了为什么论文敢把“文本 + 图像”一起放进同一个 RL 框架里。

实验与结论

文本侧，作者在 LLaDA-8B-Instruct 上测试 GSM8K、MATH500、MBPP；视觉侧则在 MMaDA-8B-Base 上做图像偏好与对齐训练。核心结果是：MaskGRPO 在文本推理和代码上都明显优于 diffu-GRPO、UniGRPO、TraceRL 等基线，并把此前 RL 收益进一步拉大。

方法GSM8K 256MATH500 512MBPP 256
LLaDA-8B-Instruct76.736.239.0
TraceRL82.139.543.9
MaskGRPO84.241.545.4

这些结果说明收益不是来自简单的训练步数增加，而是 DDM 版 importance estimation 和 rollout 设计终于开始“对上模型结构”。视觉实验也支持同样结论，不过它更多体现为统一框架跨模态有效，而不是单一 unified model 一次性解决全部模态问题。

如果后面还要进一步精简本页，我会优先保留这张 reversing 图，因为它恰好体现了这篇工作最有辨识度的模态感知设计。

价值、局限与启发

  • 价值：给离散 diffusion model 提供了一套真正可计算的 GRPO 风格 RL 接口，并展示了文本与视觉可共用一个上层框架。
  • 局限：likelihood 近似本身仍有 bias；图像侧又依赖 reward model 组合，因此 reward hacking 与偏好偏置问题并没有彻底解决。
  • 启发：DDM 的 RL 不应机械照搬 AR LLM，也不该直接套 continuous diffusion 的做法，而要把 reversing / sampler 一起视作 policy optimization 的组成部分。
