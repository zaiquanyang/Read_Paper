背景与动机

LLaDA-o 关注的是一个很具体但重要的问题：能不能用 diffusion language model 做真正的 omni multimodal model，同时支持图文理解和图像生成？已有 diffusion LLM 主要证明了 masked diffusion 在文本建模上可行，而多模态统一模型通常有两条路线：一种是 AR unified model，把文本和图像都变成 token 后做 next-token prediction；另一种是 diffusion-based unified model，但很多方法会把图像也离散化，或把理解和生成揉进同一个 dense diffusion 目标里。

从上图可以看出，作者想让同一个模型同时完成三类能力：图像理解、根据复杂文本生成图像、以及和已有 omni diffusion 模型进行 case-by-case 对比。论文的关键判断是：文本和图像并不适合同一种 diffusion 动态。文本天然适合离散 token 上的 masked diffusion；图像生成则更适合连续 latent space 上的 continuous diffusion 或 rectified flow。如果强行使用一个统一 dense diffusion objective，容易出现目标不匹配、梯度干扰和训练不稳定。

这篇论文的第二个问题是长度适配。Masked diffusion text generation 在推理时经常需要预设生成长度或 block length，这对开放式多模态问答很别扭：OCR 只需要几个词，详细 caption 可能需要很长回答。已有 omni diffusion 模型往往固定理解输出长度，导致短任务过度生成、长任务生成不完整。LLaDA-o 的目标就是在不改架构的前提下，让输出长度由输入语义决定，而不是由预设 block size 决定。

方法与框架

LLaDA-o 的核心是 Mixture of Diffusion, MoD。它不是把所有模态塞进一个扩散专家，而是拆成两个 diffusion experts：

  • Understanding expert: 负责文本和视觉 encoder token，使用 masked diffusion。结构上包含 SigLIP vision encoder、两层 MLP projector 和 LLaDA-8B-Instruct language diffusion model。
  • Generation expert: 负责图像 latent token，使用 continuous diffusion / rectified flow。结构上包含冻结的 FLUX VAE 和 diffusion Transformer。
  • Shared attention backbone: 两个 expert 不是完全隔离的，它们共享 self-attention backbone，用来完成跨模态交互和条件注入。

这套设计的直觉很清楚：专家层面按模态选择最适合的扩散形式，注意力层面又保留统一模型的交互能力。因此它比“全离散化图像”更适合高质量生成，也比“单一 dense objective”更容易避免离散/连续目标之间的优化冲突。

实验与结论

模型初始化方面，understanding expert 使用 LLaDA-8B-Instruct 作为语言 diffusion backbone，vision encoder 使用 SigLIP，两层 MLP projector 随机初始化。Generation expert 使用与 LLaDA masked predictor 类似的 diffusion Transformer，并初始化自 LLaDA；时间 embedding 等额外条件参数随机初始化。图像 VAE 使用 FLUX 的 VAE，并在训练中冻结。

价值、局限与启发

这篇论文的主要贡献有三点。第一，它明确提出 text discrete diffusion 与 image continuous diffusion 不应被强行统一成同一种 token/目标，而应通过 MoD 做模态适配。第二，它用 shared attention backbone 保留了统一模型的跨模态交互，同时通过 intra-modality bidirectional attention 降低了推理冗余。第三，它提出 data-centric adaptive length augmentation，使 diffusion text generation 更适合开放式多模态回答。

局限也比较清楚。首先，LLaDA-o 的语言 backbone 仍弱于顶级 AR LLM，因此在 MMMU、MMBench 等综合理解指标上不能全面超过 BAGEL。其次，GenEval overall 仍低于 Lumina-DiMOO 和 Mogao，说明连续生成专家虽然提升了复杂 prompt 对齐，但空间关系、计数或整体 compositionality 仍有瓶颈。再次，训练成本很高，复现门槛大。最后，论文展示的 failure analysis 不多，对多轮图文交互、编辑一致性和安全性也没有系统展开。

对 diffusion_llm 方向来说，LLaDA-o 的启发是：未来 dLLM 做 multimodal 不必追求“所有东西都离散化”或“所有目标都一个 loss”。更可行的路线是让不同模态保留各自最有效的生成机制，再在 attention、conditioning、cache 和训练数据层面设计统一接口。换句话说，统一不一定发生在 token 空间，统一也可以发生在交互骨架和推理协议上。
