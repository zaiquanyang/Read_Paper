ELF: Embedded Language Flows

abs | pdf | 代码 | summary md

作者：Keya Hu, Linlu Qiu, Yiyang Lu, Hanhong Zhao, Tianhong Li, Yoon Kim, Jacob Andreas, Kaiming He

机构：MIT

一句话总结

ELF 是一篇把 continuous embedding space + continuous-time flow matching + final-step-only discretization 做得非常干净的 continuous DLM 论文。它真正有价值的地方，不只是“连续模型也能做语言”，而是它证明了：只要接口设计得对，连续 language flow 不但能复用图像 diffusion 社区的成熟技巧，还能在更少训练 token、更少采样步数下，和主流离散 DLM 正面竞争。

背景与动机

这篇论文想回答一个很关键、但过去几年一直没有被真正做透的问题：

连续空间的 diffusion / flow language model，究竟是“语言天然更适合离散 token diffusion”，还是“连续 DLM 之前只是设计得还不够好”？

作者的判断是，过去连续 DLM 表现不如离散 DLM，不一定是因为语言必须做离散扩散，而可能是因为连续 DLM 的接口设计还不够合理。过去常见问题有：

  • 连续 DLM 往往会在很多 step 上反复插入离散化目标，比如每步都加 token CE。
  • latent diffusion 路线常常需要单独 decoder，把连续 latent 再解码回 token。
  • 连续模型虽然理论上能借用图像 flow/diffusion 的很多成熟技术，但在语言里没有真正“连续到底”。

ELF 的核心主张很鲜明：

  • 把语言先映射到连续 embedding 空间。
  • 在几乎整个生成过程中都停留在这个连续空间里做 denoising / flow matching。
  • 只在最终时刻再把连续 embedding 映射回离散 token。

作者把它叫做 Embedded Language Flows，并强调它有两层“连续性”：

  • continuous embedding space
  • continuous time

这使它能更直接复用图像 flow matching / diffusion 社区里已经很成熟的东西，比如：

  • x-prediction
  • ODE / SDE 风格采样
  • classifier-free guidance (CFG)
  • training-time CFG

论文的目标不是做系统加速，而是做一种更“像现代图像 flow model”的语言生成模型。

论文没专门大篇幅写 limitation，但从方法上看，我觉得有几处需要留意：

  • 强依赖 embedding space 质量
  • ELF 的成功很依赖 pretrained contextual embedding。
  • 这意味着它不是“纯从语言数据端到端学出连续空间”，而是借了一个强先验。
  • 最终仍然要做离散化
  • ELF 只是把离散化延后到最后一步，不是完全摆脱 token space。
  • final-step decode 仍可能成为瓶颈或误差集中点。
  • Gen. PPL 不是标准 likelihood
  • 作者用 GPT-2 Large 打生成样本的 perplexity，这很常见，但也不是严格的模型似然。
  • 训练预算小，不代表所有资源维度都更省
  • token 预算更低很亮眼，但 encoder + flow model + long sequence 训练本身仍不轻。
  • conditional generation 规模仍偏小
  • WMT14 和 XSum 能说明方法成立，但离真正大规模 instruction / reasoning generation 还有距离。

LLaDA2.0-Uni: Unifying Multimodal Understanding and Generation with Diffusion Large Language Model

abs | pdf | summary md

一句话总结

LLaDA2.0-Uni 的核心贡献是把视觉变成语义离散 token，让文本和图像共享 dLLM 的 block-level masked diffusion 建模，再用 diffusion decoder 还原图像；它证明 diffusion LLM 可以成为统一多模态理解与生成的可行架构，并把真正的潜力指向 interleaved generation and reasoning。

背景与动机

多模态模型通常分成两条路线：

  • 理解模型：例如 Qwen-VL、InternVL，强在 VQA、OCR、文档、图表、推理。
  • 生成模型：例如 FLUX、Z-Image、Qwen-Image，强在 text-to-image 和 image editing。

统一模型的好处很诱人：部署更简单，理解和生成可以互相增强，还能自然支持“边看边想边画”的 interleaved generation and reasoning。但已有统一模型大多基于 autoregressive 架构，或者是文本 AR + 图像 diffusion 的混合架构。

dLLM / masked diffusion model 的优势是并行解码和双向上下文建模。问题在于，已有统一 masked diffusion 模型仍有几个短板：

  • reconstruction-based VQ tokenizer 主要保像素重建，不保语义，导致理解能力弱。
  • 过度压缩图像 token 会牺牲生成质量。
  • 完全双向 attention 对文本不稳定。
  • 一些模型假设固定输出长度，不适合开放式理解任务。

LLaDA2.0-Uni 的核心解法是：用 SigLIP-VQ 把图像离散成语义 token，用 16B MoE dLLM backbone 做统一 masked diffusion，再用 diffusion decoder 从语义视觉 token 还原高质量图像。

论文自己也指出了几个局限：

  • SigLIP-VQ 语义强，但细节保真不足，影响 detail-sensitive image editing。

另外，从结果看：

  • OCRBench、DocVQA 仍低于 Qwen2.5-VL-7B，说明理解侧的专用 OCR/document 能力还有差距。
  • 文本渲染虽然是 unified model 中强，但仍弱于 Qwen-Image、LongCat-Image 这种专用图像生成模型。
  • diffusion decoder 虽然快速蒸馏到 8 steps，但整体系统仍包含 dLLM denoising + image diffusion decoder，端到端部署复杂度不低。

背景与动机

LLaDA-o 关注的是一个很具体但重要的问题：能不能用 diffusion language model 做真正的 omni multimodal model，同时支持图文理解和图像生成？已有 diffusion LLM 主要证明了 masked diffusion 在文本建模上可行，而多模态统一模型通常有两条路线：一种是 AR unified model，把文本和图像都变成 token 后做 next-token prediction；另一种是 diffusion-based unified model，但很多方法会把图像也离散化，或把理解和生成揉进同一个 dense diffusion 目标里。

从上图可以看出，作者想让同一个模型同时完成三类能力：图像理解、根据复杂文本生成图像、以及和已有 omni diffusion 模型进行 case-by-case 对比。论文的关键判断是：文本和图像并不适合同一种 diffusion 动态。文本天然适合离散 token 上的 masked diffusion；图像生成则更适合连续 latent space 上的 continuous diffusion 或 rectified flow。如果强行使用一个统一 dense diffusion objective，容易出现目标不匹配、梯度干扰和训练不稳定。

这篇论文的第二个问题是长度适配。Masked diffusion text generation 在推理时经常需要预设生成长度或 block length，这对开放式多模态问答很别扭：OCR 只需要几个词，详细 caption 可能需要很长回答。已有 omni diffusion 模型往往固定理解输出长度，导致短任务过度生成、长任务生成不完整。LLaDA-o 的目标就是在不改架构的前提下，让输出长度由输入语义决定，而不是由预设 block size 决定。

方法与框架

LLaDA-o 的核心是 Mixture of Diffusion, MoD。它不是把所有模态塞进一个扩散专家，而是拆成两个 diffusion experts：

  • Understanding expert: 负责文本和视觉 encoder token，使用 masked diffusion。结构上包含 SigLIP vision encoder、两层 MLP projector 和 LLaDA-8B-Instruct language diffusion model。
  • Generation expert: 负责图像 latent token，使用 continuous diffusion / rectified flow。结构上包含冻结的 FLUX VAE 和 diffusion Transformer。
  • Shared attention backbone: 两个 expert 不是完全隔离的，它们共享 self-attention backbone，用来完成跨模态交互和条件注入。

这套设计的直觉很清楚：专家层面按模态选择最适合的扩散形式，注意力层面又保留统一模型的交互能力。因此它比“全离散化图像”更适合高质量生成，也比“单一 dense objective”更容易避免离散/连续目标之间的优化冲突。

实验与结论

价值、局限与启发

这篇论文的主要贡献有三点。第一，它明确提出 text discrete diffusion 与 image continuous diffusion 不应被强行统一成同一种 token/目标，而应通过 MoD 做模态适配。第二，它用 shared attention backbone 保留了统一模型的跨模态交互，同时通过 intra-modality bidirectional attention 降低了推理冗余。第三，它提出 data-centric adaptive length augmentation，使 diffusion text generation 更适合开放式多模态回答。

局限也比较清楚。首先，LLaDA-o 的语言 backbone 仍弱于顶级 AR LLM，因此在 MMMU、MMBench 等综合理解指标上不能全面超过 BAGEL。其次，GenEval overall 仍低于 Lumina-DiMOO 和 Mogao，说明连续生成专家虽然提升了复杂 prompt 对齐，但空间关系、计数或整体 compositionality 仍有瓶颈。再次，训练成本很高，复现门槛大。最后，论文展示的 failure analysis 不多，对多轮图文交互、编辑一致性和安全性也没有系统展开。

对 diffusion_llm 方向来说，LLaDA-o 的启发是：未来 dLLM 做 multimodal 不必追求“所有东西都离散化”或“所有目标都一个 loss”。更可行的路线是让不同模态保留各自最有效的生成机制，再在 attention、conditioning、cache 和训练数据层面设计统一接口。换句话说，统一不一定发生在 token 空间，统一也可以发生在交互骨架和推理协议上。

One Token Is Enough: Improving Diffusion Language Models with a Sink Token

abs | pdf | https://github.com/skywalker0523/OneTokenIsEnough | summary md

作者：Zihou Zhang, Zheyong Xie, Li Zhong, Haifeng Liu, Yao Hu, Shaosheng Cao

机构：Xiaohongshu.inc

一句话总结

这篇论文指出 DLM 中的 moving attention sink 本质上是一种低范数 token 吸收冗余 attention、缓解 information over-mixing 的保护机制，但其位置随 diffusion step 移动会带来不稳定；作者通过加入一个全局可见但只能 attend to itself 的额外 [SINK] token，把 moving sink 固定成 stable sink，在多个 DLM 训练设置和 benchmark 上获得稳定提升，并证明一个 token 基本就足够承担这个结构性 attention anchor 角色。

背景与动机

Diffusion Language Models (DLMs) 通过 bidirectional attention 和 iterative denoising 进行并行文本生成，是 autoregressive language models (ARLMs) 之外的一类重要语言建模范式。近期 LLaDA、Dream 等 DLM 已经在复杂生成任务上展现出竞争力，但 DLM 的 Transformer backbone 里存在一个被本文认为很关键的稳定性问题：moving attention sink。

Attention sink 指一些语义信息很弱的 token 吸收了不成比例的 attention mass。在 ARLM 中，causal mask 往往让初始 token 或 BOS token 成为稳定 sink，因此很多冗余 attention 可以被固定位置“吸收”。这在一些分析中被解释为一种防止深层 Transformer 过度信息混合的机制。

DLM 的问题在于：它没有 ARLM 中固定的 causal first token 结构，生成时又会不断改变被 mask 的位置。结果是 sink token 的位置会随 diffusion step 和 layer 变化，常常落在 [MASK] 或空白等低语义 token 上。这种 moving sink 虽然仍能作为“低信息吸收点”缓解 over-mixing，但它的位置不稳定，可能破坏推理鲁棒性和模型表现。

本文的核心问题是：能否给 DLM 显式加入一个固定、低信息、专门吸收冗余 attention 的 sink token，从而把 moving sink 变成 stable sink？

方法与框架

attention output 是多个 value vectors 的加权和。如果某个 token 的 value vector L2 norm 很小，那么大量 attention 指向它时，对 residual stream 的语义扰动也较小。因此，低范数 token 可以近似扮演 “no-op” attention target，让一些 head 在没有强语义匹配时把冗余 attention 分配出去，避免 token 表示被过度混合。

本文的方法非常直接：在 DLM 输入序列中额外加入一个 [SINK] token，并通过 attention mask 让它成为稳定 attention sink。

价值、局限与启发

  • 方法极简：只增加一个 token 和一个 attention mask 约束，不需要复杂 architecture 改造。
  • 机制解释清楚：从 value-space L2 norm 解释为什么 sink token 能近似 no-op，并缓解 information over-mixing。
  • 实验覆盖两种初始化方式：从 Qwen2.5 初始化转换 DLM，以及从 scratch 训练 DLM。
  • 对比了 gated attention，说明 extra sink token 在更大模型上比增加 gate 参数更稳定。
  • 消融实验比较完整：位置、数量、zero-value、attention allocation 都支持作者假设。

论文自己指出，实验只覆盖 0.5B 和 1.5B 规模，没有扩展到更大的 DLM。除此之外，还有几个需要注意的问题：

  • 主要是 pretraining/training-time 方法：需要在训练和推理时都加入 sink token，不能保证对已训练 DLM 直接 inference-only patch 就有效。
  • 虽然 benchmark 多，但都是小到中等规模模型，缺少 7B/8B 以上 DLM 的系统验证。
  • ARC-c、SIQA 等任务上存在局部下降，说明 stable sink 不是所有任务都无条件增益。
  • sink token 与不同 noise schedule、不同 sampling strategy、KV cache 优化之间的交互没有深入展开。
  • 论文没有充分分析为什么某些任务下降，也没有报告更细的训练稳定性曲线或方差。
  • DLM 的 attention sink 可能不是简单 pathology，而是模型防止 over-mixing 的必要机制；优化 DLM 时应区分“消除 sink”和“稳定 sink”。
  • 对 diffusion LLM 推理优化而言，stable low-norm anchor 可能能配合 sparse attention、KV cache、block diffusion 等方法，作为结构性稳定器。
  • 可以尝试 inference-time sink token 注入实验：即便没重新训练，也可以测试在 prompt/attention mask 层面插入一个特殊低范数 token 是否有短期收益。
  • 对 long-context DLM，stable sink token 可能与 attention pruning、token pruning、dynamic remasking 结合，降低 attention pattern 的不稳定性。...

DIP: Dynamic In-Context Planner For Diffusion Language Models

abs | pdf | summary md

作者：Yang Li, Han Meng, Chenan Wang, Haipeng Chen

机构：College of William & Mary

一句话总结

DIP 的核心贡献是把 DLM 的非自回归迭代生成特性转化为一个动态上下文调度机会：不再把所有 ICL examples 从一开始固定进 prompt，而是在 Fast-dLLM 的 block-wise decoding 过程中按 MMR 排序和 confidence-aware policy 逐步插入 examples，从而在基本保持 GSM8k accuracy 的同时，在 Fast-dLLM 之上获得约 1.17x 的额外 throughput 提升。

背景与动机

这篇工作的核心问题是：Diffusion Language Models (DLMs) 在 In-Context Learning (ICL) 场景下可以受益于示例 prompt，但 DLMs 的 bidirectional attention 会让上下文长度带来显著推理开销。传统做法沿用 ARLM 的习惯，把所有 in-context examples 一次性放进 prompt，并在整个生成过程中保持不变。这对 ARLM 是自然的，因为 left-to-right generation 依赖固定 prefix 和 KV states；但对 masked diffusion generation 来说，这个静态 prompt 约束并不是必要的。

论文的关键观察是：DLMs 的非自回归、迭代去噪生成过程允许在生成中途动态调整 context。换句话说，模型不必从一开始就带着全部 examples 完成所有 block 的 decoding；可以先用较少 examples 开始，等生成状态显示需要更多上下文时，再逐步插入新的 examples。这样能降低平均上下文长度，从而提升 throughput。

论文还强调，现有 Fast-dLLM 这类 KV cache + block-wise decoding 方法虽然已经能加速 DLM 推理，但仍会在上下文较长时承担较高 attention 成本。DIP 的定位不是替代 Fast-dLLM，而是在 Fast-dLLM 的 block-level KV cache update 时机上，动态更新 prompt，把“什么时候插入 example”和“插入哪个 example”变成一个推理时策略问题。

图中显示，在 Fast-dLLM 下，LLaDA-8B-Instruct 和 Dream-7B-Instruct 的 throughput 都会随着 prompt 中 in-context examples 数量增加而下降。这是 DIP 的直接动机：如果不是每个 decoding block 都需要完整 5-shot context，就可以通过延迟或减少 example 使用来节省计算。

方法与框架

DIP (Dynamic In-Context Planner) 是一个 training-free 的 context optimization 方法，由两个阶段组成：

  • Example ranking: 先对候选 examples 排序，决定优先插入哪些 examples。
  • Example insertion policy: 在 block-wise diffusion decoding 过程中，根据生成阶段和 confidence 决定是否插入下一个 example。

这个框架图很好地说明了 DIP 的执行方式：左侧先用 MMR 对 examples 排序；右侧在 DLM 的 block-wise decoding 中，prompt 初始只包含 query 和少量 examples，后续 block 根据 policy 选择 insert 或 keep。蓝色表示 example tokens，橙色表示 query tokens，灰色是 mask tokens，绿色是 decoded tokens，浅黄色是 cached tokens。

价值、局限与启发

  • 问题切入点明确：它抓住了 DLM 与 ARLM 的结构差异，即 DLM 不必被静态 prompt 约束。
  • 方法 training-free，不需要微调模型或训练 scheduler。
  • 与 Fast-dLLM 这类 KV cache framework 兼容，利用 block transition 的 cache update 时机，工程上比较自然。
  • 使用 confidence 作为插入信号，额外开销低，因为 confidence 本来就是 DLM sampling/unmasking 会计算的量。
  • 实验显示在 Fast-dLLM 之上仍有额外 speedup，而不是只重复已有 KV cache 加速。

论文自己的 limitation 主要有三点：

  • 实验只覆盖 GSM8k 和 LLaDA-8B-Instruct，任务和模型范围窄。
  • DIP 只在 Fast-dLLM 框架上实现和测试；虽然理论上兼容其他 KV cache-enhanced inference framework，但没有实证。
  • 推理设置沿用 Fast-dLLM，尚未系统探索 generation length、block size、threshold、不同 decoding settings 对 DIP 的影响。

除此之外，还有几个值得注意的技术风险：

  • 策略是 heuristic，没有学习到 task-specific 的插入策略；在更复杂任务上，confidence 低未必总表示“需要更多 examples”。
  • Example 数量只增不减，无法纠正早期插入的低质量或冗余 example。
  • MMR 基于 query embedding 排序，对 reasoning task 中 example 的解法结构、推理模式相似性捕捉有限。
  • 目前只看 5-shot GSM8k，没有展示不同 shot 数、不同候选池大小、不同 example retrieval 质量下的鲁棒性。

一句话总结

这是一篇面向 Diffusion Language Models (DLMs) 的系统综述，试图把当前扩散语言模型的全景图一次性讲清楚：从连续/离散/混合范式，到预训练、SFT、RL、推理加速、多模态统一建模、下游应用，再到并行性与质量的根本张力、长序列与动态长度、基础设施与可扩展性等核心瓶颈。

背景与动机

作者的切入点很明确：AR LLM 仍然是主导范式，但它的逐 token 生成天生受制于串行推理路径；而 diffusion 模型在图像/视频里已经证明了“迭代去噪 + 并行生成”的可行性，因此自然会诱导出一个问题: 能不能把这种并行生成范式迁移到语言上。

论文认为 DLM 的吸引力主要来自五点：

  • 并行生成: 一次生成多个 token，而不是严格 next-token。
  • 双向上下文: 每步都能看左右上下文，而不只是左侧前缀。
  • 迭代修正: 先出粗结果，再逐步修补低置信位置。
  • 可控性: 天然适合 infilling、结构约束和 guided generation。
  • 多模态统一建模: 文本和图像都能纳入统一的“去噪-重构”框架。

但作者也强调，DLM 不是“更快的 AR”这么简单。它引入了新的建模对象、训练目标与推理调度，带来了一整套新的问题：如何定义 token/noise corruption、如何做高效训练、如何在并行性和 coherence 之间平衡、如何把 RL/偏好优化搬到一个不可直接 factorize likelihood 的生成过程上。

  • DLM 的“稳定 token / 稳定 block”能否统一为一种 uncertainty 或 information gain 视角？
  • dynamic-length generation 能否和 stable prefix / EOS-aware stopping 联合建模，真正减少无效后续更新？
  • DLM RL 里是否可以进一步减少 surrogate likelihood 的 bias-variance gap？
  • multimodal DLM 的 reasoning traces 是否能比 AR MLLM 更自然地和图像区域、编辑动作对齐？
  • 能否构建面向 serving 的 DLM runtime，把 cache、block decoding、verification、step scheduling 统一到一个系统里？
