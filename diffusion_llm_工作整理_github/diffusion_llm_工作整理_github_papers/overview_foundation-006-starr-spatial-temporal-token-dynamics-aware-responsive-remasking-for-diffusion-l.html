价值、局限与启发

类型一：静态置信度阈值。LLaDA-8B和Dream-7B采用固定阈值，仅解码置信度超过预定义阈值的token。缺点是完全忽略token置信度的时间演化与空间关联。

类型二：仅考虑时间维度的策略。TSE、Rainbow、Saber等方法根据解码步数动态调整阈值，但忽略了token间的空间关联。

类型三：仅考虑空间维度的策略。DUS将序列位置划分为非相邻膨胀组并行unmask；Block Diffusion和SlowFast Sampling在每步限制解码区域，对其他位置按预定义规则remask。它们虽然捕获了空间结构，但忽略了token信心的时序演化。

根本问题：现有方法本质上是静态的、非自适应的——它们要么只使用瞬时置信度信息，要么在时间/空间维度上作粗粒度调整，无法捕捉每个token独特的时空动态特性。
