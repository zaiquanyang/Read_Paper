## 2. 背景与动机（详细）

### 2.1 任务定义与应用场景

Diffusion Language Models (dLLMs) 作为 AR-LLM 的替代方案，其核心吸引力在于并行解码能力——有望大幅提升推理效率。代表性工作包括 LLaDA、Dream 等，它们已在十亿参数规模上展现了实际潜力。...

背景与动机

Uniform Diffusion Language Models (UDLM) 用均匀随机采样的 token 替代 [MASK] 符号，训练模型从任意噪声 token 中恢复干净 token。这天然支持 token-to-token 去噪（所有位置在每步都可重新评估），提供自纠错能力。

但 UDLM 从完全随机序列开始解码，使得去噪困难、生成不稳定。

方法与框架

当前 mask-based dLLMs（MDLM 范式）的解码是二值的、单向的 mask-to-token 过程：

  • 位置要么是 [MASK]，要么是已提交的 token
  • 一旦 masked 位置被解码为 token，该 token 就被固定，作为后续解码步骤的上下文
  • 无法修正：早期预测错误会作为不可更改的上下文传播到后续步骤，引发级联误差累积
  • 在激进并行解码下，误差不可避免，最终导致语义崩溃

与 speculative decoding 不同，dLLMs 缺乏从错误预测中恢复的机制，这从根本上限制了高并行度下的性能。

本文的动机是：保留 MDLM 稳定的全 mask 初始化 + 获得 UDLM 的自纠错能力。

  • 用全 masked 序列作为 UDLM 解码的初始化（保持稳定性）
  • 在后续步骤中，对所有已解码的 token 进行重新预测（获得自纠错能力）

关键洞察：传统 UDLM 训练使用均匀随机 token 构造噪声序列，但推理时遇到的噪声来自模型自身的预测分布，存在严重的 train-inference mismatch。

*图：LLaDA-2.0-mini（原始二值 mask-to-token）vs DMax（自修正 mask-to-hybrid-embedding-to-token）*

DMax 包含两个核心组件：

  • On-Policy Uniform Training (OPUT)：训练策略，将预训练 MDLM 扩展为具有自纠错能力的 UDLM
  • Soft Parallel Decoding (SPD)：推理策略，在 embedding 空间进行迭代自修正

价值、局限与启发

当前 mask-based dLLMs（MDLM 范式）的解码是二值的、单向的 mask-to-token 过程：

  • 位置要么是 [MASK]，要么是已提交的 token
  • 一旦 masked 位置被解码为 token，该 token 就被固定，作为后续解码步骤的上下文
  • 无法修正：早期预测错误会作为不可更改的上下文传播到后续步骤，引发级联误差累积
  • 在激进并行解码下，误差不可避免，最终导致语义崩溃

与 speculative decoding 不同，dLLMs 缺乏从错误预测中恢复的机制，这从根本上限制了高并行度下的性能。

  • 首次从根本上解决了 dLLM 并行解码的误差累积问题：不是设计更好的解码调度，而是赋予模型自纠错能力
  • On-Policy 训练设计精巧：弥合了 train-inference gap，使得从模型自身错误中学习成为可能，这是传统 UDLM 训练做不到的
  • Soft Embedding 插值简单有效：将不确定性显式编码到中间状态，使模型能区分可靠和不可靠预测
  • 仅用自蒸馏数据：所有训练数据来自模型自身生成，不需要外部高质量回复，降低了数据依赖
  • 高并行 + 保持精度：TPF 从 ~2.8 提升到 ~6.2（2.2×），同时精度几乎不降
  • 在低并行度下也提升精度（+0.8%~3.0%），说明自修正能力有更广泛的价值
  • OPUT 是 SPD 的硬性前提：SPD 不能独立使用，必须配合 OPUT 训练的模型，增加了训练成本
  • 训练需要两次前向传播：虽然分到不同 iteration 避免了显存增长，但训练时间翻倍
  • Block size 固定为 32：未探索不同 block size 的影响
  • 仅在 LLaDA-2.0-mini 上验证：未在更大规模模型（如 LLaDA-8B）或其他 dLLM 架构上测试泛化性
  • 自蒸馏的上限：训练数据来自模型自身生成，可能受到基础模型能力的天花板限制
  • 连续前缀设计的保守性：仅提升最长连续前缀可能过于保守，某些非连续的高置信位置也可以安全提升
  • On-Policy 训练弥合 train-inference gap 是通用原则：不仅适用于 dLLM，任何需要模型在推理时处理自身输出的场景（如 agent 自纠错、迭代精炼）都应考虑 on-policy 数据构造
  • Soft Embedding 编码不确定性：将预测置信度显式编码到中间表示中，使后续步骤能利用不确定性先验——这一思路可推广到 VLM、多模态生成等需要传递置信信息的场景...
