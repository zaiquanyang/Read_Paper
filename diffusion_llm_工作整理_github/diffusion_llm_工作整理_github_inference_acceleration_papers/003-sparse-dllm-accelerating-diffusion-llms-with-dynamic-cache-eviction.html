方法与框架

dLLM 面临严重的推理效率瓶颈：

  • 计算复杂度高：自回归 LLM 解码复杂度为 O(L)，而 dLLM 每个推理步骤都需要对整个序列（包括 prompt、已生成 token、掩码 token）重新计算 QKV 状态，复杂度高达 O(L²)。
  • 现有 KV Cache 方案内存开销大：近期工作（dLLM-Cache、dKV-Cache、Fast-dLLM）将 AR LLM 的 KV Cache 机制适配到 dLLM，利用"相邻解码步骤的 KV 状态几乎相同"的观察，在多个步骤中复用同一份缓存 KV 状态。但这些方法都存储所有层的完整 KV 表示，导致显著的内存开销（比 vanilla dLLM 高 10%-30%），严重限制了长上下文场景的实用部署。
  • 缺少对 dLLM 内部注意力稀疏性的利用：现有方法仅引入 KV Cache 机制，未对其内部属性进行分析或进一步稀疏化。

作者对 dLLM 的注意力模式进行了系统分析（Figure 2），发现两个关键特征：

  • 跨层稀疏性（Sparsity Across Layers）：dLLM 各层注意力呈现显著稀疏性，表现为局部注意力（邻近 token 关注强）和垂直注意力（所有 query 集中在少数 pivotal tokens 上）两种稳定模式。与自回归模型不同，dLLM 没有对初始 token 的异常关注。
  • 跨步一致性（Consistency Across Steps）：虽然 QKV 状态每步重新计算，但获得显著关注的具体 token 在解码步骤间保持显著稳定——低重要性 token 在早期步骤被识别后，整个解码过程中持续保持低相关性。

这两个观察直接催生了核心策略：在早期步骤选择性淘汰不重要的 KV cache 条目，仅保留关键子集。

Sparse-dLLM 是首个训练无关（training-free）的 dLLM 动态 Cache 淘汰框架，核心包含两大策略：

  • 动态双向 Cache 淘汰（Dynamic Bidirectional Cache Eviction）：利用 token 重要性在步骤间的一致性，基于注意力引导的稀疏模式，动态淘汰前缀（prefix）和后缀（suffix）位置的低重要性 KV 条目。
  • 延迟 Cache 更新（Delayed Cache Updates）：缓存更新故意延迟一个步骤以提高稳定性。当进入新的解码 block 时，缓存完全清空并刷新。

实验与结论

实验覆盖 4 个模型：LLaDA-8B-Instruct、LLaDA-1.5、Dream-v0-7B-Base、Dream-v0-7B-Instruct，在 7 个基准（MMLU、ARC-C、PIQA、GPQA、GSM8k、Math、HumanEval）上评估准确率、吞吐量和峰值内存。

|------|-----------|-------------|------------|

| LLaDA-8B-Instruct (vanilla) | 59.24 | 1.0× | 1.0× |

| + dLLM-Cache | 59.80 | 2.3× | 1.1× |

| + dKV-Cache | 59.96 | 1.4× | 1.2× |

| + Fast-dLLM | 58.87 | 2.2× | 1.1× |

| + Sparse-dLLM (ours) | 59.86 | 3.4× | 1.0× |

关键发现：

  • Sparse-dLLM 在所有模型和基准上均取得最高吞吐量，Dream 系列加速达 3.6×，LLaDA 系列达 3.4×
  • 峰值内存与 vanilla dLLM 几乎相同（差异 < 0.5GB），Dream 系列甚至低于 baseline
  • 性能几乎无损：LLaDA-8B-Instruct 上平均准确率 59.86 vs baseline 59.24，略微提升...

价值、局限与启发

dLLM 面临严重的推理效率瓶颈：

  • 计算复杂度高：自回归 LLM 解码复杂度为 O(L)，而 dLLM 每个推理步骤都需要对整个序列（包括 prompt、已生成 token、掩码 token）重新计算 QKV 状态，复杂度高达 O(L²)。
  • 现有 KV Cache 方案内存开销大：近期工作（dLLM-Cache、dKV-Cache、Fast-dLLM）将 AR LLM 的 KV Cache 机制适配到 dLLM，利用"相邻解码步骤的 KV 状态几乎相同"的观察，在多个步骤中复用同一份缓存 KV 状态。但这些方法都存储所有层的完整 KV 表示，导致显著的内存开销（比 vanilla dLLM 高 10%-30%），严重限制了长上下文场景的实用部署。
  • 缺少对 dLLM 内部注意力稀疏性的利用：现有方法仅引入 KV Cache 机制，未对其内部属性进行分析或进一步稀疏化。
  • 首个训练无关的动态 Cache 淘汰方案：不需要额外训练或微调，即插即用，可直接应用于现有 dLLM 推理框架。
  • 双向稀疏化的创新设计：充分利用 dLLM 的双向注意力特性，同时淘汰 prefix 和 suffix 中不重要的 KV 条目，区别于所有现有方法。
  • 极优的效率-内存-精度权衡：吞吐最高提升 10×（长上下文），内存几乎不增加，精度几乎不损失甚至略有提升。
  • 充分的理论分析和实验验证：从注意力稀疏性的系统观察到延迟缓存、pivotal token 语义分析，论证链路完整。覆盖 LLaDA 和 Dream 两大系列 4 个模型，7 个基准 + 长上下文测试。
  • 实现简洁：算法逻辑清晰，超参数少（仅 r 和 k），默认配置 (r=0.5, k=3) 在各模型/任务上泛化良好。
  • 代码任务性能下降：HumanEval 上 Dream 系列有明显下降（Dream-v0-7B-Instruct 从 57.93 降至 50.00），说明代码生成等需要完整上下文的任务对稀疏化更敏感。
  • 仅测试到 8k 上下文：受限于 NVIDIA 4090（48GB），未在更长上下文（32k+）上验证。
  • 固定 block 长度和保留比率：所有序列长度采用统一的 r=0.5，未探索自适应保留比率。
  • 未与 speculative decoding 等方法对比：仅与 KV Cache 类方法比较，未涉及其他 dLLM 加速范式（如提前退出、推测解码等）。...
