SPIN: Self-Play Fine-Tuning Converts Weak Language Models to Strong Language Models

SPIN arXiv abs PDF Code UCLA · arXiv 2401.01335
核心思想：使用 self-play 范式让弱模型与自己的前一版本竞争，通过 DPO 偏好优化迭代提升模型能力——"与昨天的自己竞争"。

方法要点

  • 当前模型生成回答，前一 frozen checkpoint 生成回答作为"弱"对手
  • 使用 DPO 让学生偏好自己的当前输出而非前一 checkpoint 的输出
  • 迭代进行：每次更新后前一 checkpoint 滚动更新

优点与局限

优点

  • 无需外部 teacher，迭代 self-play 可持续提升
  • 与 DPO 天然兼容，实现简单

局限

  • 更准确说是"iterative on-policy DPO"，非严格 per-token logit 蒸馏
  • supervision 是 sequence-level DPO preference

定位：Self-play + DPO 范式的代表作，属于 OPSD 谱系中的"迭代自竞争"分支。

优点与局限

优点

  • Glancing 机制提供选择性使用 draft samples 的方式
  • 与 speculative decoding 加速框架兼容

局限

  • Partial on-policy，不满足严格 on-policy 条件
  • 主要用于 speculative decoding 加速而非 reasoning 提升

定位：Speculative decoding 加速方向的 self-distillation 变体，属于 OPSD 谱系边缘的 specdec 应用。

SDPO: Reinforcement Learning via Self-Distillation

SDPO arXiv abs PDF Code ETH Zurich / MPI / MIT / Stanford · arXiv 2601.20802
核心思想：不依赖外部强教师，把"当前模型在看到 rich feedback 后形成的 hindsight token distribution"当作 self-teacher，蒸馏回原始 student，将 RLVR 中稀疏的 scalar reward 转化为 dense logit-level credit assignment。

问题与动机

  • Credit assignment 太稀疏：RLVR 中所有 token 共享同一个 reward，难以定位错误位置
  • Group reward collapse：GRPO 全组 rollout 失败时 advantage 塌为 0
  • 核心洞察：LLM 已具备 in-context hindsight correction 能力——看到反馈后能回顾性识别自己哪里出错了

方法：Self-Distillation Policy Optimization

  • 定义 RLRF 范式：将 scalar reward 升级为 tokenized feedback（runtime error、failing tests）
  • 构造 self-teacher：$q_\theta(\cdot|x,f) = \pi_\theta(\cdot|\text{reprompt}(x,f))$，同一模型+反馈条件
  • SDPO 目标：$\mathcal{L}_{\text{SDPO}} = \sum_t \text{KL}(\pi_\theta(\cdot|x,y_{<t}) \| \text{stopgrad}(\pi_\theta(\cdot|x,f,y_{<t})))$
  • 用 top-K distillation 节省显存，trust-region/EMA teacher regularization 保证稳定

实验结果

SettingMethodPerformance
LCBv6 CodingGRPO41.2%
SDPO48.8% (+7.6pp)
Science QA (Olmo3 Chem)GRPO 5h~50%
SDPO 50min同等效果 (~6x speedup)

响应长度缩短 3.2x（820→256 tokens）。Test-Time SDPO 在 very hard 题上 discovery@k 达 53.2% vs best-of-k 41.5%。

消融要点

  • Credit assignment 粒度：logit-level > token-level > sequence-level > GRPO
  • Teacher regularization：无正则 teacher 发散 (36.1%)，trust-region best (50.6%)
  • Feedback 类型：environment output + sample solution 联合效果最好

优点与局限

优点

  • 无需外部 teacher，利用模型自身 ICL 能力构建 self-teacher
  • Dense logit-level credit assignment 远优于 sequence-level reward
  • 兼容现有 RLVR pipeline，额外开销仅 ~1.2-1.5x
  • 响应更高效简洁，长度缩短 3-11x

局限

  • 依赖 base model 的 hindsight 能力，弱模型上不如 GRPO 稳定
  • 需要 rich feedback，标准 RLVR 环境效果不如有真正环境反馈
  • 主实验偏向 verifiable/agentic tasks，开放式生成未系统探索

定位：将 RLVR 升级为 RLRF 范式，通过 self-teacher hindsight distribution 实现无需外部 teacher 的 dense credit assignment，是 OPSD 方向中"内生自蒸馏+RL"的代表作。

OPSD: Self-Distilled Reasoner — On-Policy Self-Distillation for Large Language Models

OPSD arXiv abs PDF Code arXiv 2601.18734
核心思想：让同一个 LLM 同时充当 student（只看问题）和 teacher（额外看 ground-truth reasoning trace），在 student 自己采样的 rollout 上做逐 token 分布对齐。核心假设：rationalization is easier than generation。

方法

  • Student 只看问题 $x$，teacher 额外看到 ground-truth solution $y^*$，参数共享但上下文不同
  • 主目标：full-vocabulary forward KL 蒸馏在 student rollout 上
  • Pointwise KL clipping：限制极端 divergence 项的影响，防止 style token 吞没数学 token 监督
  • 最优配置：student thinking mode off + teacher thinking mode on

实验结果

ModelOPSDGRPOSFTBase
Qwen3-8B avg64.864.059.861.8
Qwen3-4B avg63.662.7—61.2
Qwen3-1.7B avg43.437.7—37.1

小模型收益最大（1.7B 提升 ~6pp）。Token efficiency：OPSD 每题 1 rollout×1024 tokens×100 steps vs GRPO 8 条×16k×500 steps。

消融要点

  • Divergence 目标：Forward KL >> Reverse KL, JSD
  • Full-vocabulary vs sampled-token：全词表蒸馏显著更优（AIME25 84.1 vs 82.1）
  • Generation length：1024 vs 4096 差异不大，前期 token 监督价值更高

优点与局限

优点

  • 设定干净：只利用 ground-truth solution 作为 privileged information
  • Token efficiency 显著高于 GRPO
  • 对小模型尤其有效：1.7B 上提升 ~6pp

局限

  • 只验证到 8B 规模，更大模型上未验证
  • 依赖 ground-truth solution，无高质量 reference 时不适用
  • 尚未引入显式 correctness verification

定位：OPSD 方向的核心代表作，在 SFT 和 RL 之间找到平衡——兼具 on-policy 真实性与 dense supervision，且不依赖外部大 teacher。

优点

OPCD: On-Policy Context Distillation for Knowledge Internalization

OPCD arXiv abs PDF Code Microsoft Research · arXiv 2602.12275
核心思想：通过 on-policy reverse-KL 蒸馏将 in-context knowledge 内化到模型参数中，使模型在移除上下文后仍能保持高性能。"知识内化 = self-distillation with context"。

方法

  • 教师：同一模型 + in-context knowledge（privileged context）
  • 学生：同一模型，无上下文
  • 学生在无上下文时自行 rollout，教师在相同 rollout prefix 上（带上下文）提供 per-token 监督

优点与局限

优点

  • "知识内化"范式清晰可推广
  • 可用于将 Agent 的工具文档、知识库等上下文信息内化
  • 有 Microsoft 官方代码

局限

  • 简略摘要，具体实验数值和 ablation 细节缺失
  • 泛化到更复杂知识类型的有效性待验证

定位：On-policy context distillation 的代表性工作，将上下文知识内化到模型参数。

CRISP: On-Policy Self-Distillation for Reasoning Compression

CRISP arXiv abs PDF Code LinkedIn · arXiv 2603.05433
核心思想：给教师添加 "be concise" 指令作为 privileged context，再用 on-policy RKL 蒸馏让学生学会在无显式指令时也产生简洁推理链，压缩推理长度而不导致 entropy collapse。

优点与局限

优点

  • "通过指令蒸馏压缩推理"可推广到控制输出长度场景
  • 有效区分了 self-distillation 与 RL 长度惩罚在 entropy collapse 上的差异
  • 方法简洁实用，有公开代码

局限

  • 缺少具体压缩率数值和 benchmark 结果
  • 压缩效果的跨任务泛化性待验证

定位：推理链压缩场景下的 on-policy self-distillation，避免了 RL 长度惩罚的 entropy collapse 问题。

OEL: Online Experiential Learning for Language Models

OEL arXiv abs PDF Code Microsoft Research · arXiv 2603.16856
核心思想：在真实部署后将文本交互经验提炼为可迁移知识，再用 OPCD 风格的 on-policy context distillation 将知识压进模型权重，实现 reward-free 的在线持续学习闭环。

方法

  • 两阶段闭环：先从交互轨迹中提取 experiential knowledge，再用 OPCD 做 on-policy RKL 蒸馏内化
  • 经验提取器将 trajectory 压缩成可迁移规则/策略（非原始轨迹），token efficiency 更高
  • 整个流程 reward-free，不需要 server 访问原始 user environment

优点

  • 问题设置现实：不要求 reward、不要求人标、不要求 server 访问用户环境
  • 经验提炼视角强：不是记忆原始轨迹而是抽象成可迁移知识
  • 闭环完整：部署→经验回流→知识提炼→参数内化→再部署

  • 知识质量依赖 extractor，可能累积偏差
  • Online loop 可能引入自我强化偏差

PACED: Frontier Curriculum Self-Distillation at Student Competence Boundary

PACED arXiv abs PDF Code LinkedIn · arXiv 2603.11178
核心思想：发现梯度信噪比随学生通过率呈钟形曲线，提出在学生"能力边界"（pass rate p ≈ 0.5）的问题上集中训练，用 $w(p)=p(1-p)$ 构造 frontier curriculum 以显著提升 OPD 效率。

  • 缺少具体数值实验结果

Why Does Self-Distillation (Sometimes) Degrade Reasoning?

Analysis arXiv abs PDF Code MSR / KAIST / SNU · arXiv 2603.24472
核心思想：诊断性研究发现 rich privileged context 的教师会抑制学生的 epistemic verbalization（不确定性表达），导致学生"假装确定"，在 OOD 任务上出现最高 40% 的性能退化。

核心发现

  • Epistemic Verbalization Collapse：rich privileged context 抑制学生不确定性表达
  • Rich context 带来更大 in-domain 增益，但造成更严重 OOD 退化
  • Thin privileged context 提供更平衡的 in-domain/OOD 表现

优点与局限

优点

  • 揭示了 OPSD 的关键失败模式
  • Epistemic verbalization collapse 概念化具有理论深度
  • 对方法设计有重要指导意义

局限

  • 纯分析论文，未提出解决方案
  • 如何平衡 in-domain 增益与 OOD 退化仍需后续探索

定位：诊断性分析工作，揭示了 OPSD 在 rich privileged context 下的 epistemic verbalization collapse 失败模式。

SSD: Embarrassingly Simple Self-Distillation Improves Code Generation

SSD arXiv abs PDF Code Apple MLR · arXiv 2604.01193
核心思想：通过训练时温度与截断配置系统性改写目标分布，使普通交叉熵训练也能诱导非平凡自我提升——压缩无用 tail、保留有价值的 head 探索。方法极简：无验证器、无 RL、无教师、无正确性过滤。

方法

  • 用训练时解码配置 $(T_{\text{train}}, \rho_{\text{train}})$ 从冻结基础模型采样，不做执行验证
  • 理论分解：support compression（压低外部尾部概率）+ within-support reshaping（保留头内有效探索）
  • 有效温度 $T_{\text{eff}} = T_{\text{train}} \cdot T_{\text{eval}}$，最佳工作带约在 1.2 附近

实验结果

ModelBaseSSDChange
Qwen3-30B-Instruct LCBv642.4%55.3%+12.9pp
Qwen3-4B-Instruct—+7.5pp—

提升主要集中在中等/困难问题。即使 62% 输出无法提取代码的高温数据仍能带来提升。单纯调温度的解码扫描 vs SSD 差 11.8pp。

优点与局限

优点

  • 方法极简但收益硬（+12.9pp on 30B）
  • 提供完整机制叙事：lock/fork、支持压缩、有效温度
  • 是 OPD/self-distillation 的重要低复杂度对照基线

局限

  • 适用性高度依赖代码任务的 lock/fork 结构
  • 需要仔细调节训练/推理解码超参数
  • 与 OPD 联系是"邻近机制"而非同一算法族

定位：无 reward 自提升的机制型论文，适合作为复杂 RL 方法的低复杂度对照基线。

RLSD: Self-Distilled RLVR — Reinforcement Learning with Self-Distillation

RLSD arXiv abs PDF arXiv 2604.03128
核心思想：OPSD 训练后期退化是因为教师控制了更新方向导致信息泄漏。RLSD 提出用环境奖励决定更新方向、自蒸馏只提供 token 级更新幅度，实现"方向与幅度分离"的无泄漏共享参数自蒸馏。

方法

  • Step 1: 计算特权信息增益 $\Delta_t = \text{sg}(\log P_T - \log P_S)$
  • Step 2: 方向感知证据比率 $w_t = \exp(\text{sign}(A) \cdot \Delta_t)$（只改幅度不改方向）
  • Step 3: 裁剪 token 级优势 $\hat{A}_t = A \cdot \text{clip}(w_t, 1-\epsilon_w, 1+\epsilon_w)$
  • 结构保证：方向隔离、支持隔离、幅度有界 → 无泄漏

实验结果

MethodMMMUMathVistaMathVisionAvg
GRPO62.4473.8047.3753.86
OPSD60.4473.6046.4752.49
RLSD67.2278.1052.7356.18

200 步 RLSD 已超过 400 步 GRPO。OPSD 前期快但中后期退化，RLSD 兼顾前期加速和后期稳定性。

优点与局限

优点

  • 先把 OPSD 为何失败讲清楚，再给解法（诊断型论文）
  • "方向 vs 幅度"抽象可迁移到多种 token 级 credit assignment 场景
  • 工程轻量，只需额外一遍带特权信息的前向传播

局限

  • 实验集中在多模态推理
  • 仍依赖可验证奖励或最终真实答案
  • Bayesian 解释依赖模型近似先验/后验能力

定位：把"教师有特权信息时自蒸馏的边界"说清楚的诊断+方法论论文，提出方向与幅度分离的核心原则。

SRPO: Unifying Group-Relative and Self-Distillation Policy Optimization via Sample Routing

SRPO arXiv abs PDF arXiv 2604.02288
核心思想：对每个 rollout 做样本级路由：正确样本走 GRPO 分支，错误且有教师信息的走 SDPO 分支，配合基于教师熵的动态加权，统一 GRPO 的稳定性和 SDPO 的高效细粒度纠错。

方法

  • 样本路由：正确 → GRPO；错误有教师信息 → SDPO；错误无信息 → 回退 GRPO
  • Dynamic-Weighted SDPO：基于教师 token 熵的动态加权，熵低权重高
  • 自动课程学习：早期错误多→SDPO 占比大；后期正确多→GRPO 占主导

实验结果

ModelGRPOSDPOSRPO
Qwen3-8B avg74.071.177.4 (+3.4)
Qwen3-4B avg69.766.774.2 (+4.5)

后期计算成本更低：10h 时 SRPO 每步 75.8s vs GRPO 91.5s（快 17.2%）。

优点与局限

优点

  • 问题定义精准：明确指出 SDPO 崩溃的两个原因
  • 路由规则简单但有效，不需额外混合超参数
  • 后期成本更低（正确样本增多→教师计算减少）

局限

  • 教师信息依赖同组正确兄弟 rollout，一组全错时无法触发 SDPO
  • 适用范围还局限在五个基准
  • 动态权重只看熵，未来可结合更多可靠性指标

定位：把"什么时候蒸馏、什么时候不蒸馏"讲得非常具体的样本级路由方法，统一 GRPO 与 SDPO。

Skill-SD: Skill-Conditioned Self-Distillation for Multi-Turn LLM Agents

Skill-SD arXiv abs PDF arXiv 2604.10674
核心思想：把智能体轨迹中总结出的自然语言 skills 只给教师看、不给学生看，通过重要性加权逆 KL 的 on-policy 自蒸馏将 skill 内化到学生，将 OPD 从"固定答案蒸馏"推进到"动态 skill 蒸馏"。

方法

  • 从历史轨迹中用外部 LLM 总结出 skills（success_analysis + mistake_analysis + golden_workflow）
  • 推导了 importance-weighted reverse-KL 估计器，修正跨 prompt 自蒸馏的梯度偏差
  • 训练目标 = GRPO（任务级 credit）+ λ·SDL（token 级塑形）
  • 学生始终在 plain prompt 下 on-policy rollout，推理时无需依赖 skill 检索

实验结果

BenchmarkVanilla GRPOSkill-Augmented GRPOSkill-SD
AppWorld50.9%42.1%64.9% (+14.0%)
Sokoban51.6%20.3%62.5% (+10.9%)

Skill-Augmented GRPO 反而变差——证明 skill 不应直接给 student。教师拥有的 rollout 在 Sokoban 上几乎完全崩溃（10.9%），证明 on-policy rollout 不可放松。

优点与局限

优点

  • 将 OPD 从"固定答案蒸馏"扩展到"动态 skill 蒸馏"
  • 重要性加权逆 KL 推导是跨 prompt 自蒸馏的核心贡献
  • 清晰证明 skills 应作为 training-only 特权信息

局限

  • 仅 AppWorld 和 Sokoban 两个基准
  • Skill 总结依赖外部 LLM API
  • 仅在单一模型尺度（4B）验证

定位：将 OPD 从单步/单答案问题扩展到多轮多路径智能体任务的关键工作。

SD-Zero: Self-Revision Turns Binary Rewards into Dense Supervision

SD-Zero arXiv abs PDF Princeton / Toronto / CMU · arXiv 2604.12002
核心思想：使用单一模型扮演 Generator 和 Reviser 双角色，Reviser 接收 Generator 的回答 + 二值奖励作为条件，通过自我修正将稀疏二值奖励转化为密集 token 级监督。

方法

  • Generator 生成初始回答，Reviser 接收回答 + 二值奖励作为条件生成修正版
  • 通过逐 token KL 蒸馏从 Reviser 到 Generator
  • 特权上下文是非文本的：Generator 完整回答 + 标量二值奖励

优点与局限

优点

  • "二值奖励 → 密集监督"的优雅转化
  • 在 Qwen3-4B / OLMo-3-7B 上比基础模型提升 ≥10%
  • 优于 RFT、GRPO、SDFT（匹配样本预算下）

局限

  • 仍需要可验证的二值奖励信号
  • Generator-Reviser 共同进化的稳定性待深入分析

定位：将自我修正作为桥接稀疏奖励与密集监督的机制，是 OPSD 中"非文本特权上下文"的代表。

  • Teacher 是学生的 EMA 平滑副本（τ=0.05），看到特权 QCP
  • 完全无需外部数据/人工标注/更强教师

OPSDL: On-Policy Self-Distillation for Long-Context Language Models

OPSDL arXiv abs PDF Baidu · arXiv 2604.17535
核心思想：使用短上下文的同一模型作为教师，对长上下文学生做逐点逆 KL 蒸馏，通过自蒸馏让长上下文模型学会保持短上下文模型的精确推理能力。

优点与局限

优点

  • 长上下文优化的新方案，无需外部教师
  • 短上下文教师提供了稳定的推理锚定

局限

  • 简略版未记录详细实验数据
  • 依赖于短上下文与长上下文之间的性能差距作为驱动力

定位：长上下文 LLM 优化的自蒸馏方案，将短上下文精确性迁移到长上下文。

PBSD: Preference-Based Self-Distillation beyond KL Matching via Reward Regularization

PBSD arXiv abs PDF arXiv 2605.05040
核心思想：把 self-distillation 从纯 KL matching 提升到 reward-regularized 目标——student 不应照抄 teacher，而应学习 teacher 分布按 latent reward 指数重加权后的 reward-tilted distribution，用 DPO 风格 pairwise preference objective 近似优化。

TRACE: Distilling Where It Matters via Token-Routed Self On-Policy Alignment

TRACE arXiv abs PDF arXiv 2605.10194
核心思想：只在真正关键的 reasoning span（≤25% token）上蒸馏，对不同类型 span 用不同 KL 方向（FKL/RKL/无），且 privileged KL 通道在短暂 warm-up 后衰减为 0，避免全 token 蒸馏的伤害。

方法

  • Span Annotator 标出关键 span（key spans / error spans），覆盖率 ≤25%
  • Key spans 用 FKL，error spans 用 RKL；KL 权重快速 decay 到 0
  • 剩余 token 走 GRPO，span token 在 KL 衰减后也交还给 GRPO

优点

RLRT: Rebellious Student — Reversing Teacher Signals for Reasoning Exploration

RLRT arXiv abs PDF MSR / KAIST · arXiv 2605.10781
核心思想：在正确 rollout 上把 teacher signal 反过来读——强化 student 背离 teacher 但仍然做对的 token（self-driven reasoning），把 teacher-student gap 从"对齐目标"重解释为"有价值探索信号"。

方法

  • RLRT 将 RLSD 的 ratio 翻转：$(P_S/P_T)^{\text{sign}(A)}$ 而非 $(P_T/P_S)^{\text{sign}(A)}$
  • 只在正确 rollout（reward gate）上启用 reversed signal，错误 rollout 退回 vanilla GRPO
  • 用 clip + mixing 限制 reversed signal 强度

实验结果

Base 模型收益最大，thinking-tuned 收益最小。从 pass@1 到 pass@256 全面压过 GRPO+EntropyBonus。

优点与局限

优点

  • 问题抓得准：self-distillation 在正确 rollout 上可能扼杀学生自己的 reasoning
  • 方法简单但语义全新：翻转 ratio + reward gate，从 imitation 变成 exploration
  • 分析扎实：因果干预 + distribution shift + pass@k 三层分析

局限

  • 目前是 self-distillation setting，teacher 和 student 共享参数
  • 实验集中在数学推理
  • 尚未探索外部更强 teacher 等更多 context 形式

定位：提出新的 self-distillation 设计轴——teacher 信号可以不是对齐目标而是探索定位器。

RESD: Learning with Rare Success via Reflection-Enhanced Self-Distillation

RESD arXiv abs PDF Code arXiv 2605.12741
核心思想：在标准 SDPO 框架里，把 teacher 看到的失败反馈从"原始错误信息"升级成"reflection + playbook + solution buffer"组成的增强上下文，让 self-teacher 在 rare-success 场景下仍能给出强 token-level 纠错监督。

方法

  • Retrospective Reflection：对失败轨迹做回顾性反思，分析失败原因
  • Playbook Curation：全局持久化经验集，跨 step 积累可复用纠错规则
  • Solution Buffer：缓存稀少成功轨迹供 teacher 参考
  • Success-Rate Rebalancing：按 batch success rate 对样本做梯度再平衡

实验结果

Manufactoria-Has0.380.9535.80
BouncingSim-Easy—1.004.25
Finer—40.9353.66

Manufactoria-Has Per-Test-Case Accuracy: RESD 76.95 vs SDPO 37.66（巨幅提升）。

消融要点

  • 去掉 reflection：Manufactoria-Has 从 76.95 掉到 51.41，影响最大
  • 去掉 playbook：从 76.95 掉到 60.65，跨 step 经验积累不可少
  • 去掉 solution buffer：从 76.95 掉到 60.24

  • 把 failure feedback 从一次性信号变成跨 step 可复用资产
  • 在极低成功率任务上效果非常强

局限

  • Reflection 质量仍依赖模型自身，可能产生"坏经验累积"
  • 更多是 teacher prompt engineering + online memory，非全新优化原理

定位：低成功率阶段更高效的 bootstrapping 工具，建议先 RESD 再切 GRPO 的阶段性训练策略。

SDAR: Self-Distilled Agentic Reinforcement Learning

SDAR arXiv abs PDF Code ZJU-REAL · arXiv 2605.15155
核心思想：把 OPSD 放到多轮 agent RL 场景中，用 token-level detached sigmoid gate 严格调制 teacher guidance，承认 skill-conditioned privileged teacher 只是局部可信，RL 保留为任务优化主干。

方法

  • GRPO 主干 + SDAR 辅助项解耦：RL 对齐任务回报，distillation 只补充 token-level shaping
  • Teacher-student gap $\Delta_t$ 经 detached sigmoid gate 过滤：$g_t=\sigma(\beta\Delta_t)$
  • Gate 只在 teacher 正向背书 student token 时放大 distillation，负向信号温和抑制
  • 使用 reverse KL，mode-seeking 更适合"只吸收 teacher 正向支持"

实验结果

BenchmarkGRPOGRPO+OPSDSDAR
ALFWorld81.280.4 (不稳)85.9
Search-QA42.0—49.0
WebShop Score80.9—89.4

GRPO+OPSD 在 7B ALFWorld 上不稳定，说明 naive OPSD 不是普适解。Random retrieval 仍优于无 OPSD。

优点与局限

优点

  • 问题定位准：多轮 agent OPSD 失败是多重因素叠加
  • 方法简单可插拔：只需两个上下文前向 + token-level gate
  • 对 retrieval 质量不敏感，Random retrieval 仍有收益

局限

  • 依赖 skill library，系统性偏差强时 gate 无法创造正确知识
  • 训练需额外 teacher-context forward pass
  • 仅在 ALFWorld/Search-QA/WebShop 验证

定位：首次把 OPSD 安全接入多轮 agent RL 的工作，核心创新是 token-level detached sigmoid gate。

Vision-OPD: Learning to See Fine Details for Multimodal LLMs via On-Policy Self-Distillation

Vision-OPD arXiv abs PDF arXiv 2605.18740
核心思想：把同一个 MLLM 的"区域裁剪视角"当特权教师、"全图视角"当学生，在 on-policy 轨迹上做 token-level 分布对齐，将"测试时缩放看细节"的收益内化进单次前向推理。

方法

  • 构建三元组数据（全图+红框/裁剪放大图/细粒度问题），约 6.2K 条训练数据
  • 教师：裁剪图条件；学生：全图条件，同一 MLLM
  • EMA teacher 正则（α=0.05）、JSD 散度（β=0.5）、Top-K logits distillation（K=100）
  • 推理时只需单次前向，无需多步工具调用

优点与局限

优点

  • 创新地把"视觉条件差异"作为特权教师构造方式
  • 不增加推理时代理复杂度
  • 训练数据量小（6.2K），性价比高

局限

  • 区域提议偏差会污染监督
  • 验证集中在细粒度视觉问答
  • 未报告详细 benchmark 对比分数

定位：首次将 OPSD 范式引入多模态 LLM 细粒度视觉理解，用"输入条件更清晰的同模态视角"当 teacher。

DASD: Direction-Adaptive Self-Distillation for LLM Reasoning

DASD arXiv abs PDF arXiv 2605.22263
核心思想：把传统"统一吸引式"self-distillation 改成"按 token 不确定性切换吸引/排斥方向"——高熵 fork token 用 repulsion 保持探索，低熵 scaffold token 用 attraction 保持执行稳定。

方法

  • 用 student entropy $H_t$ 做 entropy router 决定 distillation 方向（attraction vs repulsion）
  • 路由系数 $\omega_t = \tanh((\tau_\rho - H_t)/\hat\sigma_H) \cdot \sigma(|\bar\delta_t|-1)$
  • 与 verifier anchor 结合：trajectory-level reward 做全局锚点 + token-level signed correction

实验结果

Model (Avg@16)GRPORLSDDASD
Qwen3-8B46.547.552.5 (+6.0)
Qwen3-4B45.8—49.5
Qwen3-1.7B33.8—37.7

AIME24 诊断：DASD StepAcc 63.7, Exploration density 4.3 vs OPSD 59.1/0.7。8B 时 DASD 优势最明显。

消融要点

  • 低熵+Conformity StepAcc +18.3%，高熵+Novelty exploration +61.3%
  • 路由反了就复现 OPSD 失败模式

优点与局限

优点

  • 诊断链条完整：failure analysis → token probe → causal intervention → 方法设计
  • 方法实现干净：最终只是 token-level correction 写进 advantage
  • Scaling 性能好：模型越大 margin 越大

局限

  • 依赖 privileged context 和 verified trace
  • Entropy 是否总是最好的 router 在 agent/multimodal 下未确定
  • 实验主体集中在 math reasoning

定位：在 OPSD 谱系中首次把"distillation direction"作为独立设计维度，提出 entropy-routed signed KL 框架。
