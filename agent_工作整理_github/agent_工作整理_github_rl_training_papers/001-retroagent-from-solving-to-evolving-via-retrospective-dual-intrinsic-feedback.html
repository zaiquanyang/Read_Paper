RetroAgent: From Solving to Evolving via Retrospective Dual Intrinsic Feedback

arXiv 2603.08561GitHub
agent arXiv abs PDF Code arXiv 2603.08561
核心思想：RetroAgent 把 agent RL 的目标从“单轮解题”推进到“持续进化”。它在 extrinsic reward 之外，通过 hindsight self-reflection 生成 intrinsic numerical feedback 和 intrinsic language feedback，分别奖励有潜力的探索轨迹，并把可复用经验沉淀成 lesson memory。

问题与动机

作者针对的是标准 RL for LLM agents 的两个老问题：一是只盯最终任务奖励，容易导致探索不足、过早收敛到次优策略；二是过往经验虽然写进了模型参数，却难以被显式检索和复用，导致 agent 很难像人一样“做完一轮后总结经验，下次直接带着经验上场”。

因此这篇论文的切口不是再换一个 RL objective，而是把 episode 结束后的 retrospective reflection 正式纳入训练闭环，让 agent 同时学会：这次探索是否比过去更接近目标，以及哪些经验值得被保存并在后续相似任务中调用。

方法核心

RetroAgent 在每轮轨迹结束后，生成一个 reflection tuple $z = (\phi_{(x,\tau)}, c, l)$：

  • $\phi_{(x,\tau)}$ 是 potential score，用于衡量当前轨迹相对历史尝试的增量 subtask progress。
  • $c$ 是对本轮是否成功的自我判断，供 reflection 自身训练使用。
  • $l$ 是 retrospective lesson，会被写进 memory buffer，在后续相似任务中检索使用。

其中最关键的两条反馈链分别是：

  • Intrinsic numerical feedback：把“比历史最佳更接近成功”的增量进步转成 capability-evolution reward，避免只有最终 success 才有学习信号。
  • Intrinsic language feedback：通过 SimUtil-UCB 从 lesson memory 中联合考虑 relevance、historical utility 和 exploration coverage 做检索，避免记忆系统只重复使用少数高频经验。

训练时，一半 rollout 使用 base policy，一半 rollout 使用 memory-augmented policy，因此 agent 既保留独立探索，又逐步把 lesson 内化进参数。论文还给了两个 reflection 版本：一个是 pairwise in-context reflection，另一个是把 reflection 能力也一并放进 RL 联合优化的 RL-trained variant。

  • 相对 GRPO，RetroAgent 在四个环境上分别提升约 +18.3%、+15.4%、+27.1%、+8.9%，说明 hindsight dual feedback 比只看环境奖励更适合长程 agent 训练。
  • 在 WebShop 消融里，单独加 capability-evolution reward 就能把 success 从 66.9 提到 79.7；单独加 memory retrieval 也能到 78.6，说明数值反馈和语言反馈各自都有效，而且确实互补。
  • SimUtil-UCB 明显优于只按 similarity 或 similarity+utility 的记忆检索，表明 memory retrieval 里如果没有 exploration bonus，agent 很容易被少数高频 memory 绑住，越检索越局部。
  • 测试时的 Discovery@k 也很强：WebShop 在三次尝试内可从 82.3% 提到 99.0%，ALFWorld 的 OOD setting 可到 100.0%，说明这种 retrospective feedback 同时提升了 repeated attempts 下的自我修正能力。

价值、局限与启发

  • 这篇工作的真正价值不在“又做了一个 memory agent”，而在于它把 hindsight reflection 直接变成训练信号，让 agent 能同时学习“什么探索值得继续”和“什么经验值得保存”。
  • 它非常适合作为 `agent / RL training` 这条线里的代表工作，因为 RL、memory、test-time adaptation 三条线在这里是同一个闭环，而不是分散的模块工程。
  • 局限也很清楚：memory 仍是 lesson-level text buffer，reflection 质量高度关键；一旦自评不稳，potential score 与 lesson 质量都会波动，训练稳定性会受影响。
