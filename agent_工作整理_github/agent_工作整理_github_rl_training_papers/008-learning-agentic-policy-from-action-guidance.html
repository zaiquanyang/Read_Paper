Learning Agentic Policy from Action Guidance

agent arXiv abs PDF Code
核心思想：ActGuide-RL 的核心贡献是把“动作轨迹引导”系统化为一种最小干预的 agentic RL 训练机制，在不依赖重 cold-start SFT 的前提下，显著提升了弱到中等基座在困难 agent 任务上的可学习性与最终性能。

问题与动机

这篇论文讨论的是 agentic RL 的一个核心难点：可达性屏障（reachability barrier）。

作者认为，在长程 agent 任务里，RL 信号只会出现在当前策略“能力可达区间”内；一旦任务奖励状态落在能力边界之外，策略采样不到成功轨迹，group-based advantage 就会塌成零梯度，训练卡死。

典型做法是 SFT 冷启动再 RL，但这会带来：

  • 强依赖大规模 warm-start 数据。
  • 训练流程复杂，难扩到新环境。
  • 可能牺牲 out-of-domain 泛化。

论文提出：利用已有的“动作数据”（action trajectories）做训练期引导，而不是再依赖大量高质量 CoT/SFT。由此得到方法 ActGuide-RL。

论文强调一个关键结论：即使不做 cold-start SFT，ActGuide-RL 也能接近 SFT+RL 的 in-domain 表现。

而在同样有 SFT cold-start 的情况下，继续加 ActGuide 仍有额外收益。

这意味着 action guidance 可以部分替代重 SFT 依赖，形成更轻量的 agentic RL 路线。

方法核心

ActGuide-RL 的核心是把 action data 当作“参考计划”（plan-style guidance）注入训练 rollout：

  • 先跑一批无引导 rollout。
  • 若整组都失败（零奖励），再触发 guidance fallback。
  • 动态选择“最小足够引导强度”。
  • 把 guided 和 unguided 轨迹一起做 mixed-policy 优化，把引导期学到的探索能力内化回无引导策略。

实验与结论

  • 场景: search-agent
  • In-domain benchmark: GAIA, WebWalkerQA, XBench, BrowseComp-ZH
  • Out-of-domain benchmark: GPQA, TruthfulQA, IFEval
  • 基座: Qwen2.5-3B/7B, Qwen3-4B/8B
  • 对比: ZeroRL（无 guidance）、SFT+RL、其他公开 agent 模型

去掉任一关键组件都会掉点，尤其：

  • 去掉 minimal-intervention adaptive 选择会显著退化。
  • 去掉 fallback 机制会严重退化。
  • 去掉 mixed-policy optimization 也会大幅退化。

价值、局限与启发

  • 提出并实证验证了 reachability barrier 视角，解释了 agentic RL 卡死根因之一。
  • 用可扩展 action data 替代部分重 SFT 依赖，工程上更轻。
  • 动态最小干预 + 混合优化设计完整，且跨模型稳定收益。
  • 当前实验主要在 search-agent 场景，跨 GUI/CLI/embodied 泛化还需更多验证。
  • 对 action data 质量仍敏感，高噪声下会退化。
  • 理论单调假设在复杂现实任务中未必总成立。
  • 先判断训练失败是“采样预算不足”还是“可达性屏障导致的结构性失败”。
  • 如有现成动作轨迹数据，优先尝试训练期 fallback guidance，而非直接堆更重 SFT。
  • 关键不是 guidance 越强越好，而是“最小足够”并动态匹配任务难度。
  • 若使用引导数据，必须设计明确的内化机制（如 mixed-policy 优化），否则推理时会失效。

ActGuide-RL 的核心贡献是把“动作轨迹引导”系统化为一种最小干预的 agentic RL 训练机制，在不依赖重 cold-start SFT 的前提下，显著提升了弱到中等基座在困难 agent 任务上的可学习性与最终性能。
