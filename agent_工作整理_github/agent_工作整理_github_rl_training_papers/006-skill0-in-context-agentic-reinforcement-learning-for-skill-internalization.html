方法核心

受人类技能习得过程的启发（从"看说明书操作"到"肌肉记忆自主执行"），本文提出一个新问题：能否将 skills 直接内化到模型参数中，使得推理时完全不需要任何 skill 检索？

RL 已被证明可以将推理能力（reasoning）从 prompt-dependent 行为转化为内在能力（如 DeepSeek-R1）。本文将同样的思路迁移到 agent skills：通过训练课程从"有 skills 指导"渐进过渡到"无 skills 自主执行"，将能力从 context 转移到 parameters。

图：(a) 传统 Skill 增强方法 vs (b) SKILL0 的 Skill 内化方法

SKILL0 是一个 In-Context Reinforcement Learning (ICRL) 框架，核心思想是：训练时提供 skills 作为 in-context 指导，但通过动态课程逐步撤除，最终在推理时实现完全 zero-shot 自主执行。

框架包含三个核心组件：

  • (a) Relevance-Driven Skill Grouping（离线阶段）
  • (b) In-Context Reinforcement Learning（训练循环）
  • (c) Dynamic Curriculum Learning（自适应课程）

图：SKILL0 方法总览

课程设计分为两个层面：

(a) 离线阶段：Relevance-Driven Skill Grouping

  • 将验证集按技能需求划分为 $N$ 个子任务 $\{\mathcal{T}_k\}_{k=1}^N$
  • 每个 $\mathcal{S}_k$ 对应一个专用验证子任务 $\mathcal{T}_k$，用于评估其有用性

(b) 在线阶段：Helpfulness-Driven Dynamic Curriculum

将训练分为 $N_S$ 个阶段，每阶段 skill 预算 $M^{(s)}$ 线性衰减：

\[M^{(s)} = \lceil N \cdot (N_S - s) / (N_S - 1) \rceil\]

每 $d$ 步执行一次 Helpfulness 评估：

  • 在子任务 $\mathcal{T}_k$ 上分别评估"有 skill $\mathcal{S}_k$"和"无 skill"的准确率
  • 计算 helpfulness $\Delta_k = \text{Acc}_k^{\text{w/skill}} - \text{Acc}_k^{\text{w/o skill}}$
  • Filter：只保留 $\Delta_k > 0$ 的 skills
  • Rank：按 $\Delta_k$ 降序排列
  • Select：取 top-$M^{(s)}$ 个

当模型已将某个 skill 内化到参数中后，$\Delta_k$ 趋近于 0，该 skill 被自动过滤掉，形成自定步调课程。

实验与结论

基准测试：

  • ALFWorld：文本环境具身任务（6 类家居活动），3827 个任务实例
  • Search-QA：搜索增强 QA（单跳 + 多跳），包含 NQ、TriviaQA、PopQA、HotpotQA、2Wiki、MuSiQue、Bamboogle

基线方法：

  • 推理时 skill 增强：Few-Shot, EvolveR, SkillRL
  • RL 方法：GRPO, AgentOCR
  • 记忆方法：Mem0, ExpeL, MemP, MemRL, SimpleMem
  • 搜索方法：Search-R1, ZeroSearch, Search-o1 等
  • 闭源模型：GPT-4o, Gemini-2.5-Pro

实现细节：Qwen2.5-VL 系列，最多 180 步训练，4×H800 GPU，$N_S=3$，SkillBank 从 SkillRL 继承。

关键发现：

  • SKILL0 (3B) 在 ALFWorld 上超越 AgentOCR +9.7%，在 Search-QA 上超越 +6.6%
  • 与需要 skill 增强的 SkillRL 竞争甚至更强，但推理时完全不需要 skills
  • Token 成本仅为 SkillRL 的 1/5 甚至更低（0.38k vs 2.21k）

扩展比较：

  • ALFWorld: SKILL0 (89.8) 大幅超越 ExpeL (46.3), Mem0 (54.7), MemRL (21.4)，也超越 GPT-4o (48.0) 和 Gemini-2.5-Pro (60.3)
  • Search-QA: SKILL0 (44.4) 超越 Search-R1 (38.5), ZeroSearch (39.1), EvolveR (43.1)
  • 在域外多跳数据集 Bamboogle 上表现特别突出（63.7%/66.9%）

价值、局限与启发

当前主流范式是 inference-time skill augmentation：在每一步从 Skill 库中检索相关 Skills，注入到模型的 context 中作为自然语言引导。这种方式存在三个根本性局限：

  • 检索噪声污染上下文：不相关或误导性的 skill 描述会损坏 agent 的决策上下文
  • Token 开销过大：注入的 skill 内容在多轮交互中不断累积，限制了可扩展性
  • 模型并未真正"学到"：模型只是在执行 context 中描述的 skills，而非将能力内化到参数中——"competence resides in the context, not in the model"
  • 首个将 skill 内化作为显式训练目标的 RL 框架，提出了从"工具增强"到"真正自主"的新范式方向
  • Dynamic Curriculum 设计精巧：基于 on-policy helpfulness 自适应筛选 skills，替代了刚性的预定义课程，实现了自定步调的学习
  • Token 效率极高：视觉上下文渲染 + skill 内化使得每步上下文 < 0.5k tokens，比 SkillRL 低 5 倍以上
  • 性能全面领先：在 ALFWorld 和 Search-QA 上均大幅超越 RL baseline，与 skill-augmented 方法持平或更强
  • 理论支撑：提供了线性衰减课程下 KL 散度有界性证明，确保阶段间策略分布平滑过渡
  • 泛化性强：在域外多跳数据集（如 Bamboogle）上表现突出，证实内化知识可迁移
  • 依赖初始 SkillBank 质量：如果初始 skills 质量差，内化效果受限。论文使用 SkillRL 继承的 SkillBank，未探索从零构建
  • 离线 relevance grouping 需要人工定义：迁移到新任务领域时需要重新划分验证集子任务
  • 仅在相对简单的环境验证：ALFWorld（文本游戏）和 Search-QA 与真实世界的复杂 agent 场景差距较大
  • 未与最新的 agentic RL 方法（如 DAPO）对比：基线选择有一定时效性
  • 视觉渲染的通用性存疑：context rendering 依赖特定的渲染配置（字体、颜色编码），不同环境需要手动调参...
