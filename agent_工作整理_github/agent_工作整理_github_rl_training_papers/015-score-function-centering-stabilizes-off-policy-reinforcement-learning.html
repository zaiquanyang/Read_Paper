Score Centering Stabilizes Off-policy Reinforcement Learning

arXiv 2609.20807GitHub
Martin Marek · Max Ryabinin2026-09摘要页PDF
核心判断：异步 RL 中，rollout 由 generator 的行为分布 $q$ 产生，但 trainer 用当前策略 $p$ 重新计算 score。两者不一致会让 score 在 $q$ 下出现非零均值，产生与 reward 无关的 drift。Score Centering（SC）按真实采样分布把 score 重新中心化，恢复 baseline invariance，显著提高训练稳定性；当 staleness 较大时，再与 importance sampling 结合。

问题与动机

在线训练通常将生成和训练拆到不同引擎：generator 可能使用量化、不同 kernel、KV cache 或较旧 checkpoint，而 trainer 用当前权重计算 log-prob。因此样本来自 $q$，梯度却使用 $p$ 的 score。即使模型权重看似接近，数值 mismatch 和异步 staleness 也会在长 rollout 中累积。

在严格 on-policy 情况下，score $s_\theta(a)=\nabla_\theta\log p_\theta(a)$ 满足 $\mathbb E_p[s_\theta]=0$，所以减去只依赖 prefix 的 baseline 不改变期望梯度。换成 $a\sim q$ 后，这个零均值性质通常失效。

Drift 从哪里来

\[\mathbb E_q[R s_\theta]=\underbrace{\mathbb E_q[R]\,\mathbb E_q[s_\theta]}_{\text{drift}}+\underbrace{\operatorname{Cov}_q(R,s_\theta)}_{\text{reward-token signal}}.\]

第一项只反映 reward 均值和 sampler 下的平均 score，不关心哪条轨迹成功；它会把 trainer 持续拉向 generator 的偏置。GRPO 的 group centering 只能让同一组样本的 reward 均值为零，不能保证每个 prefix 下的 score 均值为零，因此无法从原理上消除该 drift。

Score Centering 的方法

对固定 prefix，在行为分布 $q$ 下计算平均 score，并定义：

\[\tilde{s}_\theta(a)=s_\theta(a)-\bar{s},\qquad \bar{s}=\mathbb E_{v\sim q}[s_\theta(v)].\]

于是 $\mathbb E_{a\sim q}[\tilde{s}_\theta(a)]=0$，更新只保留 $\operatorname{Cov}_q(R,s_\theta)$。这恢复了“减去 prefix baseline 不改变期望”的性质，但它并不把 $q$ 下的 covariance 自动变成目标策略 $p$ 下的 policy gradient；distribution shift 仍需要 IS 处理。

\[L_{\mathrm{SC}}=-A(a)\left(\log p_\theta(a)-\sum_v\operatorname{sg}[q(v)]\log p_\theta(v)\right).\]

利用 softmax 的归一化项，等价的 logit surrogate 是 $-A(a)[z_\theta(a)-\mathbb E_q z_\theta(v)]$，不需要显式保存完整词表的 Jacobian。

可实现的 Top-k 近似

完整保存每个位置的 sampler 词表分布成本过高。论文记录 sampler 的 top-$k$ head（默认 $k=128$），其余 tail 使用 trainer 分布并按 sampler 的 tail mass 重缩放：

\[\hat q_v=\begin{cases}q_v,&v\in H,\\\rho p_v,&v\in T,\end{cases}\qquad \rho=\frac{1-\sum_{v\in H}q_v}{1-\sum_{v\in H}p_v}.\]

由于 trainer 自身的完整 score 均值为零，tail 的贡献可以由 head residual 间接得到，最终只需对 sample token 和 top-k token 做前向计算。工程流程是：generator 记录 sample log-prob、top-k IDs、top-k mass 与 tail mass；trainer 重算这些 token 的 logits；再用 stop-gradient 的系数构造 SC loss。

训练稳定性诊断：offline 与 online mismatch

实验与核心结论

  • 在 Qwen3-1.7B Countdown 诊断中，offline SFT 对 mismatch 不敏感，而 online RL 在 $+1/0$ reward 下更容易失稳；group-centered reward 相对稳定。
  • 人工加入 sampler weight noise 时，SC 及 SC+TIS/MIS 比 vanilla policy gradient、TIS/MIS 单独使用更能延后 collapse。
  • 量化 mismatch 与 staleness 的实验显示，SC 主要去除行为分布下的 drift；staleness 较大时，SC+TIS/MIS 通常优于单独 SC。
  • 在 Qwen3-30B-A3B 的 INT8 W/A + INT4 KV 设置下，SC 仍保持约 30% 训练准确率，而其他方法最终低于 5%；top-$k$=128 通常覆盖超过 99%的 sampler mass，且相对 baseline 的额外耗时约 1%。

与 Importance Sampling 的关系

SC 解决的是 score 均值偏移，IS 解决的是行为分布 $q$ 与目标分布 $p$ 的重加权。二者可组合为对加权 score 做中心化：

\[R\left(w_a s_\theta(a)-\mathbb E_q[w_v s_\theta(v)]\right).\]

精确 IS 在期望上已经恢复目标策略梯度，因此额外 SC 项消失；实际 TIS/MIS 会裁剪或 mask 权重，引入新的偏差，所以仍可能从 SC 中受益。

价值、边界与实践启发

  • 价值：SC 是一个加法修正，不需要完整词表分布，适合 generator/trainer 分离、量化或异步的 RL 系统；top-k head + rescaled tail 让它具有工程可行性。
  • 边界：SC 不等于完整 off-policy 校正，也不能自动解决 reward misspecification、credit assignment 或长轨迹问题；它在 $q$ 下恢复的是 covariance，而非必然等于 $p$ 下的目标梯度。
  • 实践：先用 prefix 级别的 $\mathbb E_q[\tilde s]$ 和 reward 均值做 sanity check，再分别记录数值 mismatch、checkpoint lag、量化方式、KV cache 类型和 top-k mass；当 staleness 明显时采用 SC+TIS/MIS。
