问题与动机

当前 LLM Agent 主流范式 ReAct 存在根本性的探索瓶颈：Agent 在每一步只能执行一个动作、观察一个反馈，从狭窄的线性视角构建环境认知。这导致：

  • 探索多样性不足：多次采样的轨迹倾向于收敛到相同动作选择，无法覆盖环境的多样动态
  • 环境理解片面：单路径推理使得 Agent 对环境的认知不完整且有偏差，导致复杂任务中的次优决策

方法核心

当前 LLM Agent 主流范式 ReAct 存在根本性的探索瓶颈：Agent 在每一步只能执行一个动作、观察一个反馈，从狭窄的线性视角构建环境认知。这导致：

  • 探索多样性不足：多次采样的轨迹倾向于收敛到相同动作选择，无法覆盖环境的多样动态
  • 环境理解片面：单路径推理使得 Agent 对环境的认知不完整且有偏差，导致复杂任务中的次优决策

核心问题：能否让 Agent 同时与多个并行环境交互，共享跨环境经验，从而构建更全面的环境认知？

DPEPO 采用两阶段训练范式：

  • SFT 冷启动：用 DeepSeek-V3.2 标注的并行探索轨迹（~500 条 ALFWorld / ~1000 条 ScienceWorld）微调 Agent，使其具备基本的并行推理和动作生成能力
  • RL 层次化奖励优化：基于 GRPO 框架，引入轨迹级 + 步级的层次化奖励信号

价值、局限与启发

  • 仅在文本环境中验证：实验限于 ALFWorld（纯文本）和 ScienceWorld（模拟器），未涉及真实世界或多模态场景
  • 环境数量固定：训练时 K=4 个并行环境，动态环境数量选择策略未深入探索
  • 冷启动依赖强教师模型：SFT 数据依赖 DeepSeek-V3.2 标注，标注质量受限
  • 环境间无差异化激励：所有并行环境同质（共享初始状态），未探索异构环境并行
  • 未与序列级方法结合：DPEPO 替代了 ReAct，但未研究与 Reflexion 等反思机制的结合
  • 异构并行探索：不同并行环境可设置不同的初始条件或难度，增强探索覆盖面
  • 动态并行度选择：Agent 自适应决定何时需要并行探索、需要多少并行环境
  • 与反思机制结合：将 DPEPO 的并行探索与 Reflexion 式的自我反思结合，形成"探索-反思-再探索"闭环
  • 扩展到多模态 Agent：在 Web 导航、GUI 操作等视觉 Agent 场景中验证并行探索的收益
  • 自适应奖励权重：根据任务阶段动态调整 DAR 和 DTR 的权重（早期鼓励探索，后期鼓励收敛）
