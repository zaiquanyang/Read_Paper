方法核心

现有 memory-based 方法主要将原始轨迹直接存入外部数据库，存在以下问题：

  • 冗余和噪声：原始轨迹冗长，包含探索性动作、回溯和冗余步骤，信息密度低
  • 缺乏抽象：仅模仿过去的解决方案，无法蒸馏核心原则或将经验内化为策略
  • 上下文膨胀：在有限的 context window 中，原始轨迹占用大量 token 却贡献有限
  • 静态记忆：记忆库作为静态资源，无法随 agent 能力增长而演化

人类专家不会记住每个情境中的每个动作，而是发展出技能（skills）——紧凑、可复用的策略，捕捉完成子任务的本质。受此启发，本文提出 SkillRL，通过自动技能发现和递归演化，弥合原始经验与策略提升之间的鸿沟。

SkillRL 包含三大核心组件：

  • Experience-based Skill Distillation：将冗余轨迹蒸馏为简洁、可操作的知识
  • Hierarchical Skill Library (SkillBank)：分层组织蒸馏出的技能，支持高效检索
  • Recursive Skill Evolution：在 RL 训练中动态精炼技能库，使其与 agent 策略协同演化

实验与结论

环境：ALFWorld, WebShop, 7 个 search-augmented QA 任务

模型：

  • Base model: Qwen2.5-7B-Instruct
  • Teacher model: OpenAI o3

超参数：

  • SFT: lr=1e-4, batch=16, 3 epochs, ALFWorld 7500 例 / WebShop 2400 例
  • RL: lr=1e-6, batch=64, group size=8, KL coef=0.01, 150 epochs
  • Skill retrieval: Top-K=6, validation interval=5 steps, update threshold δ=0.4
  • 计算资源：8×H100 80GB, 总耗时约 30 小时

核心发现：

  • 去除技能库（用原始轨迹）导致最大退化（ALFWorld -28.2%），直接验证了"抽象优于记忆"的核心假设
  • Cold-start SFT 极其关键（-24.7%），base model 需要先学习如何使用技能
  • 层级结构重要（-13.1%），通用策略原则提供基础指导
  • 动态演化贡献 +5.5%，确保技能库是动态组件而非静态数据库

价值、局限与启发

现有 memory-based 方法主要将原始轨迹直接存入外部数据库，存在以下问题：

  • 冗余和噪声：原始轨迹冗长，包含探索性动作、回溯和冗余步骤，信息密度低
  • 缺乏抽象：仅模仿过去的解决方案，无法蒸馏核心原则或将经验内化为策略
  • 上下文膨胀：在有限的 context window 中，原始轨迹占用大量 token 却贡献有限
  • 静态记忆：记忆库作为静态资源，无法随 agent 能力增长而演化

如 Figure 1 所示，raw trajectory memory 在训练中甚至可能因引入噪声而导致性能下降。

  • 从经验到技能的抽象范式：首次系统性地将原始轨迹蒸馏为结构化技能，token 压缩 10-20x
  • 分层技能库设计：General + Task-Specific 的两层结构兼顾通用性和专业性
  • 递归演化机制：技能库随 RL 训练动态增长，形成 agent 与技能库的协同演化
  • 冷启动 SFT 有效：解决了"有技能但不会用"的 bootstrapping 问题
  • 性能显著：7B 模型超越 GPT-4o/Gemini-2.5-Pro，ALFWorld 89.9% SOTA
  • 搜索任务泛化好：训练在 NQ+HotpotQA，OOD 任务表现稳健
  • 上下文效率高：更少 token 获得更好性能
  • 开源代码：github.com/aiming-lab/SkillRL
  • 依赖强 teacher 模型：使用 OpenAI o3 做蒸馏和 SFT 数据生成，成本高且有外部依赖
  • 验证间隔固定：每 5 步做一次 validation，演化频率是固定的
  • 演化上限阈值：仅在 $Acc(C) < 0.4$ 时触发演化，阈值选择较经验化
  • 技能可解释性有限：虽然比原始轨迹紧凑，但技能仍是 LLM 生成的文本，质量依赖 teacher
  • 评估范围：主要在 ALFWorld、WebShop 和 search QA 上，未涉及更复杂的软件工程任务
  • 二值奖励：使用 0/1 奖励，未探索更细粒度的奖励信号
  • 技能检索基于语义相似度：对于复杂任务可能检索到不相关的技能
  • 技能蒸馏可直接复用：对任何 agent 训练，用强 teacher 将轨迹蒸馏为结构化技能，比存储原始轨迹更高效...
