问题与动机

终端 Agent 任务：$\tau = (\mathcal{E}, s_0, g, V)$，Agent 从初始状态 $s_0$ 在环境 $\mathcal{E}$ 中达成目标 $g$。

场景与技能抽象：

  • 场景 (Scenario) $\sigma_t$：决策点上观察的语义抽象，是到该步交互历史的充分统计量
  • 技能 (Skill) $\kappa_t$：在一个场景下应用的动作子序列，产生到下一个场景的可预测转移：$\kappa_t: \sigma_{t-1} \to \sigma_t$
  • 低层轨迹 $\zeta$ 被提升为执行轨迹：$\xi = (\sigma_0, \kappa_1, \sigma_1, ..., \kappa_L, \sigma_L)$

学习目标：

\[\mathcal{J}(\pi) = \sum_{\sigma \in \Omega} p_{\mathcal{D}}(\sigma|g) \sum_{\kappa \in \mathcal{K}_\sigma} p_{\mathcal{D}}(\kappa|\sigma,g) \log \pi(\kappa|\sigma,g)\]

这个分解明确显示：$p_{\mathcal{D}}(\sigma|g) = 0$ 的场景不可观测，$p_{\mathcal{D}}(\kappa|\sigma,g) = 0$ 的技能未被练习。因此需要训练数据在 $\{(\sigma, \kappa)\}$ 上密集覆盖——这直接驱动了本文的技能图构建方法。

方法核心

为了理解什么使训练轨迹有用，需要看 Terminal Agent 如何工作：Agent 通过逐步与一系列中间场景 (scenarios) 交互来执行，在每个场景应用一个技能 (skill) 来推进任务。因此执行轨迹由两个维度联合表征：遍历的场景和运用的技能。

现有工作主要沿以下路径扩展：

  • LLM 生成分类法扩大领域覆盖（Endless Terminals、TermiGen、Nemotron-Terminal）：往往偏离真实世界使用模式
  • 从 GitHub 仓库派生任务（CLIGym、SWE-Universal）：局限于软件工程领域（issue 修复、功能开发）

这些方法提供了有限的对底层场景和技能组合的显式控制。如 Figure 1 所示，生成的轨迹在场景覆盖和技能使用上存在冗余：不同任务实例常暴露 Agent 到重叠的场景并复用相似的技能。

从学习目标的分解（Equation 3）可以明确看出：策略的可学习区域受限于训练数据在场景-技能联合空间的支持。因此，最大化训练数据在 $\{(\sigma, \kappa)\}$ 条件积空间的密集覆盖是关键目标。

本文提出 SkillSynth：通过场景中介的技能图 (scenario-mediated skill graph) 来控制轨迹多样性，从图中采样路径作为真实工作流的抽象，再通过多 Agent harness 将其实例化为可执行任务。

SkillSynth 的任务合成分三个阶段：

  • 构建技能图：场景为节点，技能为有向边（从前置条件场景指向后置条件场景）
  • 图引导路径采样：从图中采样有向路径，指定需要顺序执行的技能组合及其遍历的场景
  • 多 Agent Harness 实例化：将采样路径转化为具体的可执行任务实例（自然语言指令 + 初始文件系统快照 + 容器化环境 + 验证脚本 + Oracle 解答）

SkillSynth 三阶段框架：技能图构建 → 图引导路径采样 → 多 Agent Harness 实例化

价值、局限与启发

为了理解什么使训练轨迹有用，需要看 Terminal Agent 如何工作：Agent 通过逐步与一系列中间场景 (scenarios) 交互来执行，在每个场景应用一个技能 (skill) 来推进任务。因此执行轨迹由两个维度联合表征：遍历的场景和运用的技能。

现有工作主要沿以下路径扩展：

  • LLM 生成分类法扩大领域覆盖（Endless Terminals、TermiGen、Nemotron-Terminal）：往往偏离真实世界使用模式
  • 从 GitHub 仓库派生任务（CLIGym、SWE-Universal）：局限于软件工程领域（issue 修复、功能开发）

这些方法提供了有限的对底层场景和技能组合的显式控制。如 Figure 1 所示，生成的轨迹在场景覆盖和技能使用上存在冗余：不同任务实例常暴露 Agent 到重叠的场景并复用相似的技能。

  • 首次将技能图用于可控终端任务合成：通过场景中介的技能图显式控制轨迹在场景×技能空间的多样性，而非仅扩展任务数量
  • 理论支撑扎实：从学习目标分解推导出覆盖准则（$\Omega \times \mathcal{K}$ 均匀覆盖），逆频采样直接优化该准则
  • 高质量大规模合成：95.7% Oracle 通过率，92.0% 双验证通过率，单次运行产出 3,560 个可用任务，每任务仅 $27.3
  • 实际工业验证：合成任务已用于训练混元 Hy3 Preview，证实了工业级有效性
  • 图的可扩展性：随着社区贡献更多 skills，图持续扩展，支持持续合成
  • 依赖初始 Skill 来源质量：从 ClawHub 和 GitHub 收集的 skills 可能有偏差，覆盖不均匀
  • 场景推断依赖 LLM 质量：前置/后置条件场景的推断质量受 LLM 能力限制，可能引入噪声
  • 路径采样限于链式结构：当前只采样链式路径，未来可扩展到子图采样（并行执行多技能），增加任务复杂度
  • Harness 修复有天花板：文件系统快照损坏等严重错误无法通过修复恢复，存在修复下限
  • 评估仅限于 Terminal-Bench：未在其他 agent 基准（如 SWE-bench、WebArena）上验证泛化性...
