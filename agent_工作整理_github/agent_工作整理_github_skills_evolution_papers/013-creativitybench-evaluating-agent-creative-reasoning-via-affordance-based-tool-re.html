方法核心

定义：推断和利用物体的 Affordance（由其物理属性启用的行动可能性），以新颖且非常规的方式实现目标。

核心洞察：工具的用途不仅限于其设计目的，更在于其结构和物理属性所能启用的动作。例如，钥匙可以用来撬开密封盒子，因为其尖锐的尖端结构提供了撬开或切割的 affordance。

创造性工具使用需要：

  • 推理部件级属性（刚性、弹性等）→ 映射到功能 affordance（切割、撬开等）
  • 发散思维但锚定物理约束
  • 将已有知识和工具使用经验重新组合为新方案

CreativityBench 包含两大核心组件：

  • Affordance Knowledge Base（KB）：4K 实体、26K 部件、150K+ affordance 标注
  • CreativityBench 任务集：14K 个 grounding 创造性工具使用任务

实验与结论

  • MacGyver：评估非常规物理问题解决，但不围绕 affordance 结构显式构建
  • EscapeBench：模拟密室环境中的创造性推理，但不建模部件级物理属性
  • Creation-MMBench / VisEscape / VillagerBench：多模态/交互环境中的创造性任务，但强调规划和执行而非 affordance 发现

共同不足：不需要模型在部件级物理属性上做 grounding，也不要求显式推理 affordance 涌现机制。

结构化 CoT 改善了 grounding 和过程准确性，但约束了发散思维。根本问题不是推理结构缺失，而是缺乏可灵活重组的 grounding affordance 知识。

采用逆向工程过程：从已知 affordance 反向合成场景，确保每个任务有明确的 ground-truth 推理轨迹。

价值、局限与启发

  • MacGyver：评估非常规物理问题解决，但不围绕 affordance 结构显式构建
  • EscapeBench：模拟密室环境中的创造性推理，但不建模部件级物理属性
  • Creation-MMBench / VisEscape / VillagerBench：多模态/交互环境中的创造性任务，但强调规划和执行而非 affordance 发现

共同不足：不需要模型在部件级物理属性上做 grounding，也不要求显式推理 affordance 涌现机制。

  • 首个大规模 affordance-grounded 创造性 Benchmark：从"为人类设计"转向"评估 Agent 创造性智能"，填补了三元智力理论中创造性维度的评测空白
  • 结构化 Affordance KB 极具价值：4K 实体、150K+ affordance 标注，层次化建模实体→部件→属性→affordance，可复用于训练、评估和轨迹构建
  • 逆向工程任务构建保证 ground-truth：从已知 affordance 反向合成场景，确保每个任务有明确的正确答案和推理路径
  • 多维度细粒度评估：客观 Tool Usage 指标 + LLM-as-Judge 的 6 维 Likert 评估，区分了"选对工具"和"用对工具"
  • 深刻的分析发现：推理能力和创造性发现能力分离、规模饱和、相似干扰物反直觉辅助效应、Interactive 模式的过早承诺问题
  • 人类研究提供了有价值的参照：人类因认知负荷低于模型，但 gold 解决方案验证有效
  • 仅文本模态：当前 Benchmark 纯文本，未涉及视觉 grounding（看物体图片推断 affordance）
  • 场景限于室内家居：8 个场景均为室内环境，未覆盖户外、工业等场景
  • LLM-as-Judge 评估偏差：辅助维度依赖 Gemini-3.1-Flash-Lite 评判，存在 judge 模型特有偏差
  • Affordance KB 的 LLM 生成质量：使用 GPT-5.2 自动扩展标注，可能存在噪声
  • 人类研究规模有限：仅 10 人、100 个任务，且人类因认知负荷表现低于模型，难以完全验证 benchmark 难度设计
  • 未涉及训练改进：仅评估未提出改进方法，讨论中提到的方向（物理-文本双重推理、foresight governance）有待实现...
