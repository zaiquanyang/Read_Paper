GenEvolve: Self-Evolving Image Generation Agents via Tool-Orchestrated Visual Experience Distillation

agent arXiv abs PDF Project arXiv 2605.21605
核心思想：GenEvolve 不再把 open-ended image generation 看成“改写一次 prompt”这么简单，而是把整条生成过程重写成 agent trajectory：什么时候去搜索事实、什么时候找参考图、什么时候调用内部生成技能、最后如何把这些信息拼装成可执行的 prompt-reference program。真正的新意在于，它不仅用 GRPO 优化最终结果，还从同一请求下的 best/worst trajectories 中提炼 structured visual experience，再蒸馏回 student policy。

问题与动机

作者关心的是一个比“文生图提示词优化”更大的问题：复杂图像请求往往同时需要外部事实检索、视觉参考筛选、内部绘图知识调用、约束绑定与失败规避，因此本质上更像多步 agent 决策，而不是单轮 prompt engineering。

  • 外部信息需求：人物、地点、产品、年份、品牌等事实经常需要 search 才能补齐。
  • 视觉锚点需求：用户常常并不只要语义对，还要特定姿态、材质、构图与风格。
  • 生成知识需求：文本渲染、空间布局、attribute binding、数量计数等 failure mode 需要专门的 skill guidance。

因此论文的关键判断是：如果只给最终图像一个 scalar reward，模型很难知道究竟是 search query 写坏了、reference 选错了，还是 prompt 没把 layout / text rendering 约束绑定进去。

方法核心

GenEvolve 把一次图像生成轨迹建模成 tool-orchestrated visual trajectory。agent 在多轮交互里调用三类工具：文本 search、image search，以及按需查询内部 generation knowledge。最终输出不是普通 prompt，而是一个 prompt-reference generation program：

  • gen_prompt：面向 generator 的最终指令。
  • reference_images：按角色组织的参考图，而不是无结构图片堆叠。
  • selected_skills：显式激活 text_rendering、spatial_layout、attribute_binding 等内生绘图知识。

训练上分两层：

  • SFT 冷启动：先把模型教会基本的 tool orchestration 和 program 输出格式。
  • GRPO + experience distillation：同一 prompt 下采样多条轨迹，用图像奖励和文本程序充分性奖励做 group-relative optimization；再把 best / worst trajectory 的差异抽象成五类 visual experience，如 search、reference、knowledge、prompt 与 failure avoidance。

实验与结论

论文的实验重点不是单纯比较“谁生成得更好看”，而是比较 agent 是否真的学会了更好的工具编排、参考图使用和 failure-aware prompt synthesis。奖励也不是只看图像，而是图像质量与最终程序充分性共同决定。

  • 图像奖励：综合 factual faithfulness、visual correctness、text accuracy 与 aesthetics，其中 visual correctness 和 text accuracy 权重最高。
  • 文本奖励：检查最终 program 是否充分编码了 grounding facts、reference role、generation knowledge 与 executable constraints。
  • 核心收益：GenEvolve 学到的不是更会“润色 prompt”，而是更会在轨迹层面做决策，尤其体现在更合理的 search、reference 绑定和 skill routing 上。

最值得记住的实验信息是：作者把 best/worst trajectories 之间的结构性差异提炼成 teacher-only visual experience，再做 token-level distillation。这样 student 学到的不是抽象的“高分偏好”，而是更接近过程监督的具体决策经验。

价值、局限与启发

  • 价值：把 image generation 从黑盒 prompt optimization 推进到了真正的 agent post-training 场景，工具调用、参考图组织和内部绘图知识第一次被统一到同一个轨迹优化框架里。
  • 方法启发：best-vs-worst trajectory comparison 很适合视觉任务，因为最终图像 reward 很难直接分解到每一步，而 visual experience distillation 给出了一条可解释的中间桥梁。
  • 局限：系统仍然依赖 reward 设计和 teacher trajectory 质量；如果 search / image retrieval 本身不稳，后续蒸馏也可能学到噪声。
  • 阅读重点：这篇论文最该看的不是某一张定量表，而是“为什么单次 prompt rewrite 不够”以及“experience 槽位化后如何进入 distillation”这两个结构性设计。
