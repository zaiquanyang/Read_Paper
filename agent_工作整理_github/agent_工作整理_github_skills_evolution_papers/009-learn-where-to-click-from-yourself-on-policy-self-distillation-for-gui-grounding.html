方法核心

  • 昂贵的多重 rollout：GRPO 需要采样多个 rollout 来估计优势，训练成本高（每 epoch 约 17 小时，8×A800）
  • 困难样本的稀疏信号：当所有 rollout 都未命中目标时（二值奖励全部为 0），梯度为零，模型无法从失败中学习
  • 人工设计奖励的依赖：需要精心设计奖励函数（二值/距离/高斯），不同设计对性能影响显著

On-Policy Self-Distillation (OPSD) 提供了一种有前景的替代方案：

  • 使用同一模型同时作为 teacher 和 student，通过不对称上下文产生差异
  • Teacher 拥有 student 无法访问的特权信息（如参考答案、验证信号），产生更可靠的输出分布
  • 通过 token 级 reverse KL 散度 提供密集的逐 token 监督信号
  • 只需单次 rollout，训练效率大幅提升

GUI-SD 由两个互补组件组成：

  • Visual Privileged Guidance（视觉特权引导）：用视觉特权上下文替代文本特权，使 teacher 保持信息丰富的软分布
  • Entropy-Guided Optimization（熵引导优化）：用自适应 token 加权替代均匀 reverse KL，在最有影响力的坐标 token 上集中优化

GUI-SD 框架：(a) Teacher 分支接收目标边界框 + 高斯软掩码 + hint prompt 的特权上下文。(b) 基于数位权重和熵门控的加权 reverse-KL 目标

用视觉特权上下文替代文本特权信息，让 teacher 接收目标感知引导而不直接获取精确坐标。

具体做法：

  • 红色边界框：在 teacher 输入图像的目标区域上绘制红色边界框
  • Hint Prompt：附加文字提示 "Hint: The answer is located within the red rectangle."
  • 高斯软掩码：对距离目标边界框越远的像素进行渐进式衰减，模拟"放大"效果
\[\alpha(x, y) = \exp\left(-\frac{d^2}{2\sigma^2}\right)\]

其中 $d$ 是像素 $(x, y)$ 到目标边界框最近边的距离（框内 $d=0$），$\sigma$ 根据目标大小自适应缩放（含最小下界以防止小目标被过度遮蔽）。

实验与结论

基础模型：Qwen3-VL-Instruct-8B

训练数据：ScaleCUA GUI 数据集的 grounding 训练子集，经两阶段清洗后约 7K 样本：

  • UI-Venus1.5-8B 过滤：保留预测与原始标注一致的样本
  • Qwen3-VL-8B 改写：将原始指令改写为多样化表述

超参数：

  • 学习率：2.5e-6 → 0（线性衰减）
  • Batch size：1 × 16（梯度累积）= 16
  • Epochs：1，Warmup ratio：0.05
  • Max completion length：128
  • EMA decay：0.95
  • 硬件：8×A800-80G

评估 Benchmark（6 个）：

  • ScreenSpot-v2：通用 GUI grounding
  • ScreenSpot-Pro：专业高分辨率软件（目标仅占截图 0.07%）
  • UI-Vision：最大桌面 GUI benchmark（83 个应用）
  • MMBench GUI L2：跨平台层级指令遵循
  • OSWorld-G / OSWorld-G-Refine：Linux 环境真实交互

价值、局限与启发

  • 昂贵的多重 rollout：GRPO 需要采样多个 rollout 来估计优势，训练成本高（每 epoch 约 17 小时，8×A800）
  • 困难样本的稀疏信号：当所有 rollout 都未命中目标时（二值奖励全部为 0），梯度为零，模型无法从失败中学习
  • 人工设计奖励的依赖：需要精心设计奖励函数（二值/距离/高斯），不同设计对性能影响显著
  • 首个 GUI Grounding 的 OPSD 框架：将 OPSD 从自然语言推理成功扩展到视觉 grounding 任务，提供了一种不依赖多重 rollout 的高效训练范式
  • 训练效率极高：每 epoch 仅 4.2 小时（GRPO 需 16.8 小时），4× 加速，同时精度更高
  • 视觉特权设计优雅：用边界框 + 高斯软掩码 + hint prompt 构建视觉特权上下文，既提供有效引导又保持 teacher 分布的信息量（entropy=0.50），避免了 Distillation-to-SFT Collapse
  • 熵引导优化精准：位置信用分配（百位权重 > 个位）和熵门控监督（高置信 token 权重 > 低置信）组合，在最有影响力的 token 上集中优化
  • 全面超越 GRPO：在 6 个 benchmark 上 Avg +4.9pp（68.4 vs 63.5），超越所有 GRPO 变体
  • 跨规模一致有效：在 2B/4B/8B 三个规模上一致提升，SSP 上分别 +3.7/+4.6/+7.1pp
  • 未探索更大模型和其他模型家族：当前仅在 Qwen3-VL 上验证，其他 VLM（如 LLaVA、InternVL）上的效果未知
  • 仅处理 ADD/NOOP 二值决策：GUI grounding 本身是坐标预测任务，但 GUI-SD 的 OPSD 框架未扩展到更复杂的多步 GUI Agent 任务
  • 依赖高质量视觉特权设计：边界框标注和高斯掩码的超参数（$\sigma$ 的缩放因子、最小下界）需要调优
  • 训练数据规模有限：仅用 ~7K 样本训练（1 epoch），大规模数据下的效果和收敛特性有待验证
  • 开放域性能未评估：主要评估 GUI grounding 精度，未涉及更广泛的 Agent 任务（如任务完成率、多步规划等）...
