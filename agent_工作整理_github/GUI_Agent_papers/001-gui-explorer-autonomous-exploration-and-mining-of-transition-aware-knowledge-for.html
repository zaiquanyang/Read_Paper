GUI-explorer: Autonomous Exploration and Mining of Transition-aware Knowledge for GUI Agent

本地总结 GUI explorationtransition-aware memorytraining-free
GUI-explorer 的重点不是训练一个新模型，而是让 GUI agent 自主探索应用，把“当前界面、动作、下一个界面”的状态转移知识挖出来，形成可检索的 GUI knowledge base。

核心机制

  • 把知识单元从静态 screenshot 或 action label 提升为 transition tuple：$(observation, action, next\ observation)$。
  • 探索阶段记录动作后果，避免只记“这个按钮在哪”，而不知道“点完会去哪里”。
  • 推理阶段根据当前任务和界面检索相关转移知识，给 agent 提供动态 guidance。

价值与局限

它直接回应了 GUI agent 的一个基础痛点：视觉 grounding 不等于环境理解。缺点是探索质量受初始 agent 和环境覆盖限制，且 transition memory 如果没有去重、版本管理和失败过滤，容易膨胀成 noisy cache。
