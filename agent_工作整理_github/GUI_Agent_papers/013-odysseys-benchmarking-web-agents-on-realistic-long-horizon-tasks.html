Odysseys: Benchmarking Web Agents on Realistic Long-Horizon Tasks

本地总结 web agentlong-horizonrealistic tasks
Odysseys 代表了 Web Agent 评测从短链路点击走向真实长程任务的趋势。它关注 agent 在复杂网页环境中持续规划、跨页面保持状态、处理现实约束的能力。

为什么放在 GUI Agent 页

Web agent 是 GUI agent 的一个重要子类：DOM/accessibility tree 能提供结构化信息，但用户最终面对的仍是视觉界面和交互状态。Odysseys 与 WeaveBench 的共同点是都在提醒：真实 agent 任务不是单步 grounding，而是长程状态维护和过程合规。

对训练的启发

长程 web benchmark 更适合用 trajectory-aware memory、可验证终态、局部过程奖励共同训练。如果只用最终 success/fail，很难判断失败来自 grounding、页面理解、跨页状态、还是工具使用策略。
