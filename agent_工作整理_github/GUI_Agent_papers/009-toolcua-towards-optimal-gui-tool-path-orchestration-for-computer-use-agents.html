ToolCUA: Towards Optimal GUI-Tool Path Orchestration for Computer Use Agents

arXiv 2605.12481GitHub
本地总结 Code GUI-tool hybridMCP toolsonline agentic RL
ToolCUA 的核心判断很锋利：给 agent 工具不等于 agent 会用工具。难点不是“会不会调用”，而是“什么时候该用工具，什么时候必须回到 GUI grounding”。

核心机制

  • 从成功 pure-GUI trajectories 出发，合成 trajectory-aware tool library 和 GUI-tool interleaved trajectories。
  • next-state grounding：工具调用后预测的状态必须和原 GUI 轨迹中的后续 screenshot 对齐，避免幻想 API。
  • Tool-Bootstrapped GUI RFT：先 warmup SFT，再在 GUI/tool critical switching steps 上做单轮 RL。
  • Online Agentic RL：用 Tool-Efficient Path Reward 鼓励合适工具与更短路径，而不是鼓励工具调用越多越好。

关键结论

预实验显示，很多强模型加入工具后成功率反而下降：小模型 underuse，大模型 overuse。ToolCUA-8B 在 OSWorld-MCP 上通过混合路径编排提升到约 46.85%，同时减少平均步骤。它和 OSExpert 很互补：OSExpert 发现技能，ToolCUA 学会在 GUI-tool 空间里编排技能。
