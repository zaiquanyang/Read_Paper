ScreenSearch: Uncertainty-Aware OS Exploration

本地总结 arXiv OS explorationpartial observabilitystate graph
ScreenSearch 把 desktop GUI 的“看起来一样但其实不一样”变成可计算问题：用 UIA 结构做 screen retrieval / dedup，再用 matched-action outcome dispersion 估计状态歧义。

核心机制

  • 用 UIA-derived structural features 为 screen 建 canonical state ID，降低 cursor/focus 等无意义变化影响。
  • 维护 deduplicated state graph，让不同 history 中的相同界面共享统计。
  • 用同一 action 在相似 screen cluster 上的后继状态分叉程度定义 ambiguity，再用 PUCT graph-bandit 平衡 novelty 和 ambiguity reduction。

对训练的启发

它提供了区别于 token probability 的不确定性信号：region/action 的质量可以看它执行后进入哪个 state cluster，是否降低歧义。对 bbox、click point、drag region 这类异质动作参数蒸馏很有启发。
