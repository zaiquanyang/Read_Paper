Harness 相关研究12 篇工作 · 4 条主线

  • 执行模型冻结条件下的 Harness 优化

    执行模型参数不变；编辑/生成模型可预先训练

    • 离线搜索后固定使用

      先迭代程序，再用于新题

      • Video-RSI冻结 Solver 与 Editor，离线补查视频证据并筛选程序修改，再固定 Harness 用于新题。
        不做 SFT / RL；仅程序搜索代码公开 · 推理/演化

    • 按实例生成或编辑

      生成/编辑模型先训练；每题执行前改程序

      • Turbo Harness离线训练 Editor，每题执行前基于共同 Harness 与搜索经验生成一次实例补丁。
        Editor：RL（GRPO）代码公开 · 含训练
      • JIT-Agent离线训练生成器，每题执行前生成专用的记忆、规划、动作与工具编排程序。
        生成器：SFT → DPO → RL（Evo-GDPO）部分公开 · 推理/权重

    • 新任务的反馈适配

      用开发题反馈调程序，再评估留出题

      • Harness Learning离线训练 Proposer，新任务上利用开发反馈多轮修改程序，再用于该任务的留出题。
        Proposer：RG 为 SFT → RL；QA 直接 RL（均为 GRPO）代码待发布

  • Harness—执行模型协同优化

    交替修改运行程序与执行模型权重

    • CoTrace失败轨迹驱动程序搜索，匹配当前运行时的数据用于模型训练，并逐项评估组件更新。
      执行模型：SFT 或 RL（DPPO），两套方案官方代码未核实
    • WHALE交替用成功轨迹做在线 SFT、冻结新模型搜索程序，维持模型与 Harness 匹配。
      执行模型：在线 SFT（RSFT），非 RL代码公开 · 含训练
    • HarnessForge依据失败修改规划、动作与记忆接口，再复用成功轨迹训练模型适配新接口。
      执行模型：默认 SFT；另测 RL-style 对齐部分公开 · Harness/数据工具

  • 执行模型能力训练

    Harness 支撑数据生成、恢复或流程内化

    • ReTerm保存自然失败的环境与历史，从同一状态采样恢复分支，用 SFT / RL 训练恢复能力。
      执行模型：SFT → RL（ReTerm-GRPO）代码公开 · 训练/数据/权重
    • Harness-Zero临时 Agent 在动作前审查或改写学生响应，生成目标接口轨迹做 SFT，部署时移除审查。
      执行模型：SFT（审核轨迹蒸馏）代码公开 · 含 SFT
    • Harness Scaling在预先构造的多种 Harness 上训练执行模型，使策略适应未见接口和流程组合。
      执行模型：RL（PPO / GRPO）；Harness 预先固定官方代码未核实

  • 训练与评测流程优化

    分别改进训练诊断与搜索评测效率

    • Task-CoEvolve自适应抽取有区分力的验证题，按入选概率估计完整成绩，减少候选评测。
      不做 SFT / RL；选题与程序搜索代码待发布
    • EvoTrainerTrainer 根据轨迹证据改进 RL 配方，并升级训练侧诊断工具、流程与技能库。
      执行模型：RL（GRPO-style）；Trainer 不训参数部分公开 · RL 底座/配方

训练标签指本文新增的参数训练：SFT＝监督微调，RL＝强化学习；DPO 单列为偏好优化，程序搜索不计为 RL。

开源/代码状态核验：2026-10-16；Harness Scaling 为匿名 ICLR 2027 稿，暂无可核实官方代码入口。「代码公开」表示已有实际实现；「部分公开」标明范围；代码可见与完整复现是不同口径。

查看官方代码入口与公开范围
  • Video-RSI（官方仓库）：代码公开 · 推理/演化。MIT；公开初始与最终 Harness、评测及演化相关工具。
  • Turbo Harness（官方仓库）：代码公开 · 含训练。MIT；包含 SkyRL、GRPO 配置及训练脚本；未确认可下载的训练后 Editor 权重。
  • JIT-Agent（官方仓库）：部分公开 · 推理/权重。公开生成、选择、修复与运行时代码及模型权重；缺少完整三阶段训练器、数据与配置。
  • Harness Learning（官方仓库）：代码待发布。2026-10-16 官方仓库只有 LICENSE 和 README，README 标注 Code coming soon；RG 指 Reasoning Gym。
  • CoTrace（论文）：官方代码未核实。论文称发布已采用的配置，但论文、摘要及现有笔记未提供可核实的官方代码入口；不据此断言未开源。
  • WHALE（官方仓库）：代码公开 · 含训练。Apache-2.0；公开训练与程序搜索管线，部分中间数据和论文配置仍有复现边界。
  • HarnessForge（官方仓库）：部分公开 · Harness/数据工具。公开已生成 Harness、评测及数据处理/SFT 工具；不捆绑完整训练数据、权重或 checkpoint。
  • ReTerm（官方仓库）：代码公开 · 训练/数据/权重。公开 SFT 与 RL 实现、ReTerm-10K 数据及 ReTerm-9B；训练需外接任务环境适配器。
  • Harness-Zero（官方仓库）：代码公开 · 含 SFT。Apache-2.0；公开轨迹审核、数据构建、SFT 管线及模型入口。
  • Task-CoEvolve（官方仓库）：代码待发布。2026-10-16 仓库只有 README 与 figs，README 明确 Code will be available soon。
  • EvoTrainer（官方仓库）：部分公开 · RL 底座/配方。公开 ROLL 底座、配置、训练配方及诊断技能；环境封装与部分分析器缺失，部分提示和工具模板脱敏。
