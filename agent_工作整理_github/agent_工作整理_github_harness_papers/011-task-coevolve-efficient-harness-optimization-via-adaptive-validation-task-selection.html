核心思想：搜索 Harness 时，每个候选只跑一部分验证题；优先选择历史候选表现分歧较大的题，再按入选概率估计全题库成绩，让不同子集上的候选可以比较。模型权重保持冻结，变化的是 Harness 代码与选题分布。

1. 问题：Harness 搜索贵在反复评测

搜索 $K$ 份候选、每份运行 $N$ 道题、每题尝试 $r$ 次，需要约 $KNr$ 次任务执行。终端题会占用沙箱几十分钟，评测往往比生成代码补丁更贵。

固定小子集容易让代码适应少数题；随机换题又使不同轮次的原始分数难以直接比较。Task-CoEvolve 因此同时解决“选哪些题”和“如何从部分评测估计完整成绩”。

2. 自适应选题与 Harness 共同演化

  1. 初始化：两份初始 Harness 跑完整验证集，建立每题历史成功率与观察次数。
  2. 选择子集：根据历史结果做方差加权抽样，偏向候选有成功也有失败的题，并给未成功题和观察不足题保留探索机会。
  3. 评测与估计：新候选只执行抽中的题，使用题目入选概率估计其全验证集成绩。
  4. 更新与选优：把新结果写入历史，供下一轮选题和代码编辑参考；最终保留估计分最高的候选。

验证题库固定，未抽中题目的统计不变。图中的“越来越难”表示随能力边界变化而转向更有区分力的题，算法没有预设难度递增课程；一直失败的题也未必最有用。

3. 关键机制：方差选题，逆概率校正

选题权重

\[w_t=\max\{\bar p_t(1-\bar p_t),\ell_t\}+\frac{\lambda}{\sqrt{n_t}}.\]

$\bar p_t$ 是历史成功率，$n_t$ 是观察次数；从未成功的题取 $\ell_t=0.125$，其余为 0，$\lambda=0.025$。成功率接近 0.5 的题优先，但历史包含模型随机性与环境噪声，方差不能视为纯粹的结构差异。

令 $\pi_t=\Pr(t\in S_k)$ 为本轮最终入选概率，通过 4,000 次抽样模拟估计。这些模拟无需调用 Agent 解题；$\pi_t$ 与单次归一化抽样权重不同。

文本分类：Hájek 比率估计

\[\widehat S(h)=\frac{\sum_{t\in S_k}x_t(h)/\pi_t}{\sum_{t\in S_k}1/\pi_t}.\]

较少入选的题获得更大权重，再除以总权重；三个分类数据集分别估计后取宏平均。比率形式一般不是有限样本严格无偏估计。

终端任务：历史 anchor 加残差

\[\widehat S(h)=\frac1N\sum_{t\in T}\bar p_t+\frac1N\sum_{t\in S_k}\frac{x_t(h)-\bar p_t}{\pi_t}.\]

先以历史全题库均分为起点，再估计当前候选的变化量。anchor 可减轻低概率题的逆权重放大；实际仍受近似入选概率、小样本与选优误差影响。两个 benchmark 使用不同估计器，不能直接互换。

最大单步收益来自避免反复使用同一子集。均匀重采样加成绩校正，是评估后续改进时需要保留的强基线。

  • 排序仍有误差：一次全量重评诊断中，7% / 20% 预算的估计分与完整分 Spearman 仅 0.13 / 0.62；选中候选的真实名次为 10/60 和 12/60，未恢复真正最优者。
  • 估计器依赖任务：分类 20% 时把 Hájek 换为 difference，成绩从 49.3±0.8 降至 46.0±2.6。终端则有 Hájek 将真实 52.8% 估为 82.8% 的案例，低概率题会放大噪声。
  • 强起点的负结果：DeepSeek-V4-Flash 配 Terminus 2 已达 70.8%；该设置下 10 次全量搜索最好仍为 70.8%。

6. 搜到了什么，以及结论的边界

分类 Harness 组合 word-bigram 与 character n-gram 的 TF-IDF 索引，用 reciprocal rank fusion 合并检索结果，并控制上下文中的标签多样性。终端 Harness 则轮询命令回显、画面稳定及 shell prompt，在命令结束后提前返回，减少固定等待浪费。

  • 方法定位：meta-agent 根据上下文和日志编辑代码；执行模型、编辑模型均未进行参数更新。本文的方差统计单位是验证题。
  • 泛化证据：分类有独立 test，终端没有 held-out test；终端成绩支持在该 89 题库上的搜索效率，未知任务收益仍需验证。
  • 统计限制：全部历史可能滞后于能力变化；每候选样本数固定；选最大估计分仍有 winner’s curse，且 Monte Carlo 入选概率存在误差。
  • 复现细节：7% 分类档原表列每池 2/3/3 题，与方法中的逐池向上取整不一致；应澄清抽样实现和取整规则，并保存抽样前历史、权重、概率、种子及选优规则。
