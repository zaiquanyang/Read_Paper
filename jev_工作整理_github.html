OpenJev-RLCD: A Working RLCD Implementation

Zhimin Gao · Pichao Wang ｜ arXiv:2609.38850v1 ｜ 2026-09-30

arXiv · PDF 原文 · 官方代码

核心思想

决策模型既要答对，也要用概率表达不确定性。OpenJev-RLCD 对每条推理后的选项分布使用严格适当评分：先校准概率读出，再强化能得到高评分的推理，使单次查询的置信度更适合阈值路由。

关键结果：GSM8K-Verify 上，RLCD 与 GRPO 准确率相近（92.2% / 91.8%）；错误率预算为 5% 时，覆盖率从 19.4% 提升到 81.1%。

问题与动机

只奖励答案对错的 RLVR / GRPO，可能提高准确率却留下过度自信的错误。部署中需要按置信度决定自动执行或回退，因此还要看风险—覆盖曲线；二分类中的全局温度缩放能调整概率，却不能修复跨样本置信度排序。

方法核心：先校准，再强化

模型先生成推理 \(r\)，再从候选 token 的 logits 读出分布 \(u_\theta(x,r)\)。采用越高越好的 Brier 得分：

\[J(u,y)=2u_y-\lVert u\rVert_2^2=1-\lVert u-e_y\rVert_2^2.\]

其期望在报告真实分布时唯一最大。评分位置也很关键：若只优化多条推理的平均分布，单条推理仍可极端自信、彼此矛盾。令 \(p=\mathbb E_r[u(r)]\)，则：

\[J(p,q)=\mathbb E_r[J(u(r),q)]+\mathbb E_r\lVert u(r)-p\rVert_2^2.\]

因此面向单次调用，使用逐推理目标（\(\lambda=0\)）。

  1. Stage 1 · 校准读出：每题采样 4 条当前策略推理，关闭 REINFORCE（\(c=0\)），仅通过可微的 Brier 目标更新参数。关闭采样路径的策略梯度，不等于冻结模型权重。
  2. Stage 2 · 强化推理：保留读出优化，以 Stage 1 模型为 KL 参考（\(\beta=0.04\)），用 leave-one-out 优势强化推理，并将策略梯度缩放至 \(c=0.3\)；两阶段各 400 步。

解耦针对两个训练问题：从头联合优化可能坍塌为空推理；REINFORCE 梯度 RMS 约为读出梯度的 7–12 倍，噪声会压制校准更新。

  • Stage 2 消融：从同一 Stage 1 checkpoint 出发、匹配 400 步预算，RLCD 在 GSM8K 上提高准确率 1.8 个百分点、降低 Brier 0.029；MMLU-Pro 上，GRPO 分支的 Brier 与 AURC 恶化，RLCD 分支继续改善。
  • 增益依任务而异：MMLU-Pro 的 Stage 1 已达 47.0% 准确率、27.3% Cov@20%，第二阶段的额外收益较小。

价值、局限与启发

  • 工程启发：先建立推理后概率监督基线，再判断策略强化是否值得；同时报告准确率、校准指标和目标风险预算下的覆盖率。
  • 任务边界：ChaosNLI 的人类分歧实验中，逐推理目标可学出空推理，JSD 为 0.075，接近直接 CE 的 0.074；更长思考并非所有不确定性的解法。
  • 证据范围：主要结果来自一个 1.7B 模型和两类决策任务；测试集上的风险—覆盖结果仍需在具体业务分布与路由策略中验证。

System1-Arena: Which Decisions Can Be Left to System 1?

arXiv:2610.21244 ｜ 统一结构化决策接口的跨模型 Benchmark

arXiv · PDF 原文 · 代码 · 数据集 · 项目页

核心思想

用同一套结构化决策请求，比较原生 System-1 模型与生成式 LLM 的准确率、概率质量、延迟、成本和闭环表现。本文提供评测基准，核心发现是：Jev 在高频局部决策中具有成本与概率质量优势，但单步得分不足以判断长程任务的成败。

问题与动机

只看静态准确率，会忽略错误置信度、实时延迟与状态偏移后的恢复能力。System1-Arena 覆盖 92,125 个结构化问题、105 个静态任务、138 个闭环环境和 30 个模型；其中非 Agent 静态部分为 87 个任务，闭环环境中 128 个报告二元成功率、10 个报告连续奖励。

方法核心：统一接口，分层看结果

  • 决策请求：输入状态与问题集，支持 Boolean、Choice、Score，输出候选集上的归一化概率。System 1 不生成中间推理文本，直接读出分布。
  • 概率获取：原生决策模型直接输出概率；开源 LLM 读取答案位置的候选 token 概率；闭源 LLM 生成结构化数值再归一化。三者接口一致，概率信号的生成机制仍有差异。
  • Agent 评测：单步测试对齐记录轨迹的参考动作；闭环测试让模型连续选动作、改变后续状态。固定 Harness 先构造候选集，再执行最高概率动作；正确动作若不在候选中，决策头无法补救。
  • 实时模式：环境在推理期间继续推进，让延迟影响动作落地时的观测新鲜度。
\[\mathrm{Brier}(p,t)=\sum_o\bigl(p(o)-t(o)\bigr)^2\quad\text{（越低越好）}.\]

Brier 衡量整体概率预测质量；更低的平均 Brier 仍需结合具体阈值下的风险—覆盖率检验。

实验与结论

  • 思考预算消融：Qwen3.8-27B 从 0 增至 2,048 个思考 token，准确率由 70.2% 升至 75.6%，Brier 却由 0.391 升至 0.430；额外推理可以提分，却未必让概率更可靠。
  • 同源底座比较：5 对 System-1 模型中，4 对改善非 Agent Brier，全部 5 对的 Agent 单步匹配率下降，闭环成功率则有升有降。静态后训练收益不能直接外推到控制能力。

价值、局限与启发

  • 适用方向：高频、局部、候选明确的过滤、排序与路由值得优先尝试 System 1；长程控制需要额外验证状态恢复、候选覆盖与最终成功率。
  • 评测边界：固定 Harness 的动作离散化与兜底会影响闭环结果；公开数据可能存在污染，随机生成与环境仅单次抽样，缺少重复运行方差。
  • 工程启发：将静态 Accuracy / Brier、离线单步和在线闭环分开验收，并核算每次成功任务的总成本。论文的每千次请求单价不能直接替代该成本。

与 OpenJev-RLCD 联读：RLCD 改进推理后的概率读出；本基准提供跨任务检验这些收益及其闭环边界的视角。
