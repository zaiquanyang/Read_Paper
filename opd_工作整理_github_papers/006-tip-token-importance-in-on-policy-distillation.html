TIP: Token Importance in On-Policy Distillation

TIP arXiv abs PDF arXiv 2604.14084
核心思想：OPD 里并非所有 rollout token 都值得蒸馏。只用 student entropy 选 token 会漏掉最危险的 Q3（自信但错误）token。TIP 将 uncertainty 和 teacher-student disagreement 融合为 Soft-OR 分数，只蒸馏高价值 token，50% 预算下性能全面超过 full-token OPD，显存下降约 47%。

问题与动机

  • Token 训练价值不均：传统 full-token OPD 对整条 student 轨迹每个 token 都做蒸馏，但大量 token 训练价值很低。
  • Entropy-only 的盲区：只按 student entropy 选 token 时，Q3（低熵但 teacher 强烈不同意）和 Q4（低熵且正确）无法区分——自信但错误的 token 被一起忽略。
  • 核心判断：token importance 必须同时考虑 uncertainty（student 知不知道自己不会）和 disagreement（teacher 觉不觉得 student 走偏了）。

方法：Soft-OR Token Selection

  • 四象限 taxonomy：按 student entropy $h_t$ 和 teacher-student KL divergence $\delta_t$ 将 token 分为 Q1（高熵+高分歧，最值得纠正）、Q2（高熵+低分歧）、Q3（低熵+高分歧，最危险）、Q4（低熵+低分歧，最不重要）。
  • Soft-OR scoring：$s_t = \hat{h}_t + \hat{\delta}_t - \hat{h}_t \hat{\delta}_t$，任一信号高即可把 token 选出，避免 Q3 被漏掉。
  • Top-$k$ selection：按 $s_t$ 取 top-$\lfloor\rho m\rfloor$ token 做蒸馏，$\rho$ 为保留比例。
  • 最终损失：只在选中 token 上做 KL distillation，$\hat{\delta}_t=0$ 时退化回 entropy-only。

Beyond Math — DeepPlanning (Agentic)

优点与局限

优点

  • Q1/Q2/Q3/Q4 分析框架清晰，uncertainty × disagreement 两个维度拆解 token importance
  • Soft-OR 公式简洁直觉强，entropy-only 退化保证兼容性
  • 50% 预算全面超过 full-token OPD，显存省 47%
  • Q3-only 在 agentic planning 上甚至超过 full OPD

局限

  • Soft-OR 需要实时计算 teacher-student KL，推理成本仍在
  • 主实验集中在 math reasoning，泛化到开放生成待验证
  • Q3 token 数量少、检测依赖 KL，低资源场景可能不稳定

定位：token-level importance scoring for OPD。与 EOPD（entropy-aware KL routing）、TSD-KD（token-selective dual KD）互补——TIP 关注"选哪些 token 蒸馏"，EOPD 关注"用什么 KL 蒸馏"，TSD-KD 关注"用什么形式监督"。Q3 correction 在 long-horizon/agentic 场景的启发值得后续跟进。
