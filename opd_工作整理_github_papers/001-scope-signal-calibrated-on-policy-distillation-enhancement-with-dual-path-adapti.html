SCOPE: Signal-Calibrated On-Policy Distillation Enhancement with Dual-Path Adaptive Weighting

arXiv 2604.10688GitHub
SCOPE PDF Code arXiv 2604.10688
核心思想：OPD 最大的问题是把所有 rollout 的监督信号当成同等可信。SCOPE 按 trajectory correctness 分流——错误轨迹用 teacher PPL 加权（teacher 越自信越值得学），正确轨迹用 student PPL 加权（student 越不确定的正确路径越值得强化），实现 trajectory-level signal calibration。

问题与动机

  • Pass@k paradox：现有 OPD/RL 方法提升 Pass@1 却降低 Pass@k——概率质量被压缩到少数路径，牺牲多样性。
  • Flawed prefix trap：teacher 在 student 的错误 prefix 上也会被拖偏，高 teacher PPL 的错误前缀 recovery rate 显著更低。
  • 核心问题："哪些 trajectory 值得教、值得教多少"。

方法：Dual-Path Adaptive Weighting (DPAW)

  • Correctness 分流：rollout 按 verifier 分成正确组 $\Omega_c$ 和错误组 $\Omega_w$。
  • 错误轨迹 (teacher-guided)：走标准 OPD surrogate，用 teacher PPL inverse 加权——teacher 越自信，纠错信号越可信。
  • 正确轨迹 (student-guided)：改用 MLE self-reinforcement，用 student PPL 加权——student 越不确定的正确路径越值得强化。

消融要点

  • 去掉 DPAW：Avg@32 42.7 → 39.9，uniform weighting 问题复现。
  • 去掉 student-guided weight：Pass@32 77.9 → 74.1——正确路径保 diversity 有价值。
  • 反转 teacher-guided weight：Avg@32 42.7 → 38.6——应优先学 teacher 自信的样本。

优点与局限

优点

  • 精准拆穿 "uniform supervision" 假设，问题定义强
  • 正误路径用相反 PPL 逻辑，直觉自然且有实验支撑
  • 同时提升 Avg@32 和 Pass@32

局限

  • 依赖 verifier 分流，更适用于数学/代码等 objective task
  • 多 rollout + teacher scoring 开销大（641.9s vs OPD 227.5s）
  • 未直接处理 token-level teacher uncertainty

定位：trajectory-level signal routing for OPD。与 EOPD（token-level KL routing）、LSM（token-level supervision granularity）互补。
