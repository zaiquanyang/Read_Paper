# LearnPruner: 重新思考视觉语言模型中基于注意力的 Token 剪枝

## 基本信息

- **标题**: LearnPruner: Rethinking Attention-based Token Pruning in Vision Language Models
- **ArXiv ID**: 2604.23950
- **链接**: [Abs](https://arxiv.org/abs/2604.23950) | [PDF](https://arxiv.org/pdf/2604.23950.pdf)
- **作者**: Rinyoichi Takezoe, Yaqian Li, Zihao Bo, Anzhou Hou, Mo Guang, Kaiwen Long
- **机构**: Li Auto Inc.
- **会议**: ICLR 2026

---

## 核心问题与动机

VLM 推理时需要处理大量视觉 token（如 LLaVA-1.5 为 576 个，LLaVA-NeXT 可达 2880 个），带来严重的计算负担。Token 剪枝的核心在于判断 token 重要性，当前方法主要依赖**注意力分数**。但本文发现两个关键问题：

1. **视觉编码器的 [CLS] 注意力不可靠**：ViT 倾向于在背景区域产生高范数异常 token（artifacts），导致 [CLS] token 对前景区域的关注不足
2. **LLM 的注意力存在层间差异**：虽然存在 attention shift 现象（视觉 token 索引越高获得的注意力越多），但**文本到视觉的注意力**对此偏移具有鲁棒性，且在中间层才能有效关注语义相关区域

核心问题：*能否设计一个两阶段剪枝框架，在不同阶段使用最合适的重要性度量？*

---

## 方法概述

### 注意力机制分析（关键发现）

通过在 LLaVA-1.5-7B 上的系统实验，得出三个核心观察：

**发现 1：视觉编码器 [CLS] 注意力的缺陷**
- 将 token 选择限制在前景区域（$\texttt{[CLS]}_{fg}$）始终优于全图选择（$\texttt{[CLS]}_{all}$），尤其在激进剪枝比例下
- 甚至随机前景选择（$\text{Random}_{fg}$）都能达到与 $\texttt{[CLS]}_{all}$ 相当的性能
- 结论：[CLS] token 未能有效关注前景区域

**发现 2：LLM 中文本注意力 vs 视觉注意力**
- 视觉注意力受 attention shift 严重影响，不同样本间偏差大
- 文本注意力的偏移趋势更平缓，且不同样本和低索引 token 也能获得高关注度
- 结合视觉注意力会导致性能大幅下降

**发现 3：LLM 中间层的注意力最可靠**
- 浅层：不相关区域吸收了文本 token 的大部分注意力
- 中间层（8+ 层开始）：不同文本 token 能聚焦到语义相关区域，>95% 原始性能
- 深层：注意力可靠性显著下降

### LearnPruner 框架

基于上述分析，提出**两阶段剪枝框架**：

![框架概览](assets/arxiv_2604_learnpruner_rethinking_attention_based_token_pruning_in_vision_language_models/framework2.png)

**阶段一：移除视觉冗余（视觉编码器后）**

使用**可学习剪枝模块（LPM）**替代 [CLS] 注意力：
- 轻量 MLP 对每个视觉 token 做二分类（保留/剪枝）
- 使用 Straight-Through Estimator（STE）实现端到端训练
- $\mathbf{M}_{\text{soft}} = \text{Softmax}(\text{MLP}(\mathbf{X}_v^{(0)}))$，推理时作为重要性分数

为防止 LPM 过度聚焦前景而丢失关键背景信息，引入**多样性 token 选择**：
- LPM 选完后，对剩余 token 计算与已选 token 的最大余弦相似度
- 迭代添加相似度最小的 token，直到 token 预算用尽
- 默认保留 10% 的 token 预算用于多样性选择

**阶段二：移除文本无关内容（LLM 中间层）**

在 LLM 第 12 层利用**文本注意力**进行二次剪枝：
- $\tilde{\mathbf{A}}^{(k)} = \frac{1}{N_q} \sum_{i=1}^{N_q} \mathbf{A}^{(k)}(\mathbf{X}_{q,i}^{(k)}, \mathbf{X}_v^{(k)})$
- 仅保留注意力分数最高的 top-k token

两个阶段的 token 保留比例 $R_1:R_2 = 3$（消融实验验证最优）。

### 训练细节

- **训练数据**：LLaVA-665K 数据集的 10%（数据效率极高，5% 即可达到强性能）
- **训练策略**：冻结基础 VLM 权重，仅训练 LPM
- **损失函数**：$\mathcal{L} = \mathcal{L}_{\text{ntp}} + \lambda \cdot \mathcal{L}_{\text{prune}}$，其中 $\mathcal{L}_{\text{prune}} = (\frac{1}{N_v} \sum \mathbf{M}_{\text{hard}} - \tau)^2$，$\tau=0$ 鼓励最小化 token 使用
- **注意力掩码训练**：通过修改 Softmax 模拟剪枝过程——被剪枝 token 不参与注意力计算

### 消融实验

**重要性度量对比（64 token）**：
- Stage1 [CLS] Attn → 94.6%
- Stage1 LPM → 96.1%（+1.5%）
- Stage1 LPM + Stage2 Text Attn → **96.9%**（+0.8%）
- Stage1 LPM + Stage2 LPM → 96.9%（第二阶段用 LPM 无额外收益，说明注意力信号已足够可靠）

**LLM 剪枝位置 k**：k=12 最优，浅层注意力不可靠（8 层仅 96.2%），深层注意力衰退

**R1:R2 比例**：3:1 最优——第一阶段保留更多 token 保证视觉完整性，第二阶段只需少量 token 精准选择

**多样性 token 比例 λ**：0.1 最优——平衡前景语义和背景补充

**数据效率**：仅用 5% LLaVA-665K 即可达到强性能，10%~100% 性能稳定

## 优势

1. **精准的重要性度量**：用可学习模块替代 [CLS] 注意力，更准确关注前景区域
2. **阶段适配的剪枝策略**：视觉编码器后用 LPM（注意力不可靠），LLM 中间层用文本注意力（注意力可靠），每阶段使用最合适的度量
3. **极高参数效率**：仅 0.53M 可学习参数，远少于 TwigVLM 的 610M
4. **强数据效率**：5% 训练数据即可达到强性能
5. **跨架构泛化**：在 LLaVA 系列和 Qwen2.5-VL 上均有效
6. **激进剪枝下优势显著**：在 32 token（94.4% 剪枝）时远超其他方法

## 局限性

1. **需要少量训练**：虽然参数少，但仍需训练（非 training-free），而 FastV、SparseVLM 等无需训练
2. **固定剪枝位置**：第二阶段固定在第 12 层，未实现自适应层选择
3. **R1:R2 比例固定**：使用固定比例 3:1，不同任务的最优分配可能不同
4. **主要在 7B 模型上验证**：未在更大规模模型（如 13B/70B）上测试
5. **复杂场景下可能丢失关键信息**：当场景过于复杂时，第一阶段剪枝可能丢失后续推理所需的视觉信息

## 复现 / 实现要点

- **基础模型**：LLaVA-v1.5-7B、LLaVA-NeXT-7B、Video-LLaVA-7B、Qwen2.5-VL-7B
- **训练数据**：LLaVA-665K 的 10%
- **训练策略**：冻结基础 VLM，仅训练 LPM（轻量 MLP）
- **端到端训练**：通过修改 Softmax 实现注意力掩码，模拟剪枝过程
- **损失函数**：$\mathcal{L} = \mathcal{L}_{\text{ntp}} + \mathcal{L}_{\text{prune}}$，$\tau=0$，$\lambda=1$
- **推理设置**：第一阶段保留 $R_1$ token（90% LPM + 10% 多样性），第二阶段在第 12 层保留 $R_2$ token，$R_1:R_2=3$
- **评估基准**：GQA、SQA、TextVQA、POPE、MME、VQAv2、MMBench（中/英）、TGIF-QA、MSVD-QA、MSRVTT-QA
- **评估设备**：NVIDIA A100-80GB

## 未来工作启发

1. **自适应剪枝位置**：根据输入动态选择最优剪枝层，而非固定 k=12
2. **自适应 token 分配**：根据图像信息密度动态调整 R1:R2 比例
3. **与量化结合**：token 剪枝 + 量化可能实现更极致的效率提升
4. **更大规模验证**：在 70B+ 模型上验证剪枝收益是否更大
5. **在线学习 LPM**：让 LPM 在推理过程中自适应更新，而非固定训练后的权重
6. **视频场景深化**：当前视频实验较初步，可探索时序维度的自适应剪枝策略
